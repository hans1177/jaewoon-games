# 포근섬: 작은 왕국 키우기 — Game Design / Code Sync

구현 기준: `5bb5500a2d43e0fb32a84c55ac46a61356093796` (main)

## 실제 게임 루프
직접 채집 → 주민 자동화 → 병영/병사 → 보이는 자동전투 → 5개 자원 거점 점령.

## 그래픽 콘셉트
**COZY_CHIBI_STORYBOOK**
- WorldArtPass: `COZY_CHIBI_KINGDOM_WORLD_V8`
- CharacterArtDirection: `COZY_CHIBI_KINGDOM`
- 큰 머리, 둥근 얼굴, 짧고 굵은 팔다리의 동화책/미니어처 왕국 비율.
- 직업은 모자·앞치마·도끼·망토 같은 실루엣 소품으로 구분.
- 멧돼지 등 동물은 파츠가 떠 보이지 않고 하나의 연결된 몸처럼 보여야 한다.
- RPG 영웅 체형과 심야 공포 체형을 재사용하지 않는다.

## 현재 MVP
직접 나무/식량 채집, NPC 마을, 야생동물/약탈병, 주민 자동화, 병영/병사, 5거점, 자동전투, 협동지원, 저장.
