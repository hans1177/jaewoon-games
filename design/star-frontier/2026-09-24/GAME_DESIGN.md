# 별길 개척자

## 핵심

작은 우주 개척선을 직접 조종해서 운석을 채굴하고 해적 드론과 싸운 뒤, 정거장으로 귀환해 판매와 업그레이드를 반복하는 공유 월드 우주 탐험 게임이다.

## 한 판 흐름

1. 청람 성역의 개척자 정거장에서 출발한다.
2. 가까운 운석을 찾아 채굴해 화물칸을 채운다.
3. 해적 드론을 격파하면 즉시 크레딧을 얻는다.
4. 정거장으로 돌아와 광석을 판매하고 우주선 또는 레이저를 강화한다.
5. 워프 게이트를 통과해 적동 운석대, 유령 성운으로 진입한다.
6. 성역이 깊어질수록 적이 강해지고 격파 보상이 늘어난다.

## MVP 규칙

- 성역 3개.
- 운석은 채굴 후 일정 시간 뒤 재생성.
- 화물칸 용량 제한 존재.
- 부스트는 에너지를 소비하고 비사용 시 회복.
- 정거장 도킹 범위에서만 판매, 수리, 업그레이드 가능.
- 선체가 0이 되면 화물은 잃지 않고 시작 정거장으로 구조된다.
- 크레딧, 광석, 우주선 티어, 레이저 레벨, 현재 성역을 저장한다.
- 이동, 채굴, 공격, 경제, 저장은 서버 권한으로 처리한다.

## 모바일

좌측 이동 패드와 우측 액션 패드를 기본 UI로 사용한다. 키보드는 W/A/S/D, Q/E, Shift, F, R을 보조 입력으로 지원한다.

## 차별화

외부 게임의 코드, 에셋, 맵, 세력 설정은 복사하지 않는다. 참고하는 건 넓은 우주를 탐험하고 채굴과 전투가 성장으로 이어지는 장르적 재미뿐이다.
