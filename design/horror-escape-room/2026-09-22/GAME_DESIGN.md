# 심야 술래잡기 — Game Design

실제 플레이어 몬스터 1명이 생존자를 얼리고 생존자들이 서로 해동하며 버티는 몬스터 얼음땡.

역할선정: 지원자 우선 → 없으면 공정 가중랜덤 → 직전 몬스터 제외 → 강제 몬스터 +50% 보상. 1인은 역할 직접 선택 + AI 충원.

몬스터: 드라크 / 프랑켄 / 울프 / 미이라 / 리퍼.

MVP: 학교맵1, 얼음/해동, 대시, 마지막 생존자, 5종 몬스터, 성장/해금, AI 충원, 저장, 라운드 재시작.

금지: 퍼즐, 암호, 복잡한 탈출아이템, 지나치게 어두운 화면.

출시: Studio 미사용. Headless FAST_MVP + exact Rojo artifact + Open Cloud private/restricted publish.
