# 심야 감염전 [4대4] — Game Design / Code Sync

구현 기준: `5bb5500a2d43e0fb32a84c55ac46a61356093796` (main)

과거의 “1몬스터 vs 생존자 얼음/해동” 규칙은 폐기됐다.

## 실제 게임 루프
- 8명 정원, 시작 인간 4 vs 몬스터 4.
- 실제 플레이어가 부족하면 양 팀 빈자리를 AI가 채운다.
- 인간이 잡히면 몬스터로 감염 전환되어 전 인간 팀을 사냥한다.
- 인간은 정화 공격으로 몬스터를 라운드에서 제거한다.
- 인간 0명 = 몬스터 승리 / 몬스터 0명 = 인간 승리 / 240초까지 양팀 생존 = 무승부.
- 학교 / 폐병원 / 폐놀이공원 3맵.

## 인간 확장 구조
인간마다 **고유 도구 + 패시브 + 감염 후 능력**을 가진다.
현재: 방송부 / 전기기사 / 배달부 / 사진가 / 경비원.

## 그래픽 콘셉트
**REALISTIC_HUMANS_ABERRANT_MONSTERS**
- WorldArtPass: `MIDNIGHT_<MAP>_INFECTION_HORROR_V9`
- CharacterArtDirection: `REALISTIC_HUMANS_ABERRANT_MONSTERS`
- 인간은 세 게임 중 가장 현실적인 Roblox 인체 비율.
- 몬스터는 큰 어깨·긴 발톱·두건·낫·비정상 머리/주둥이 같은 과장된 공포 실루엣.
- 몬스터는 색만 바꾸지 않고 체형 자체를 다르게 한다.
- 화면은 어둡되 동선과 적 실루엣이 읽혀야 한다.
- 학교 전체를 한 장의 거대한 지붕으로 덮지 않는다.
- 포근섬 치비 비율과 RPG 영웅 갑옷 골격 재사용 금지.
