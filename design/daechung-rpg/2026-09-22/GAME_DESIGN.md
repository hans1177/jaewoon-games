# 5포탈 RPG: 던전 파티 — Game Design / Code Sync

구현 작업: PR #2741 `assistant/daechung-class-visual-ai`  
공개 배포 상태는 변경하지 않는다. 이 문서는 현재 내부 구현 계약이다.

## 핵심 방향

이 게임의 성장 우선순위는 **직업/보스동료 조합 > 플레이 실력 > 아이템**이다.

- 시작 직업 4개: 파쇄기사 / 그림자추적자 / 룬술사 / 영혼소환사
- Lv.15: 1차 전직, 각 시작 직업당 2분기
- Lv.40: 각 1차 분기가 고유 2차 완성형으로 승급. 2차에서 추가 분기 없음
- Lv.60: 만렙
- Lv.60 이후 XP: 전투력 증가 없는 직업 숙련으로 전환
- 장비 슬롯: **무기 1 + 방어구 1 + 유물 1**
- 무기/방어구는 T1~T5의 완만한 성장
- 복잡한 세트/문장/동료 전용 장비는 사용하지 않음

## 보스 동료 시스템

별도 인간형 AI 캐릭터 로스터를 계속 만드는 대신 **보스를 잡아 그 보스를 AI 동료로 영입**한다.

### 획득

영입 가능한 보스를 **처음 격파하면 해당 보스 동료를 확정 해금**한다.  
같은 RoomCode/같은 전투 지역에서 보스 처치에 참여한 플레이어도 해금을 받는다.

현재 영입 대상:

1. 금빛 큰뿔 — 돌진·균형파괴
2. 백색 송곳니 — 추적·마무리
3. 고목의 심장 — 속박·보호
4. 유적 수호자 — 방벽·균형
5. 심연 군주 — 압박·처형

해금 상태는 DataStore에 저장한다.

### 파티

- 플레이어 1명 + AI 보스 동료 최대 3명
- 마을의 보스 동료 로스터에서 두 번 터치해 편성/제외
- 동료는 리더의 현재 레벨에 자동 동기화
- 동료 자체 레벨업/장비 파밍 없음
- 각 동료는 **기본 공격 1개 + 고유 스킬 1개 + 특성 1개**

즉, 새 캐릭터 육성 노가다가 아니라 **어떤 보스 3명을 데려가느냐**가 파티 조합의 핵심이다.

## 현재 동료 전투 역할

- **금빛 큰뿔**: 고유 스킬로 큰 균형 피해
- **백색 송곳니**: 체력이 낮은 적 마무리 강화
- **고목의 심장**: 속박/짧은 회복 지원
- **유적 수호자**: 리더 가드 회복 + 균형 보조
- **심연 군주**: 균형이 무너진 적 처형 강화

보스 동료 외형은 원본 보스의 실루엣·색·핵심 장식을 그대로 사용한다. 별도 인간형 캐릭터로 다시 디자인하지 않는다.

## 플레이어 전직

### Lv.15 1차 전직

- 파쇄기사 → 철벽파쇄자 / 광전파쇄자
- 그림자추적자 → 암살추적자 / 환영추적자
- 룬술사 → 원소룬술사 / 폭주룬술사
- 영혼소환사 → 수호영매사 / 망령지배자

### Lv.40 2차 완성형

- 철벽파쇄자 → 성채파쇄자
- 광전파쇄자 → 혈철파괴자
- 암살추적자 → 야습추적자
- 환영추적자 → 환영지배자
- 원소룬술사 → 원초룬술사
- 폭주룬술사 → 폭풍룬술사
- 수호영매사 → 선조수호자
- 망령지배자 → 영혼군주

## 아이템 구조

장착은 세 칸만 사용한다.

- **무기**: 기본 공격 성능/간단한 공격 성향
- **방어구**: 최대 HP·가드·회피 등 생존 보조
- **유물**: 직업 특성을 가볍게 변형

아이템이 직업/동료 조합을 압도하지 않도록 수치 상승은 완만하게 유지한다.

## 현재 포탈/전투 구현

- 현재 런타임은 5개 포탈 지역을 유지
- 1번 초원은 Seed 기반 자동변형 런
- 초원 기본 몬스터 10종
- 히든 보스: 백색 송곳니 / 고목의 심장
- 런 보스: 금빛 큰뿔
- 일반/정예 전투 몬스터를 모두 처치해야 금빛 큰뿔 봉인 해제
- 전투: 공격 / 스킬 / 홀드 막기 / 완벽 패링 / 회피
- 서버 권위 가드·패링·균형·가드브레이크
- 파티 사냥 15킬/기여도 보상
- RoomCode 1~10 멀티 상태 유지

포탈 역할/개수의 추가 재구성은 별도 확정 구현으로 다룬다. 현재 이 변경에서는 포탈 공개 상태를 바꾸지 않는다.
