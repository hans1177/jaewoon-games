# 5포탈 RPG: 던전 파티 — Game Design / Code Sync

구현 작업: PR #2741 `assistant/daechung-class-visual-ai`

과거의 “스토리 동료 수집형 4인 고정 파티” 문서는 현재 Roblox 구현 계약이 아니다.

## 실제 게임 루프
마을 준비 → 시작 직업 선택 → 5개 포탈 사냥터 → 퀘스트/장비 성장 → AI 유저 파티 → Lv.15 전직 시험/1차 전직 → 15마리 파티 사냥 → 보스.

- 5개 포탈 지역, 3·5지역 보스
- 마을 귀환 풀회복, 전투 중 귀환 금지
- 레벨업 최대체력 +10 / 공격력 +10
- 무기 5티어 / 방어구 5티어
- 시작 직업 4개: 파쇄기사 / 그림자추적자 / 룬술사 / 영혼소환사
- 1차 전직 8개: 각 시작 직업당 A/B 2분기, Lv.15 직업 시험 후 선택
- 마을 전직소에서 골드로 A/B 재전직 가능
- AI 유저 10명: 파쇄기사3 / 그림자추적자3 / 룬술사2 / 영혼소환사2
- AI는 R15 Humanoid + PathfindingService로 일반 유저처럼 걷고 달리고 직업별 위치를 잡는다
- 플레이어와 AI 모두 R15 액션 애니메이션, 무기 Trail, 타격 VFX 사용
- AI 더블클릭 파티 초대/제외
- 파티 사냥 15킬, 기여도별 XP/골드
- 전투: 공격 / 스킬 / 홀드 막기 / 완벽 패링 / 회피. 가드 게이지·가드 브레이크·몬스터 균형 게이지 사용
- 완벽 패링은 서버 판정 + 재무장 지연으로 막기 연타 악용을 방지
- 1번 초원 포탈은 Seed 기반 자동변형 런: START/COMBAT/EVENT/ELITE/TREASURE/EXIT 방과 연결 경로를 매 런 재조합
- 초원 기본 몬스터 10종: 초원 늑대 / 검은갈기 늑대 / 돌진 멧돼지 / 가시벌 / 숲도마뱀 / 뿔사슴 / 덩굴괴물 / 초원 도적 / 늑대 조련사 / 이끼등 거북
- 초원 히든 장소: 비밀 숲·룬석. 히든 보스: 백색 송곳니 / 고목의 심장
- 초원 런 보스: 금빛 큰뿔. 황금뿔 돌진(패링 가능) / 대지 짓밟기(막기·패링 불가) / 삼연속 돌진
- 히든 보스는 다중 공격 패턴, 패링 가능 기술과 패링 불가 기술을 혼합
- 현재 자동변형 프로토타입은 1번 초원만 적용. 2~5포탈과 전체 50종+ 몬스터 확장은 후속

## 캐릭터/그래픽 콘셉트
**RPG_STYLIZED_TOY_DARK_FANTASY**

- WorldArtPass: `RPG_FANTASY_PORTAL_WORLD_V5`
- CharacterArtDirection: `RPG_STYLIZED_TOY_FANTASY_R15`
- Roblox R15 감각을 유지한 장난감·피규어풍 스타일라이즈드 판타지.
- 현실적인 성인 기사 체형이 아니라 머리·손·무기·장비 실루엣을 조금 과장한다.
- 캐릭터와 마을은 초반에 밝고 친근하며, 포탈을 지날수록 배경이 어둡고 신비로워진다.
- 무료 미디블 갑옷/집 에셋을 원본 그대로 쓰지 않고 스크립트 제거 후 색·재질·부품·배치를 변형한다.
- 플레이어와 AI가 같은 직업/전직 장비 언어를 사용해 AI가 다른 유저처럼 보이게 한다.
- 초원 늑대 / 협곡 도적 / 룬 골렘 / 설원 야수 / 심연 기사는 지역별 체형을 다르게 한다.
- 보스는 일반 몹 단순 확대 금지.
