# 대충 RPG / Whatever RPG — Game Design

스토리로 동료를 모으고 항상 4인 파티를 구성해 직접 싸우는 동료 수집형 3D 액션 RPG.

핵심: 4인 고정 파티, AI 동료, 숙명관계, 파티기억, 보스/히든동료, 장비가 AI 행동 변경, 이탈/배신/복귀, 숨은 5번째 지원 존재, 라이벌 AI 파티.

시작 직업: 파쇄기사 / 그림자추적자 / 룬술사 / 영혼소환사.

MVP 동료: 카일 / 세라 / 이리스 / 노아 / 심연의 간수 / 무명의 동료.

금지: 주사위 중심, 자동전투 대체, 희귀=상위호환, 8비트/도트 BGM 중심.

출시: Studio 미사용. Headless FAST_MVP + exact Rojo artifact + Open Cloud private/restricted publish.
