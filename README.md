# 재운게임즈

재운게임즈의 웹게임, Godot 프로젝트, Unity 모바일 게임 원본과 재운컴퍼니 개발 시스템을 관리하는 저장소입니다.

## 표준 구조
- `web-games/`: HTML/CSS/JavaScript 웹게임
- `godot-games/`: 기존 Godot 원본 프로젝트
- `unity-games/`: Unity 모바일 게임 원본 프로젝트
- `builds/`: 기존 Godot/Web Export 결과물
- `assets/`: 공용 런타임/개발 시스템/에셋
- `tools/`: 로컬 개발·Unity 연동 도구

## 재운컴퍼니 개발 플로우

본개발 전 기획·스토리·콘티·기술 스파이크·플레이어블 초안·내부평가·사용자 승인 과정을 거친다.
제안은 총괄→부서와 부서→총괄 양방향이며, 큰 방향 변경은 사용자 승인 없이 실행하지 않는다.

- 설계 문서: `COMPANY_FLOW.md`
- 실행 계약: `assets/vibe-company-development-flow.js`

상세 규칙은 `COMPANY_FLOW.md`, `STRUCTURE.md`, `GAME_RULES.md`, `ASSET_RULES.md`, `LICENSES.md`, `DEPLOY.md`를 기준으로 합니다.
