# 생존2 유니티 버전

기존 웹버전은 유지하고, 캐릭터/애니메이션/동료 AI/전투를 유니티 2D 아이소메트릭으로 옮기는 작업용 프로젝트야.

기준: Unity 2022.3 LTS, WebGL 빌드 예정.

캐릭터 원본 기준: 2DPIXX Warrior (CC-BY 3.0), 128x160 프레임, 4방향, Idle/Walk/Attack.

원본 에셋 페이지: https://opengameart.org/content/warrior-animated-character-isometric

웹버전과 저장 데이터 규칙은 유지한다. 자동저장은 날짜가 넘어갈 때만 실행한다.
