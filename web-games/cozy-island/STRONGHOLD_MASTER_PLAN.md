> 이 문서는 **지속 개발의 작업 원본**이다. 체크 표시는 실제 main에 반영·공개·검증된 항목에만 붙인다. 일반 개발 큐 및 자동 파이프라인은 오너 한방패치 이후 최신 main을 바탕으로 다시 진행한다. 오너의 게임 개발중지 지시가 있으면 격리 정책을 우선한다.

## 0. 반드시 지킬 게임 정의
- 플레이어 아바타·조이스틱·집 꾸미기·대화/수동 물주기·직접 낚시·반복 탭 수확 등 생활 타이쿤 기능은 기본 전략 UI에서 제거한다.
- **마을회관(성채/keep) HP = 0이면 해당 영주 즉시 패배**. 다른 건물이 남아도 결과를 뒤집지 않는다.
- 자동 2분 몬스터 습격 제거: **적 영주가 경제·병력·전술 상태로 판단한 출병만 유효**. 내 부대는 적 성/마을을 직접 공격한다.
- 경제·건설·군사·적 AI·승패/정찰/운송은 같은 영지 월드 좌표와 영속 저장을 공유한다.
- 모바일 우선: 건설 카테고리 > 상세 카드(비용/일꾼/생산/레벨) > 유령 배치 > 확정/취소, 성벽은 연속 배치. 유닛은 집결/이동/공격/경계/퇴각으로 조작.
- 기본 벌목장·채석장·창고·주민 제공, 초기 목재·석재 부족으로 진행이 막히지 않도록 자동 경제부터 가동.
- 모든 신규 그래픽은 리포지토리 기존 자산/직접 만든 메시를 사용하고 외부 자산은 원본·라이선스·SHA 기록 확인 후 추가한다.

### 경제 시뮬레이션
- 건물마다 노동력 수요/생산 주기/투입 재료/최대 창고량/3단계 강화 값을 가진다.
- 주민 오두막→일꾼 증가; 건물 가동 전 자동 배치; 노동력 부족 시 생산 감소 표시. (노비 개별 구매/급식 사망 루프 폐지.)
- 물자 이동은 수레/일꾼 경로를 시각화하고 이동 거리에 따른 운송 지연을 반영한다.
- 식량 배급(절약/보통/풍족), 세금(낮음/보통/높음) → 금화·주민 만족도·생산성에 영향. 식량 부족·과세에 의한 이탈/파업.
- 거래소 자동 구매/매도는 품목별 한계가격·수량 정책으로 설정, 실시간 무역 가격 반영.
- 모든 자원/건물/정책은 세이브 재진입 시 유지. 기존 세이브는 누락 키만 보충하고 자원·진행도를 삭제하지 않는다.

## 2. 맵 및 세력
- 큰 연결형 등각 3D 맵(강·숲·산·평야·협곡), 카메라 드래그·줌·맵 위치 선택.
- 내 중심 성과 중립 마을, 서로 다른 위치·경제·방어 구성을 가진 **적 영주 3명 이상**.
- 적 마을/자원 기지 점령 시 보급 경로와 자원 거점 확보. **영주 마을회관 파괴 시 해당 영주 패배.**
- 적 영주 유형: 돌격형(철혈), 방어형(석벽), 상업형(황금), 화염형(화염), 후기 대군형(제국).
- 실시간 정찰/전쟁 안개와 이전 정찰 정보 표시. 고지대 사거리 보너스, 숲 은폐, 협곡 진형 제한.
- AI도 같은 비용/노동력/생산/징병/건설 규칙 사용, 적은 위협도·자원·방어 상태로 공격/수비/퇴각.

## 3. 전투 및 승패
- 성벽 연속 건축/모서리/성문 자동 접합, 연결된 걸어갈 수 있는 성벽, 수비 병력 배치.
- 부대 선택·집결·이동·공격·위치 사수·전술 진형·후퇴, 숫자 단축 그룹, 모바일 전술 패널.
- 검병·창병·궁수·석궁병·기사·공병·공성추·투석기·공성탑 등 역할/상성.

## 5. 구현 증거·배포 운영
- **오너 한방패치**: 실제 게임 기능 수정 → main 자동 병합 → 기존 `.github/workflows/magic-forest-pages.yml`로 **즉시 공개 배포** → 링크 안내 → GitHub Actions/Playwright **배포 후** 검증. 유료 브라우저 사용 금지.
- 정상 배포와 게임 동작 확인을 구분한다. 공개 소스 커밋/배포 잡/브라우저 조작·저장 실측이 없으면 검증 완료를 선언하지 않는다.

- 기존 렌더링 모델/경제·방어 모듈을 계속 사용하며 별도 사이트·새 배포 파이프라인을 만들지 않는다.

- 후속 확장 아이디어: 성문 개폐 상태에 따른 AI 아군·적군 서로 다른 통과, 운송 카트의 실제 경로 시각화, 성벽 모서리 자동 모델 교체, 선배치 전체 자원 예약, 드래그 자동 반복 건설, 마지막 건설 일괄 되돌리기(부분 취소/환불), 부대의 실제 월드 전술 명령 공유, 동맹 영주와 공성 지원, 검증된 룸/세이브 권한을 갖춘 서버 기반 전맵 멀티플레이.
- 완료 검증 기준: 코드·main 배포·모바일 터치/저장·성문 인부 경로/드래그 배치·적성 분리의 **실제 공개 브라우저 재현 결과**가 있어야 완료로 표기한다. 배포 성공이 기능 검증 성공을 의미하지 않는다.

## 2026-10-25 인부 통행 후속 수정
- 기존 인부 그래픽은 성채 내부에서 같은 원을 도는 위장 애니메이션이었다. 이를 삭제하고 `findWorkerRoute()` BFS를 이용한 창고↔실제 생산시설 간 **왕복 이동 그래픽**으로 바꾸었다. 이동로는 성문을 통과하고 성벽/닫힌 성문을 우회한다.
- 경로 캐시는 성벽·성문·개폐 상태 변화에 따라 무효화된다. 건설 시 길 단절 검사를 통과하지 않는 구조는 거부된다.
- 기존 무료 GitHub Actions의 배포 후 Playwright QA에 연속성벽 90격자, 성문 자동 방향, 경로 우회 및 자재창고 차단 방지 검사 추가. 실제 라이브 검증 결과가 나오기 전에는 완료 판정을 보류한다.
