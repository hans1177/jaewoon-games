# 푸른 항로 · 다섯 바다의 약속

2026-10-25 오너 요청에 따라 순수 웹게임의 표현을 픽셀 항해와 실사풍 초상화로 개편한다. 유니티 전환이나 기존 3D 표현 복귀를 이번 요청의 후속 단계로 간주하지 않는다.

## 1차 범위

- 유럽 13개 항구의 실제 위치·해안선, 국가 위치 참고선, 확대 축척, 미개척 해역과 미니맵.
- 유럽·중동·아프리카·인도·동아시아 출신의 독자 주인공 5명. 출신지는 도입 이야기이며 본편은 서로 다른 유럽 항구에서 시작한다. 다른 대륙의 상세 플레이는 이번 범위가 아니다.
- 항구 마을의 교역소·조선소·선술집·왕궁·탐험가 사무실·길드를 클릭하면 화면이 전환된다.
- 교역품 13종, 특산품·실제 현재 시세 기반 소문, 보물 수색 3종, 유적 6종과 발견 보고, 직업 5종.
- 주인공별 3장 이야기, 동료 5명의 2회 대화와 영입 조건, 성장 및 항해사·돛 담당·포술장·보급장·의무관 배치.
- 범용 기함 4종과 6개 지역 특수선, 기존 돛·함포·호위함 개선과 장갑·적재실·타륜·선체의 단계별 개조, 소모품 5종.
- 함포 4등급의 위력·사거리·장전·탄속, 실제 포문 수 표시와 포격 섬광·연기·폭발·피해 숫자·독립 효과음.
- 유적 입구의 최대 4인 턴제 육지 전투, 픽셀 일행·늑대·멧돼지·약탈자, 10인 고유 특기, 공격·방어·약품·비상 식량·망원경 관측·퇴각. 전투 단계와 체력·집중도 저장한다.
- 해적·사략선·적대국 순찰함과 측면 포격, 국가 동맹·지원 포격·휴전, 항구 투자·7일 배당·방어 지원, 일 단위 인공지능 항구 습격과 통제권 변화.
- 낮밤·날씨, 원작 음원을 복제하지 않는 독자 절차 작곡, 1·2·4배속과 항해 사건 선택.

## 구조와 보존

`engine.mjs`가 항해·교역·전투·탐험·동료·세계·저장을 담당한다. 기존 장면 책임 파일 `ocean3d.mjs`는 이름을 보존하되 `createOceanView`로 픽셀 해도·마을·시설을 그린다. `main.mjs`는 조작·화면·오디오를 연결한다. 새 파이프라인이나 우회 배포를 만들지 않는다.

저장 키 `jg-ocean-voyage-v1`과 버전 1은 유지한다. 추가 필드는 기본값으로 복구하고, 과거 항구 좌표는 새 축척으로 이동한다. 복사 저장에는 손상 검사용 검증값이 있으며 서버 인증·치팅 방지 기능은 아니다. 동맹과 세계 정세는 단일 플레이어의 인공지능 시뮬레이션이다. 실제 다중 접속은 구현하지 않았다.

기존 Kenney GLB·CC0 원본은 보존한다. 새 자산의 출처·생성 프롬프트·해시는 `CC0-ASSETS.md`에 기록한다. Natural Earth 현대 경계는 지리 참고선이며 1590년의 역사 국경을 정확히 재현한다는 뜻이 아니다.

## 배포와 검증

기존 `.github/workflows/magic-forest-pages.yml`을 통해 main을 게시한다. 게임 주소: https://hans1177.github.io/jaewoon-games/web-games/ocean-voyage/

문서의 기능 목록은 전체 품질 검증 통과 선언이 아니다. main 반영·실제 게시 리비전·휴대폰 크기 브라우저와 저장 검증 결과는 각각 확인해야 한다. 후속 자동 개발은 이 픽셀 표현과 유럽 1차 범위, 최신 main 및 오너 지시를 유지한 채 영향을 받는 단계에서 이어간다.
