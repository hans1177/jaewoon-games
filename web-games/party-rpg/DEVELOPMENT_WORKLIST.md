# 파티 RPG — 정통 CRPG 전환 및 사건·인물 중심 스토리 개발 작업표
> 작성: 2026-10-25. 이 문서는 `web-games/party-rpg/` 직접 작업자를 위한 실행 체크리스트다. 완료 표시에는 코드·배포 SHA와 실제 근거를 반드시 남긴다. 마케팅/구상표가 아니라 실행·인수인계 문서다.

## 원칙 및 현재 구조
- **목표:** *필라스 오브 이터니티* 계열의 성인 비율, 저채도·거친 돌/철/가죽/천, 우울한 중세 판타지 배경, 사건·인물 선택이 엮인 대화 중심 CRPG.
- **게임:** 순수 웹 Three.js, `index.html`에 게임·대화·상태·저장, `view.mjs`에 GLB 월드·렌더러. Unity/턴제 전환 금지. 기존 실시간 일시정지 유지.
- **승인 경로:** 현재 `main` 기준 확인 → 기존 함수 직접 수정 → PR/main 병합 → 기존 `.github/workflows/magic-forest-pages.yml` → 실제 공개 주소 검증. 별도 배포 루트·새 작업 큐 금지.
- **보존:** `party-rpg-v1` 저장키, 기존 플레이어/장비/레벨/AI 10명/파티 정원 4명/전투 수치/던전 보상 및 초대 규칙. 신규 `state.story` 필드만 호환 마이그레이션.
- **자산:** `assets/shared/party` CC0 Quaternius 인물·괴물 / Kenney 건축 GLB 및 기존 초상화 사용. 기존 자산을 후처리하는 것과 완전히 새로운 고퀄리티 성인 모델을 교체하는 것은 별개다. 외부 GLB를 들일 경우 라이선스·원본 URL·해시·용량·모바일 로딩 결과를 기록한다.

## 권장 진행 순서
1. **코드 진척 우선**: V01–V07, U01–U02, S01–S06를 같은 소스 기준으로 이어 작성. 실 소스 변경 없이는 완료로 표기하지 말 것.
2. **씬 일관성**: 첫 로딩→캐릭터 생성→서막→마을→초원→첫 인물 대화→첫 사건 파일→던전의 실제 UX가 연속적으로 보이게 할 것.
3. **QA**: 파일 구문 검사/보존 조건 → `main` 병합 → 공식 GitHub Pages 게시 → 실제 플레이 화면·콘솔·저장 검증. 브라우저 접근 불가 시 정확히 *미검증* 표시.
4. **자동 개발 재개**: 신규 파일을 우회 배포 파이프라인에 연결하지 말고 기존 최신 `main` 게임 소스를 다음 단계의 기준으로 사용.

## 알려진 디자인 부채 / 다음 작업자가 놓치면 안 되는 점
- 기존 Quaternius/Kenney GLB의 **기본 형태 자체가 로우폴리 카툰풍**이다. 색·비율·재질 후처리만으로 실사급 Pillars 느낌을 완전히 보장하지 못한다. 상용급 교체 모델은 라이선스 확인 후 기존 `assets/shared/party` 공급 경로에 직접 통합할 것.
- `view.mjs`에서 부가 오브젝트는 **장식 전용**이며 기존 `p.x/y` 이동·충돌·퀘스트 좌표를 건드리지 않는다.
- `state.story`는 선택·방문·동료 대화를 누적 저장한다. 과거 `party-rpg-v1` 저장에 새 필드가 없어도 이전 파일을 읽을 수 있어야 한다.
- 지역 조사 분기는 요새/신전/결말 잠금을 새로 추가해 기존 플레이어를 소프트락하지 않도록 설계할 것.
- 상태를 변경했다고 배포 성공으로 보고하지 말고, 실제 URL의 sourceSha가 해당 커밋을 가리키는지 따로 확인.

## 2026-10-25 직접 패치 인수인계 — 소스 반영 항목
- `view.mjs`: 렌더 노출 하향, 차가운 하늘·안개, 지역별 하늘색, 주변광과 횃불 조명 하향, 지면 그림자 수신, GLB 재질 채도·반짝임 하향, 인간 메시 폭을 좁히고 키 비율을 높였다.
- `index.html`: 화면·캐릭터 로스터·일지 버튼의 회흑색/철색 UI CSS, 5장면 서막(루카의 마지막 근무/미나의 기록 포함), 사건 수첩 6건, 증언 공개 d20 설득 및 보호 선택, 고정된 사건 결과·대화 반응·결말 후폭풍. `state.story.cases`는 이전 저장에서 새 객체로 호환 초기화하고 `party-rpg-v1` 키를 변경하지 않았다.
- 체크: JS 문법 검사 두 파일 통과, 캠페인 데이터·버튼 결속·저장키·기존 실시간 루프·일시정지 경로 존재 확인. 이는 **브라우저 실제 실행이나 렌더 품질 합격 증거가 아니다.**
- **미완료 핵심:** 기본 캐릭터 GLB는 여전히 기존 저폴리 형태로, 완전한 현실적 판금/사슬갑 메시 교체는 하지 않았다. 표면 범프/노멀 제작 및 실제 외부 정통 3D 모델 교체도 미완료. 전투/직업별 애니메이션의 실제 브라우저 확인 미완료.
- 후속 작업자는 V03(사실적인 고품질 인간 GLB 교체), V04(범프·노멀 실제 디테일), V06(사건 현장별 고유 소품), Q02–Q04(실제 브라우저/모바일 QA) 순서로 진행하되 기존 게임 저장/전투/배포 경로를 바꾸지 말 것.
- 모든 항목 완료 표시는 GitHub diff, 배포 `sourceSha`, 브라우저 실행 근거가 확보된 뒤 갱신한다. 소스 반영/배포 성공/브라우저 검증은 서로 다른 상태다.
