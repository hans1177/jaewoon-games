플레이 방법

① 팀의 빈 칸이나 동물을 선택하고 상점에서 구매해. 빈 칸을 선택하지 않으면 맨 뒤에 추가돼.

② 같은 동물끼리 합성하거나 먹이를 줘. 동물을 두 번 선택하면 서로 자리를 바꿀 수 있어.

③ 상점 동물은 고정할 수 있고, 새로고침에는 금화 1개가 필요해.

④ 자동 전투에서 서로의 앞 동물이 동시에 공격해. 8승을 먼저 달성하면 성공, 체력 5개를 잃으면 종료야.

⑤ 모든 진행은 현재 기기의 브라우저에 자동으로 저장돼. 다른 기기나 로블록스판과 공유되지 않아.
