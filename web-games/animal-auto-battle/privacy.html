기기에 저장하는 정보

게임은 실명, 연락처, 로그인 정보를 요청하지 않아. 동물 편성, 라운드, 승리 기록, 도감 정보는 사용자의 기기 안에만 저장되고 개발자에게 전송되지 않아.

네트워크 접속

게임 화면은 GitHub Pages에서 HTTPS로 제공돼. 이때 호스팅 제공자가 IP 주소, 접속 시간, 브라우저 정보 등 웹 요청 정보를 자체 정책에 따라 처리할 수 있어. 게임 소스에는 광고·분석·추적 SDK 및 인앱 결제가 없어.

보관과 삭제

앱 데이터 또는 브라우저 사이트 데이터를 삭제하면 게임 진행 기록이 삭제돼. 별도 서버 백업은 제공하지 않아.
