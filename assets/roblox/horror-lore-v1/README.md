# Horror Escape Room Lore Props v1

현재 Roblox `horror-escape-room`의 실제 Lore 10개와 1:1 대응하는 project-original 3D 원본 팩.

- 학교 4종
- 폐병원 3종
- 폐놀이공원 3종

OBJ + MTL 원본이며 각 Lore ID가 catalog에 고정돼 있다.
100점은 정적 제작 체크 목표이고 Roblox Studio runtime 품질 PASS를 의미하지 않는다.
`productionVerified=false`, `PENDING_STUDIO`를 유지한다.
게임 보상/저장/상호작용 권한은 소유하지 않는다.
