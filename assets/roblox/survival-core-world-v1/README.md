# Survival Core World v1

현재 Roblox `survival`의 `GameConfig.StudioAssets.Families`에서 요구하는 핵심 3D 자산 11개를 실제 OBJ 원본으로 제작한 내부자산 팩.

- 환경: TREE_TRUNK_THICK, TREE_CROWN_ROUND, ROCK_MEDIUM, ROAD_DIRT
- 건축: FOUNDATION_RECT, WALL_SOLID, DOOR_SINGLE, ROOF_GABLE
- 소품: CHEST, CRATE, LAMP

100점은 정적 제작 체크 목표다. Roblox Studio runtime 품질 PASS나 production verified를 뜻하지 않는다.
게임 밸런스/채집량/보상/세이브/네트워크 권한을 소유하지 않는다.
