# Survival Combat Parts v1

현재 Roblox `survival`의 StudioAssets에서 요구하는 모듈식 3D 파츠 9개.

- WEAPON: BLADE_LONG / GUARD_CROSS / GRIP_LONG
- CHARACTER: TORSO_CLOTH / SHOULDER_LIGHT / BACK_CAPE
- CREATURE: HEAD_CANINE / JAW_LONG / CLAW

파츠별로 독립 교체 가능하도록 분리했다.
100점은 정적 제작 체크 목표이며 실제 Roblox rig/animation/runtime PASS를 뜻하지 않는다.
데미지, 공격 범위, 이동, 저장, 네트워크 권한은 소유하지 않는다.
