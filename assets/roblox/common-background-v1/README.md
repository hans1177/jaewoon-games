# Roblox Common Background v1

로딩/메뉴/인트로/챕터 타이틀 등에 재사용하는 회사 공용 배경 팩.

## 14개 프로필

FOREST_DAWN, DEEP_FOREST, SNOW_FIELD, DESERT_DUSK, SWAMP_MIST, CAVE_BLUE, CRYSTAL_CAVERN, COAST_SUNSET, VILLAGE_WARM, CITY_NIGHT, RUINS_MOON, VOLCANIC_GLOW, SKY_ISLAND, HORROR_CORRIDOR.

## 레이어 구조

1. SKY_GRADIENT
2. FAR_SILHOUETTE
3. MID_STRUCTURE
4. NEAR_FOREGROUND
5. FOG_OR_LIGHT
6. LANDMARK

단순 색상 교체만 다른 배경으로 세지 않는다. 형태·깊이·랜드마크·빛/안개 문법이 달라야 한다.

## 응용

좋은 프로필은 게임에 완전히 맞지 않아도 팔레트/조명/안개/랜드마크/레이어 높이/깊이/날씨를 변형해 재사용한다.

실제 3D 월드 지형 권한은 소유하지 않는다. 이 팩은 표현 배경 자산이다.
