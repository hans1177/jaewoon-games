# Roblox Common Background v1

회사 공용 메뉴/로딩/인트로 배경과 월드 시각 프로필.

## 12개 기본 테마

FOREST, SNOW, DESERT, SWAMP, CAVE, COAST, VILLAGE, CITY, RUINS, DUNGEON, MAGICAL_FOREST, HORROR_INTERIOR

## 배경 구성 기준

모든 배경은 최소 전경/중경/배경 3단계 깊이를 갖는다.

1. Macro terrain / skyline
2. Route + landmark
3. Structural midground
4. Vegetation / architecture cluster
5. Functional props
6. Surface breakup
7. Weathering / contact detail
8. Ambient motion
9. Lighting focus

무작위 소품 살포나 안개로 디테일 부족을 숨기는 것을 금지한다. 메뉴에서는 UI를 읽을 수 있는 negative space와 readability shade를 제공한다.

게임별 스타일에 맞게 색·재질·랜드마크·소품·조명·날씨를 변형한다. 낮은 점수 버전도 사용 가능하고 높은 점수 파생본이 준비되면 유효품질 비교 후 교체한다.
