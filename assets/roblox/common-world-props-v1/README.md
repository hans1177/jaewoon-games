# Roblox Common World Props v1

회사 공용 Roblox 월드 소품 비주얼 베이스 8종.

- 표지판
- 나무 울타리
- 벽 횃불
- 나무통
- 벤치
- 테이블
- 시장 가판대
- 돌우물

대상은 현재 Roblox 게임의 마을, 생존 거점, 실내외 허브, 상점, 길 안내, 세트 드레싱이다.
게임별 palette와 scale을 덮어써 스타일을 맞출 수 있다.

밸런스, 가격, 보상, 제작법, 세이브, Remote 권한은 소유하지 않는다.
