# Roblox Common Presentation v1

회사 공용 로딩·메뉴·인트로·컷신·시네마틱 표시 자산.

## 범위

- 자사 브랜드 마크 베이스
- 로딩 화면 / 스피너 / 진행도 / 팁
- 브랜드 스플래시
- 메인 메뉴
- 상단바 / 사이드 내비게이션
- 검색·필터 / breadcrumb / 입력 힌트 바
- 일시정지 / 설정
- 인벤토리 / 캐릭터 / 지도 / 퀘스트 로그 / 도감 전체화면
- letterbox / 자막 / 화자명 / 화자 방향
- 컷신 스킵 표시
- 챕터 / 지역 / 보스 타이틀
- 장면 전환
- 컷신 선택지

## 컷신 문법

간단한 연출부터 시작한다.

- SIMPLE_INTRO
- NPC_DIALOGUE
- BOSS_REVEAL
- REGION_REVEAL
- QUEST_MOMENT
- VICTORY_STINGER
- DEFEAT_STINGER
- STORY_CHOICE

쇼트는 와이드→관계/행동→반응→디테일 순으로 목적이 있어야 한다. 카메라를 움직이는 것 자체를 품질로 세지 않는다.

## 모션·스킬·타격 임팩트

그래픽 연출은 단일 파티클로 끝내지 않는다.

- 모션: 의도→예비동작→중심이동→행동→접촉→후속동작→회복→다음 상태
- 스킬: 아이콘→캐스트→텔레그래프→형태→트레일→충돌→반응→상태→잔류→오디오
- 타격: 예비동작→접촉 포즈→VFX→방향성 반동→표면 반응→잔류→UI/오디오→회복

데미지, 히트박스, 쿨다운, 판정 타이밍, 실제 카메라 권한은 게임 코드가 소유한다.

## 외부 고품질 게임 참고 원칙

원본 UI, 아트, 카메라 쇼트, 애니메이션을 복사하지 않는다. 다음 추상 원리만 내부 스타일로 재저작한다.

- 장면이 복잡해도 자막·화자·핵심 피사체가 묻히지 않게 한다.
- 카메라 흔들림/시네마틱 움직임은 축소 가능한 표현이어야 한다.
- 대화 컷신은 표정·시선·키 차이·소품 가림·클리핑·팝을 반복 검수한다.
- 컷신 페이스는 게임 직전/직후의 플레이 템포와 연결한다.
- 재질·조명·전경/중경/배경 분리로 화면 깊이를 만든다.
- 화려함보다 게임 정보와 피사체 우선순위를 먼저 보존한다.

Studio는 내부 사용·내부감사에 필수 아님. production 승격만 별도 증거를 요구한다.
