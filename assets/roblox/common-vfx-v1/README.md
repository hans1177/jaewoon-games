# Roblox Common VFX v1

회사 공용 Roblox VFX 베이스 총 8종.

- IMPACT_FLASH
- TRAIL_SHORT
- SHAPE_BURST
- DANGER_TELEGRAPH
- HEAL_BURST
- PICKUP_SPARKLE
- LEVEL_UP_BURST
- SHIELD_HIT

외부 텍스처 없이 Roblox 기본 Part / Trail / Tween으로 구성한다.
게임마다 color / accent / scale / duration만 파생해 사용한다.
위험 표시·회복·보상·레벨업·방어 피드백은 표현만 담당하고 실제 판정은 게임 코드가 소유한다.
데미지, 히트박스, 쿨다운, 이동, Remote 권한을 소유하지 않는다.
