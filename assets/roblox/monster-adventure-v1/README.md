# Monster Adventure Roblox internal assets v1

현재 Roblox 게임의 실제 9종 몬스터에 맞춘 project-original 3D source pack이다.

## 대상
- 스타터: 불꽃여우 / 새싹거북 / 물방울수달
- 평원: 풀숲멧돼지 / 밤날개 / 바람새
- 들판: 뿔바위소 / 철갑악어 / 폭풍독수리

## 제작 기준
- 100점 static authoring checklist 목표
- 종별 실루엣/재질/부위 구조 분리
- 스타터 3종 Hero 우선
- 모바일 Roblox용 중간 폴리곤 예산
- OBJ + MTL 실제 원본
- 게임 수치, 데미지, 포획 확률, 세이브, Remote 권한 없음

## 상태
아직 Roblox Studio runtime verification 전이다.
