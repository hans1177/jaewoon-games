# Roblox Common Foliage v1

회사 공용 Roblox 초목/자연 환경 비주얼 베이스 8종.

- 풀 포기
- 둥근 관목
- 고사리 군락
- 야생화 군락
- 나무 그루터기
- 쓰러진 통나무
- 소나무
- 고사목

현재 Roblox 게임의 숲, 마을 외곽, 생존 지역, 모험 맵, 허브 조경에서 재사용하는 환경 밀도 베이스다.
게임별 palette와 scale을 덮어써 스타일을 맞출 수 있고 far/mid/near 품질 단계를 제공한다.

채집량, 드랍, 충돌 판정, 이동 방해, 밸런스, 저장, Remote 권한은 소유하지 않는다.
