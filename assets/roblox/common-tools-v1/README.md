# Roblox Common Tools v1

회사 공용 Roblox 무기/도구 비주얼 베이스 8종.

- 장검
- 창
- 도끼
- 망치
- 곡괭이
- 활
- 지팡이
- 방패

RPG, 생존, 액션, 모험 게임에서 공통 재사용하고 게임별 palette/scale로 스타일을 맞춘다.
VisualGrip Attachment를 제공하지만 공격 판정, 공격력, 공격속도, 채집량, 내구도, 장착 권한은 게임 코드가 소유한다.
