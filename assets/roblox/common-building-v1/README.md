# Roblox Common Building v1

회사 공용 Roblox 건축 모듈 비주얼 베이스 8종.

- 바닥 모듈
- 창문 벽
- 모서리 벽
- 돌 기둥
- 직선 계단
- 아치문
- 평지붕
- 난간

기존 공용화된 foundation/wall/door/gable roof와 겹치지 않는 핵심 빈 모듈을 채운다.
마을, 생존 거점, 던전, 공포 건물, 타이쿤 구조물에서 공통 재사용하고 게임별 palette/scale로 스타일을 맞춘다.

충돌 판정, 건설 비용, 내구도, 제작법, 저장, Remote 권한은 소유하지 않는다.
