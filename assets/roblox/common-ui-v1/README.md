# Roblox Common UI v1

회사 공용 Roblox UI 베이스.

- FRAME_PANEL
- BUTTON_PRIMARY
- BAR_HEALTH

특징:
- 게임마다 theme만 바꿔 재사용
- 모바일 48px 최소 터치 높이
- 패널/버튼/체력바 공통 시각 언어
- 게임 HP/데미지/Remote/저장 권한 없음
- survival 전용이 아니라 모든 Roblox 게임의 공용 베이스

공용 베이스라도 각 게임 스타일에 맞는 파생 설정과 실제 런타임 검증이 필요하다.
현재 `productionVerified=false`, `PENDING_STUDIO`.
