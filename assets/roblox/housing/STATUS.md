# 하우징 작업 초안

2026-09-30 사용자 요청으로 몬스터 100종 작업을 먼저 마무리하느라 보류한 초안이다. main 등록·게임 적용·검증을 하지 않았다.

현재 파일은 54종 건축/가구 카탈로그, 기초 연결·지지력·소유권·재료·보관/복원 코어의 미검수 초안이다. 사막·숲·고딕·설원·해적 항구·마도공학 테마는 배경·가구·장식·아이템까지 함께 쓰도록 설계 중이다.

다음 작업: 실제 모델 생성기, 배경/아이템 테마 팩, 서버 통합과 모바일 배치 UI, 저장 어댑터, 예외/악성 입력/구조 안정성 시험. 코난 엑자일 공식 건축 자료는 시스템 참고이며 그래픽과 데이터는 독자 제작한다.
