# 던전 회사

Unity Web 1차 검증용 던전 운영/방어 게임.

- 방: 경비실 / 함정 공방 / 보물방
- 몬스터: 슬라임 / 고블린 / 해골 전사
- 함정: 가시 / 화살 / 화염
- 자동 침입 웨이브
- 골드 / 악명 / 던전 핵 HP
- 방 확장, 몬스터/함정 강화
- PlayerPrefs 저장
- 모바일 터치용 운영 UI

빌드 메서드:
- Web: `JaewoonGames.DungeonCompany.Editor.DungeonBuild.BuildWeb`
- Android: `JaewoonGames.DungeonCompany.Editor.DungeonBuild.BuildAndroid`
