# 정글 탐험대

정글 깊숙한 곳의 고대 유적과 지하 신전을 탐사하는 Unity 게임이다.

## 전체 진행
1. 정글 입구에서 흔적 3개 조사
2. 마체테 획득 후 강가 통과
3. 독늪에서 해독 허브 2개 조사
4. 해독제 제작
5. 거대나무 숲 흔적 조사
6. 갈고리 획득 후 절벽 통과
7. 고대 유적의 봉인석 3개 조사
8. 지하 신전 진입
9. 신전 수호자 격파
10. 최종 보스 고대 재규어 수호신 격파

## 지역
- 정글 입구
- 강가
- 독늪
- 거대나무 숲
- 절벽 지대
- 고대 유적
- 지하 신전
- 수호신 제단

## 몬스터
- 독개구리
- 재규어
- 거대뱀
- 악어
- 독거미
- 원숭이 무리
- 유적 수호자
- 신전 수호자
- 고대 재규어 수호신

## 장비
- 카메라
- 마체테
- 쌍안경
- 흔적 탐지기
- 포획 덫
- 갈고리
- 마취총
- 해독제

## 입력
- PC: WASD 이동 / Space 공격 / E 조사 / Q 도구
- 모바일: 왼쪽 터치 이동 / 오른쪽 공격·조사·도구 버튼

## 저장
진행도, 조사 수, 장비, 처치 수는 PlayerPrefs로 자동 저장된다.
