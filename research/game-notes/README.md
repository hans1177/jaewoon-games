# 게임 연구노트

각 게임에서 실제로 검증된 제작 지식을 축적한다.

기록 예:

- 어떤 UI 배치가 작은 모바일 화면에서 잘 읽혔는지
- 어느 몬스터 수부터 성능이 떨어졌는지
- 어떤 전투 템포가 더 잘 작동했는지
- 어떤 무료 에셋 세트가 장르와 잘 맞았는지
- 어떤 버그가 반복됐고 어떻게 막았는지
- 어떤 기획을 버렸고 왜 버렸는지

원칙:

1. 근거 없는 추측은 `hypothesis`로 표시한다.
2. 실제 QA/빌드/플레이 근거가 있는 항목만 `verified`로 올린다.
3. 다른 게임에서 재사용하면 원본 노트를 참조한다.
4. 실패도 새로운 원인/해결 패턴을 남겼다면 자산으로 보존한다.
5. 사용자 핵심 결정 권한은 연구노트로 확대되지 않는다.
