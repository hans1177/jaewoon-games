JAEWOON COMPANY PWA

재운컴퍼니 앱 설치

PWA v19

재운컴퍼니 개발 채팅을 휴대폰 홈 화면에 앱처럼 설치해서 사용할 수 있어. 별도 APK를 받는 방식이 아니라 웹앱(PWA) 설치 방식이야.

Chrome으로 열고 설치 재운컴퍼니 앱 열기 재운게임즈 홈페이지

설치 링크

아래 주소를 Chrome 또는 Safari에서 열면 돼.

https://jaewoon-games.pages.dev/install.html

Android · Chrome 설치 방법

  1. 위 Chrome으로 열고 설치를 눌러.
  2. 재운컴퍼니 앱 설치 버튼이 나타나면 눌러.
  3. 버튼이 안 뜨면 Chrome 오른쪽 위 ⋮을 눌러.
  4. 앱 설치 또는 홈 화면에 추가를 선택해.
  5. 설치가 끝나면 홈 화면의 재운컴퍼니 아이콘으로 실행하면 돼.

iPhone · Safari 설치 방법

  1. 설치 링크를 Safari에서 열어.
  2. 하단 또는 상단의 공유 버튼을 눌러.
  3. 홈 화면에 추가를 선택해.
  4. 오른쪽 위 추가를 누르면 설치돼.
설치 안내. Android에서는 Chrome 설치를 권장해. 설치 버튼이 바로 안 나오면 메뉴에서 “앱 설치” 또는 “홈 화면에 추가”를 선택하면 돼.
