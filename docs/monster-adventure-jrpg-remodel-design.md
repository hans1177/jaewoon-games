## 문법 정리
- A 핵심 시스템: 관계 선택. NPC의 신뢰와 평판이 탐험 지역, 지원, 전투 준비를 바꾼다.
- B 핵심 시스템: 지역 탐색. 포획·전투·조사 결과가 NPC 관계, 다음 장면, 경로를 바꾼다.
- C 장르 결합: 주 장르를 몬스터 육성 JRPG로 조정하고 부 장르 추리를 유지한다. 기존 생활·추리 장르 문법과 변경점을 명시한다.
- A→B→A 인과: NPC 선택→지역·적·보상 변화→탐색·전투 결과→관계·대사·해금 변화. 단순 컷신만으로 충족하지 않는다.

## 플레이어 경험
- 시작 시 몬스터를 선택하고 주인공 이름·외형·칭호를 설정한다.
- 첫 탐험, 귀환, 주요 승리, 지역 진입에 대화 장면을 배치하되 대화는 선택에 따른 상태 변화가 있어야 한다.
- 전투는 속도·상성·우선도·명중·치명타를 반영하며 몬스터 포획/육성/도감을 유지한다.
- 선택과 조사 결과는 저장·로드 후에도 유지한다. 기존 저장을 초기화하지 않는다.

## 구현 체크리스트
1. 캐릭터 편집 및 저장 복원.
2. 스토리 이벤트 중복 방지, 안전한 다음/건너뛰기.
3. NPC 선택 분기(신뢰), 탐색 정보(단서), 상호 인과 전투 효과.
4. 모바일 터치 UI 및 접근성, 키보드 조작.
5. HTML/JS 정적 검증, 게임 회귀검사, 실제 브라우저 플레이.

## 보류
- 기존 원본과 JRPG 장르 변경의 최종 정합성은 별도 검증이 필요하다.
- 자동 설계 게이트 통과·디자이너 승인으로 표시하지 않는다.
