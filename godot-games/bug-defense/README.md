# 곤충 디펜스 Godot 실전판

기존 `web-games/bug-defense`를 보존한 상태에서 Godot 출시 방향을 검증하기 위한 고도화판입니다.

## 우선 구현

- 모바일 터치 + 가상 조이스틱
- 캐릭터 그래픽과 이동/공격 모션
- 적 3종 + 보스 그래픽
- 기지 그래픽
- 포탑 그래픽과 자동 공격
- 포탑 4종
- 포탑 강화
- 현상금 사냥
- 함정
- 플레이어 공격 강화
- AI 지원 동료 3명
- 30웨이브
- 기지 HP 300
- 시작 재화 100원
- 자동 저장/복구
- 안전 여백과 화면 크기 대응

## 모바일 조작

왼쪽 아래: 가상 조이스틱 이동

오른쪽 아래: 공격

화면 중앙의 빈 땅을 탭: 선택한 포탑 설치

위쪽: 포탑 종류 선택 / 다음 웨이브 / 현상금 / 함정 / AI 지원 / 상점

## 기존 웹판에서 확인한 기준값

- 기지: 300/300
- 시작 돈: 100원
- 총 웨이브: 30
- 일반 포탑: 50원
- 화살 포탑: 120원
- 치유 포탑: 777원
- 플레이어 공격 강화: 35원
- 포탑 강화: 60원
- 거미함정: 300원
- 개미귀신 함정: 500원
- 현상금: 병정개미 200원 / 나비 350원 / 작은 독거미 500원
- 현상금 재사용 대기: 60초

## 최종 검증 항목

1. 프로젝트가 Godot에서 열리고 `main.tscn`이 실행되는지
2. 휴대폰 터치와 가상 조이스틱이 정상 동작하는지
3. 화면 잘림이나 조작 버튼 겹침이 없는지
4. 캐릭터 이동/공격 모션이 자연스러운지
5. 적 이동/피격/처치가 정상인지
6. 웨이브가 정상 시작되고 30웨이브까지 진행되는지
7. 10웨이브마다 보스가 정상 등장하는지
8. 포탑 설치/공격/강화가 정상인지
9. 함정과 현상금이 정상 작동하는지
10. AI 지원 ON/OFF와 역할별 행동이 정상인지
11. 저장 후 종료하고 다시 실행했을 때 진행도가 복구되는지
12. 기지 파괴와 재시작 흐름이 막히지 않는지

## 주의

이 버전은 최종 사용자 피드백을 받기 위한 실전 검증판입니다. 실제 Android/Windows 출시 빌드 판정은 Godot 에디터 및 실제 기기에서 마지막 검증 후 확정합니다.
