# 심야 감염전 상용 콘텐츠 로드맵

## 1. 운영 원칙

- 초기부터 괴담/귀신 100종을 한 번에 소모하지 않는다.
- 도감은 장기 업데이트형 콘텐츠로 운영한다.
- 실제 플레이 가능한 귀신은 도감과 분리해 천천히 추가한다.
- 도감, 코스메틱, 세레머니, 이스터에그는 경쟁 수치에 영향을 주지 않는다.
- 전투 승리조건은 인간 0명 / 몬스터 0명 / 시간 종료 무승부를 유지한다.
- Studio 실제 플레이 검증은 소스 빌드업 완료 후 별도 최종 단계에서 진행한다.

## 2. 초기 괴담 도감

초기 출시 목표는 12종이다.

- 학교: 5종
- 폐병원: 4종
- 폐놀이공원: 3종

각 괴담은 단순 1회 발견으로 끝내지 않고 3단계 목격 구조를 목표로 한다.

1. 1차 목격: 멀리서 실루엣, 소품, 짧은 이상현상
2. 2차 목격: 가까운 위치에서 다른 연출 또는 흔적
3. 3차 목격: 확실한 괴담 장면과 도감 설명 완성

초기 12종만으로도 최대 36개의 발견 장면을 제공하는 것이 목표다.

## 3. 장기 도감 확장

- 목표 상한은 전 세계 민담/전설/괴담 기반 약 100종.
- 현대 공포영화/게임 캐릭터처럼 권리 문제가 있는 고유 캐릭터는 사용하지 않는다.
- 2~3주마다 3~5종 정도를 추가한다.
- 업데이트마다 기존 맵에도 새 출현 위치 또는 새 목격 단계를 추가한다.
- 한 판에 모든 괴담이 등장하지 않는다.
- 일반 / 이상 / 희귀 / 전설 수준의 출현 희귀도를 둘 수 있다.
- 특정 정전, 맵 이벤트, 구역, 시간대 조건에서만 나오는 괴담을 만든다.
- 주간 목격 대상 3종을 운영해 일부 괴담 출현률을 높일 수 있다.
- 시즌 종료 후 기존 괴담을 삭제하지 않고 출현률만 낮춰 복귀 유저도 수집 가능하게 한다.

## 4. 실제 플레이 가능한 귀신

초기 실제 플레이 몬스터는 기존 5종을 유지한다.

- 드라큘라
- 프랑켄슈타인
- 늑대인간
- 미라
- 사신

도감 귀신은 기본적으로 플레이 불가다.

향후 업데이트에서 완성도가 충분한 귀신만 하나씩 플레이 캐릭터로 승격한다. 한 업데이트에서 0~1종 추가를 기본 속도로 한다.

도감 항목을 추가했다고 자동으로 플레이 캐릭터가 되는 구조는 사용하지 않는다.

## 5. 괴담 계약서

장기 수집 보상은 전투 능력치가 아니라 해금 선택권으로 제공한다.

예정 마일스톤:

- 일정 도감 수집량 달성 시 괴담 계약서 조각 지급
- 조각을 모으면 괴담 계약서 1개 완성
- 계약서는 이미 플레이 가능 업데이트가 완료된 귀신 중 원하는 1종의 영구 해금에 사용
- 아직 플레이 캐릭터가 아닌 귀신은 계약서 대상에 나타나지 않는다
- 나중에 해당 귀신이 플레이 가능으로 승격되면 계약서로 해금 가능

도감 100% 완성 보상은 장기적으로 다음 조합을 목표로 한다.

- 전용 칭호
- 전용 코스메틱
- 전용 승리 세레머니
- 괴담 계약서 또는 특별 플레이 귀신 해금권

## 6. 중복 발견 처리

이미 완성한 괴담을 다시 발견했을 때 완전히 무의미하게 만들지 않는다.

예정 시스템:

- 중복 목격 → 괴담 조각 획득
- 괴담 조각으로 미발견 괴담의 위치 힌트 구매
- 직접 미발견 항목을 즉시 해금하는 방식은 피한다
- 희귀 괴담일수록 위치 힌트 비용을 높일 수 있다

이 시스템 역시 전투 성능과 무관해야 한다.

## 7. 판매 / 수익화 원칙

플레이 성능이 더 강한 귀신을 현금 전용으로 판매하지 않는다.

판매 가능한 요소:

- 플레이 귀신 조기 해금권
- 귀신 스킨
- 등장 연출
- 승리 포즈 / 세레머니
- 로비 칭호
- 프로필 프레임
- 결과 화면 테마
- 기타 순수 코스메틱

기본 플레이 귀신은 무료 플레이로도 획득 가능한 경로를 유지한다.

## 8. 맵 콘텐츠 방향

맵은 단순 전투 공간이 아니라 탐색할수록 작은 사건이 나오는 공간으로 만든다.

### 학교

- 복도 그림자 괴담 몬스터
- 사물함 눈
- 야간 청소부 코믹 등장
- 혼자 굴러가는 체육관 공
- 칠판 농담
- 급식 트레이 이상현상
- 고무오리, 자판기 캔 같은 랜덤 코믹 연출

### 폐병원

- 무인 휠체어
- 움직이는 커튼
- 배터리 1% 모니터
- 오리 엑스레이
- 혼자 움직이는 침대
- 영안실/슬리퍼/링거대 랜덤 연출

### 폐놀이공원

- 고개 돌리는 광대
- 무단결근 매표소
- 쳐다보는 회전목마 말
- HELP 최고점수 아케이드
- 혼자 튀는 팝콘
- 풍선 / 무인 범퍼카 랜덤 연출

모든 놀람/코믹 연출은 충돌, 터치, 레이캐스트, 데미지, 이동, 에너지, 보상, 팀 판정에 영향을 주지 않는다.

## 9. 맵 상호작용

승리조건 퍼즐이 아니라 추격 중 선택지를 늘리는 용도로 사용한다.

- 공통 에너지 단말
- 중앙 에너지 코어
- 학교 비상 방송실
- 병원 수술실 전력장치
- 놀이공원 회전목마 전원

향후 새 맵도 고유 상호작용 1개 이상을 갖는다.

## 10. 열세 패시브

5:3 / 6:2 / 7:1처럼 한 진영이 크게 밀릴 때 직접적인 공격력/속도/사거리 보정을 주지 않는다.

현재 방향:

- 5:3 → 열세팀 에너지 자연 회복 +25%
- 6:2 → +50%, 충전 단말 추가 회복
- 7:1 → +80%, 충전 단말 추가 회복, 마지막 1명 진입 시 일회성 에너지 보너스

인간과 몬스터 양쪽에 대칭 적용한다.

## 11. 결과 세레머니

결과 단계는 약 6초로 유지한다.

인간 승리 예시:
- 단체사진 망함
- 정화기 하이파이브
- 퇴근 성공

몬스터 승리 예시:
- 괴물 출석체크
- 단체 으쓱춤
- 누가 제일 무섭나 포즈

무승부:
- 전원 어색한 박수

한 명은 랜덤으로 박자 틀림, 눈감음 등 코믹 역할을 맡을 수 있다. 결과 세레머니는 승패 확정 이후에만 재생하며 경쟁 수치에 영향을 주지 않는다.

## 현재 직접 구현 단계 — 공간감 / 몬스터 정체성 / 스킬 연출

로드맵의 기존 전투 규칙과 저장 구조는 유지하면서 다음을 실제 게임 소스에 반영한다.

### 맵 공간감
- 학교 실내 천장은 기존보다 높여 복도·교실·체육관이 답답하지 않게 만든다.
- 폐병원 중앙 병동/수술실 천장을 높이되 지하실은 상대적으로 낮게 유지해 구역 대비를 만든다.
- 폐놀이공원은 야외 개방감을 유지하고 귀신의 집·지하 통로의 천장만 높여 이동 가독성을 확보한다.

### 플레이 몬스터 5종
- 드라큘라: 귀족 흡혈귀. 긴 망토, 높은 칼라, 송곳니, 붉은 눈/장식.
- 프랑켄슈타인: 전기 실험체. 머리 볼트, 봉합 흔적, 금속 어깨, 전기 코어.
- 늑대인간: 야성 추격자. 귀/주둥이, 등 털, 꼬리, 발톱.
- 미라: 고대 저주체. 겹겹의 붕대, 늘어진 천 조각, 금빛 저주 장식.
- 사신: 그림자 수확자. 깊은 후드, 검은 얼굴, 보랏빛 눈, 낫.

### 고유 스킬과 이펙트
- 드라큘라 박쥐 돌진: 전방 고속 돌진 + 적색/검은 박쥐 잔상.
- 프랑켄슈타인 괴력 돌진: 강한 전진 충격 + 녹색 전기/충격파.
- 늑대인간 야성 질주: 짧은 고속 추격 + 황색 발톱 잔상.
- 미라 저주의 모래: 주변 생존자 둔화 + 금빛 저주 고리.
- 사신 그림자 이동: 전방 순간 이동 + 보라색 그림자 문.

스킬 이펙트는 판정 수치를 임의 변경하지 않고 서버 권한 스킬 결과를 시각적으로 표현한다.

## 현재 직접 수정 단계 — 월드 로비 공포코믹 리디자인

- 로비 화면은 공포 분위기를 유지하되 NPC 얼굴과 주요 동선이 선명하게 보이도록 조도를 더 올린다.
- 로비 전용 BGM을 전투 BGM과 분리하고 기존 로비 음악을 교체한다.
- 미스터 블랙, 토비, 메리 직원 외형을 서로 완전히 다른 기괴한 체형과 얼굴 실루엣으로 교체한다.
- 프런트 전화기, 고장난 자판기, 우산꽂이, 청소 카트, 분실물 인형, 객실 열쇠, 오래된 라디오 등 내부 소품을 추가한다.
- 소품은 공포코믹 연출과 연결하되 충돌/데미지/보상/팀 판정에는 영향을 주지 않는다.
- 비명 효과음은 다시 넣지 않고 시각 연출, 물체 움직임, 대사와 로비 음악으로 분위기를 만든다.

## 현재 직접 수정 단계 — 실제 대전형 AI / 몬스터 재디자인 / 세레머니 교체

### 대전형 AI
- 몬스터 AI는 한 플레이어에게 전부 몰리지 않고 각자 다른 목표를 고르며 같은 진영끼리 간격을 유지한다.
- 인간 AI는 단순 도주가 아니라 몬스터를 찾아 접근, 거리 조절, 정화 공격, 대시를 사용한다.
- 인간 AI는 방송부/전기기사/배달부/사진가/경비원 중 실제 인간 폼을 하나씩 배정받고 해당 폼의 정화 사거리, 쿨다운, 대시 보정을 사용한다.
- 몬스터 AI도 드라큘라/프랑켄슈타인/늑대인간/미라/사신 고유 스킬을 실제 전투 중 사용한다.
- AI는 서로 겹쳐 한 덩어리로 이동하지 않고 분산/측면 이동을 섞는다.

### 몬스터 재디자인
- 플레이어와 AI 양쪽 모두 5종 몬스터의 실루엣을 멀리서도 구분할 수 있게 세부 외형을 강화한다.
- 각 몬스터 스킬은 해당 캐릭터 콘셉트와 일치하는 서버 판정과 전용 시각 효과를 유지한다.

### 결과 세레머니
- 기존 단순 점프/춤/코믹 박수 세레머니를 제거한다.
- 실제 승리 팀 캐릭터를 보여 주는 3D 결과 연출과 진영별 시네마틱 포즈로 교체한다.
- 인간 승리는 생존/정화 완료 느낌, 몬스터 승리는 사냥 완료 느낌, 무승부는 대치 종료 느낌으로 분리한다.
