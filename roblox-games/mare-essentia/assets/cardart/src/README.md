# 대항해시대 5대륙 전투카드 원화

- 기존 `BoardingCards.luau`의 5대륙 × 30장 = **150장**의 전투 수치·덱·저장 키·ID는 변경하지 않는다. 목표 175장의 추가 25장은 미제작이다.
- **도형으로 그린 저품질 그림은 실물 GIF 통과 처리 금지.** 초안 `eu_24`(스톤헨지), `me_01`(다우선), `me_24`(페트라), `nw_24`(마추픽추), `af_01`(므테페)는 검수 탈락. 정상 원화가 확보되기 전까지 새 프레임 애니메이션 후보로 등록하지 않는다.
- **고품질 재제작 후보 6장**: `eu_03` 갈레온, `ea_02` 거북선, `ea_18` 시베리아호랑이, `me_21` 페르시아표범, `nw_18` 재규어, `af_18` 아프리카 코끼리. 5대륙이 모두 포함되고 함선·동물 분류가 구분된다. 유물·원더 분류 UI는 기존 카드에도 유지한다.
- 후보는 개별 **16프레임 × 80ms** 반복 GIF와 4×4 PNG 프레임 시트(1024×1024, 프레임당 256×256)로 제작했다. 9개 원본 프레임 그림은 16개로 보간했으며, 선체/동물 그림 전체가 프레임마다 바뀌는 **완성 프레임 방식**이다. 60fps 촬영 자료라는 주장은 하지 않는다.
- 로블록스는 GIF 자체를 재생하지 않으므로 기존 `NavalBattle.luau::animateCardArt`가 **실제 등록·승인된** `CardArt/카드ID`를 `ImageLabel.ImageRectOffset`으로 재생한다. 새 렌더 루프·모션 레이어·저장 키는 없다. 카드 화면 비율 0.69, 5대륙별 색상/분류 명패, 터치 확대는 기존 구현을 사용한다.
- 현재 채팅에서 전달한 `mare_motion_6.zip`에는 GIF·시트·해시·검수용 페이지가 담겨 있다. **ZIP 파일은 GitHub 저장소에 업로드되지 않았고 Roblox 자산 ID도 등록되지 않았다.** 원화가 게임에 출력됐거나 60fps 실측에 합격했다고 주장하지 않는다.
- 실제 Roblox 이미지 업로드 시 기존 `tools/mare-essentia-upload-assets.mjs`의 승인 해시·체험 권한 검사·스튜디오 실기기/화면 QA를 반드시 통과해야 한다. 인증 없는 도형/지도 원화 자동 대체 및 유료 서비스 사용은 금지한다.
