# 대항해시대 지역별 카드 원화

- `eu_01`~`af_30` 지역 카드 150장의 정적 SVG 원본은 기존 그대로 보존한다.
- **갈레온 `eu_03`는 SVG 레이어 모션을 사용하지 않는다.** 요청한 퀜트형 모션은 16프레임(한 장당 80ms) 반복 GIF 원화와 4×4 PNG 프레임 시트를 사용한다.
- GIF는 실제 반복 재생 파일이며, Roblox는 GIF를 직접 재생하지 않으므로 `NavalBattle.luau::animateCardArt`에서 **기존 단일 ImageLabel의 ImageRectOffset**을 80ms 간격으로 바꾼다. 개별 선체/돛/파도 UI 레이어, 새 렌더 루프, 새 저장 키는 없다.
- 프레임 시트: `eu_03.png` (1024×768, 256×192 × 16프레임). Roblox `CardArt/eu_03` 이미지 자산은 아직 미등록이며, 등록 승인 후에만 기존 전투화면의 카드에서 작동한다. 미등록 상태에서는 기존 해역 도판과 기존 전투 로직을 유지한다.
- 원본 GIF 제작과 코드 결합은 별도다. Roblox Studio 실제 화면·프레임·등록 권한·배포 검증 전에는 완료로 표시하지 않는다.
- 규칙·전투력·카드 수·덱 제한·저장 구조는 변경하지 않는다.
