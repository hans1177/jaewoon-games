# 대항해시대 5대륙 전투카드 원화

- 기존 지역별 카드 150장의 정적 SVG 소스와 카드 능력치는 유지한다. **175장 전체는 미제작**이며, 추가 25장 규칙은 변경하지 않는다.
- 1차 실물 제작 **10장**: 유럽 `eu_03` 갈레온(함선), `eu_24` 스톤헨지(원더); 동아시아 `ea_02` 거북선(함선), `ea_18` 시베리아호랑이(동물); 중동 `me_01` 아라비아 다우선(함선), `me_24` 페트라(원더); 신대륙 `nw_18` 재규어(동물), `nw_24` 마추픽추(원더); 아프리카 `af_01` 스와힐리 므테페(함선), `af_18` 아프리카 코끼리(동물).
- 각 원화는 **주인공 오브젝트 하나**, 세로형 **가로/세로 비율 0.69**, 실제 16프레임×80ms 무한반복 GIF다. 손패/전장 카드별 덱 컬러와 함선·동물·원더·유물 분류 배지는 `NavalBattle.luau`의 기존 화면에서 표시한다. 손패와 전장 카드는 터치 확대를 지원한다.
- Roblox는 GIF 파일 자체를 재생하지 못한다. 카드 원본에서 그림부만 추출한 **4×4 정사각 PNG 스프라이트 시트(1024×1024, 한 프레임 256×256)**를 `CardArt/카드ID`로 승인·등록한 경우에만 기존 `animateCardArt`가 `ImageRectOffset`을 80ms마다 바꾼다. 선체·돛·파도 등의 독립 모션 레이어/새 렌더 루프·새 저장 키는 없다.
- **원화 파일은 현재 대화의 ZIP 제작 결과에 보관했고, 깃허브에는 바이너리 원화를 업로드하지 않았다.** 따라서 Roblox 자산 ID 등록과 권한 확인, Studio 실기기 카드 표시·성능 검증, 배포가 남았다. 현재 게임에서 실물 GIF가 재생된 것으로 간주하면 안 된다.
- 원화가 등록되지 않은 카드는 기존 지도/해역 도판과 기존 전투/저장 동작을 유지한다. 판매·유료 서비스·새 자동개발 경로는 사용하지 않는다.
