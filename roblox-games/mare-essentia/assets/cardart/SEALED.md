# 봉인된 카드 그림 (연결·업로드 금지)

목록과 이유는 `SEALED.json`. 이 id들은 `APPROVED_IMAGES.json`에 올리지 않는다(업로드 도구도 거부).
교체할 그림을 찾으면 파일을 바꾸고, 눈으로 확인한 뒤 SEALED.json에서 빼서 승인한다.

## ★ 최우선 규칙: 지식 카드 784장 그림은 ChatGPT가 직접 제작한다
- 지식 카드(784장)의 그림은 **ChatGPT가 직접 만든 것만** 사용한다. (사용자가 제공)
- **바이브(자동 에이전트·자동 수집·자동 생성)는 지식 카드 그림을 만들거나 수집하거나 교체하지 않는다.** 위키 자동 수집, 스케치 변환, AI 자동 생성 모두 금지.
- 바이브가 할 수 있는 일: 제공된 그림을 확인(검수)하고 승인 목록에 올리는 것, 연결 코드 작성, 문제 있는 그림을 봉인하고 사유를 기록하는 것까지만.
- 부족한 카드는 "ChatGPT 제작 필요" 목록에만 올린다. 임시 그림으로 채우지 않는다.

## 카드 1장 제작 방식 (ChatGPT 제작 → 검수 → 등록)
카드 1장마다 아래 순서와 산출물을 지킨다.
1. **원화**: 고화질 원본 1장. 카드 이름과 그림이 맞아야 한다. 맞지 않으면 **제외**하고 이유를 적는다.
2. **24프레임 모션**: 원화로 만든 최고 품질 모션(돛·깃발·선체·파도처럼 카드에 맞는 움직임).
3. **16프레임 게임용 파일**: 24프레임을 줄여 현재 게임 형식에 맞춘 파일.
   - **권장 규격**: 16프레임, 초당 10프레임(루프 약 1.6초), 처음과 끝 프레임이 이어지는 **무한 반복**. 스프라이트 시트 4×4(최대 1024×1024). 움직임은 작고 부드럽게(돛·깃발 흔들림, 파도 일렁임). 카드 주제와 무관한 흔들림·화면 전체 확대는 금지.
   - **24프레임 원본**: 초당 12~24프레임, 편집·재가공용으로 보관만 한다(게임에는 넣지 않는다).
   - **정지 원화**는 항상 따로 둔다(강화 1단계 이하·로딩 중에 보여 줌).
4. **기존 원본 보존**: 이미 있던 파일은 덮어쓰거나 지우지 않는다.
5. **파일 검증**: 규격·손상 검사를 통과해야 한다.
6. **품질 등급을 따로 적는다**: 단일 원화에 부분 변형만 한 모션은 "후보"다. 궨트급 최종 품질은 사람이 승인해야 "최종"이 된다.
7. **GitHub 등록은 승인 후**: 후보 상태에서는 등록(`APPROVED_IMAGES.json`)하지 않는다. 등록 수는 진행표에 따로 센다.
8. **진행표**: 제작 수 / 전체 수 / 남은 수 / 등록 수 / 제외 수를 같이 보고한다. (예: 55/175장, 남은 120장, 등록 0장)

## 앞으로 카드 그림 제작 규칙
1. **현대 인물 사진 금지**: 가수·모델·일반인 사진, 에어컨·사무실 같은 현대 배경, 얼굴이 크게 나온 현대 사진은 쓰지 않는다. (실존 인물 초상은 사용자가 따로 제공)
2. **누드·선정적 그림 금지**: 고전 명화 속 나체도 안 된다. (Roblox 계정 제재 이력)
3. **카드 내용과 맞는지 확인**: 위키 대표 이미지를 그대로 믿지 말 것(범고래↔이명법 사례). 이름·시대·주제가 일치해야 한다.
4. 1517년 세계관에 어울리는 고지도·판화·삽화·유적·자연물 위주로 고른다.
5. 사람이 눈으로 확인한 것만 `APPROVED_IMAGES.json`에 올린다.
