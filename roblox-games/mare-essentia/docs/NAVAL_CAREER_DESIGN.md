# 해군 경력·작위·영지·대규모 해전 설계안

> 목표: "해적배 잡기"에서 끝나던 전투를 **국가 전쟁 참전 → 승진 → 작위 → 영지·저택 → 제독**까지 이어지는 한 줄기 성장으로 만든다.
> 연도·명칭은 대략적인 역사 기준이다. 구현 전에 항목별로 사람이 한 번 확인한다(`docs/RULES.md` 규칙).

## 1. 큰 그림 (한 줄 흐름)

```
전투 경험치(전투 경력) + 명성 + 사관학교 퀘스트
        │ 1년에 1번 "왕실 퀘스트" 완수
        ▼
   승진(계급) ──▶ 작위 하사 ──▶ 영지(농지·땅) 하사 ──▶ 그 항구에 집 건설 ──▶ 저택·사령부 …
        ▲                                                     │
        └──── 참전(국가 전쟁) · 사략 · 호송 · 봉쇄 퀘스트 ◀────┘
```

세 가지 축을 따로 둔다. 서로 영향을 주지만 하나가 막혀도 다른 축은 오른다.

| 축 | 오르는 법 | 막는 법 |
|---|---|---|
| 계급(군 직위) | 전투 경험치, 사관학교 퀘스트, 전쟁 참전 | 연 1회 승진 심사 |
| 작위(신분) | 명성, 왕실 퀘스트 | 국적(그 나라 명성) |
| 영지(재산) | 작위에 딸려 하사 | 땅을 받은 항구 한 곳에만 건설 |

## 2. 나라·문화권별 사다리 (역사 기반)

작위는 유럽식만 있는 게 아니다. **그 문화권이 실제로 쓰던 이름과 보상 방식**을 쓴다. 명성 기준값은 예시이며 `Ranks.luau` 표로 조정한다.

| 문화권 | 군 직위(하→상) | 작위·신분 | 땅을 받는 방식 | 사관학교(발전 단계) |
|---|---|---|---|---|
| 영국 | 사관후보생 → 소위 → 중위 → 함장 → 전대장 → 소장 → 중장 → 제독 | 기사(Knight) → 준남작 → 남작 → 자작 → 백작 | 장원(manor) | 항해 수학교 → 왕립 해군 아카데미(1733 포츠머스) → 왕립 해군대학(1806) |
| 스페인 | 알페레스 → 중위 → 함장(Capitán de navío) → 함대 사령관 | 이달고 → 기사(Caballero) → 백작 → 후작 | 엔코미엔다·아시엔다 | 세비야 통상원 도선사 시험(1503) → 근위 해군생도 중대(카디스 1717) |
| 프랑스 | 해군생도 → 소위 → 중위 → 함장 → 전대장 → 부제독 | 슈발리에 → 남작 → 백작 → 후작 | 영지(seigneurie) | 해군생도 중대(1670) → 해군 사관학교 |
| 네덜란드 | 함장 → 소장(Schout-bij-nacht) → 부제독 → 총제독 | 시민 귀족(작위 약함, 부와 명예 중심) | 상업 이권·해군성(Admiralty) 자리 | 항해 학교(암스테르담) → 해군성 사관 과정 |
| 포르투갈 | 선장 → 대선장(Capitão-mor) → 제독 | 이달고 → 그리스도 기사단 기사(Comendador) → 백작 | **카피타니아(식민지 영지)** | 사그레스식 항해 공방 → 왕립 해군생도 학교(1782) |
| 오스만 | 레이스(선장) → 베이 → 파샤 → 카푸단 파샤(대제독) | 베이 → 파샤 | **티마르(군공 토지)** | 조선소(Tersane) 도제 → 해군 공학교(1773) → 해군사관학교(1838) |
| 명·청(중국) | 수비 → 참장 → 부장 → 총병 → 수군 제독 | 군공 작위는 드묾(관직 중심) | 둔전·봉록 | 위소(衛所) 수군 훈련 → 복건선정학당(1866) |
| 일본 | 아시가루 → 사무라이 → 수군 대장 → 후나테 부교 | 사무라이 신분 | 영지(료치) 석고 | 수군(스이군) 도장 → 나가사키 해군전습소(1855) |
| 조선 | 만호 → 첨사 → 수군절도사 → 삼도수군통제사 | 무반 관직 | 둔전(군 농지) | 수영(水營) 훈련 |
| 인도·아라비아 | 나이크(선장) → 사르켈(수군 대장) → 제독 | 만사브 등급(무갈) 또는 술탄의 샤이크 | **자기르(수입권 토지)** | 항구 선장 조합 |

> 기억할 점: "호칭이 바뀌면 건물 이름도 바뀐다." 같은 기능이라도 문화권마다 간판이 다르다 (영지 저택 = 장원 저택 / 티마르 관청 / 자기르 저택 / 수영 막사).

## 3. 계급과 승진

- 계급은 **7단계**로 통일(내부 번호), 이름만 문화권 표에서 가져온다.
- 승진 조건: ① 전투 경험치(전투 경력 레벨) ② 사관학교 퀘스트 완료 수 ③ 직전 1년 안의 전공(참전·소탕 횟수).
- **1년에 한 번** 왕실(수도 항구)에서 승진 심사. 게임 안 1년을 지나야 하고, 심사 퀘스트(예: "해적 소굴 소탕", "호송 임무 완수")를 끝내면 승진.
- 승진하면 얻는 것: 지휘 가능한 선단 크기(+척), 전열 함선 면허, 월급(국가 지급), 함대 지원 요청권.

## 4. 작위·영지·집

1. **작위 하사**: 명성이 기준을 넘으면 수도 항구 왕궁에서 연 1회 왕실 퀘스트가 열린다. 완수하면 작위.
2. **영지 하사**: 작위에 따라 땅 크기가 다르다(기사 = 작은 농지 한 필지 → 백작 = 마을 한 구역).
   플레이어가 그 나라 항구 중 **한 곳을 골라** 받는다(이미 다른 사람이 정한 곳 제한은 없음: 싱글).
3. **집 건설**: 받은 땅에 건물을 지을 수 있다. 첫 건물은 직위에 맞는 **작은 집**.
4. **발전 단계(명성·계급에 따라 자동 해금)**: 집 → 저택 → 영주관(농지에서 수입) → 해군 사령부 → 제독 관저.
   - 농지: 곡물·식량·지역 특산이 매일 조금씩 쌓임(창고에서 수령). 선단 보급품 가격이 싸짐.
   - 저택: 동료 거처, 연회(명성↑), 방문자.
   - 사령부: 선단 정비소와 연결, 대규모 해전 소집.
5. 건물은 기존 `Facility`/`PortBuildings` 건설 시스템과 같은 구조를 쓴다(비용·시간·단계).

## 5. 사관학교 발전

항구에 사관학교 건물이 있다. **발전도**(지역 전투 경험·퀘스트로 오름)에 따라 간판과 기능이 바뀐다.

| 단계 | 일반 명칭 | 하는 일 |
|---|---|---|
| 1 | 항해 공방 / 도선사 훈련소 | 기초 항해·사격 퀘스트, 승진 심사 응시 자격 |
| 2 | 해군생도 학교 | 포술·전술 퀘스트, 선장 면허 보너스 |
| 3 | 해군 사관학교 | 함대 지휘 과정(승진 필수), 선단 크기 증가 |
| 4 | 해군대학 / 제독 학교 | 제독 승진, 대규모 해전 지휘 퀘스트 |

문화권별 실제 이름은 §2 표의 마지막 열을 쓴다(오스만 = 조선소 도제 → 해군 공학교 …).

## 6. 더 큰 규모의 전투 (참전·습격·대전)

현재 "주점에서 전투 → 해적 한 척" 구조에 **전쟁 층**을 올린다.

### 6.1 전쟁 이벤트 (역사 기반)
`HistoryEvents`에 "전쟁" 종류를 추가한다. 전쟁이 열려 있는 동안 교전국 항구에서 **참전 요청**이 뜬다.
- 예시: 스페인 무적함대와 잉글랜드(1588), 영란전쟁(1652~74), 레판토 해전(1571), 7년 전쟁 해상전(1756~63), 트라팔가(1805) 등.
- 한 번에 한 전쟁만 참전. 편(국적)을 고르면 상대국 항구에서는 적대 상태가 된다.

### 6.2 참전 방식 세 가지
| 방식 | 내용 | 승리 보상 |
|---|---|---|
| **함대전** | 내 배 + 같은 편 함선 N척 vs 적 함대. 현재 실시간 전투 엔진에 아군/적 AI 함선을 늘린다 | 계급·명성·전리품 |
| **호송·봉쇄** | 상선단을 지켜 목적지까지 / 적 항구 앞바다를 막는다 | 국가 보상금, 작위 점수 |
| **사략(습격)** | 사략 면허로 적국 상선단·보급선 습격 | 전리품 큰 몫(거의 사냥감) |

### 6.3 항해 중 만나는 적국 선단
이미 만든 항해 장면의 **주변 배(교역선·국가 함대)** 를 이어 쓴다.
- 전쟁 중에는 적국 함대 표시가 **공격 가능**으로 바뀌고, 손님(교역선)은 중립/적 상선으로 나뉜다.
- 수동 항해에서 접근하면 "습격" 또는 "회피" 선택 → 습격하면 실시간 해전으로 전환.

### 6.4 주점의 대규모 해전 의뢰
주점 의뢰판에 **"○○ 해전 참전"** 항목이 추가된다. 누르면 전쟁 참전 흐름의 시작점이 되고, 바로 한 척 전투(현재 방식)와 구별된다.

## 7. 연속 퀘스트 (해군 계열)

| 사슬 | 단계 예시 |
|---|---|
| 사략선장 | 사략 면허 → 호송선 습격 → 적 항구 봉쇄 → 적 기함 격침 |
| 해군 입문 | 사관학교 입학 → 포술 시험 → 해적 소탕 → 승진 심사 |
| 호송 지휘 | 호송 임무 → 해적 매복 돌파 → 선단 지휘 → 제독 호위 |
| 왕실 연 1회 | 매년 다른 임무(작위·승진 심사) |

기존 `Quests.luau`의 `kind = win/…` 구조에 `warKind`, `chain`, `nextId`를 더한다.

## 8. 해군 직업군 (전투 경력의 갈래)

전투 경력 레벨에 따라 **전문 분야**를 고른다(`Specialties` 확장).

- **포술장** — 포 데미지·장전 속도
- **항해장** — 순풍 활용, 회피 기동 쿨타임 단축
- **사략선장** — 습격 전리품 증가, 면허 퀘스트
- **해군 장교** — 월급·승진 빠름, 함대 지원 요청
- **호송 지휘관** — 선단 방어, 호송 보상
- **해적 사냥꾼** — 현상금, 해적 보스 추가 피해

스킬 버튼(반원 배치)은 선택한 직업군에 따라 달라진다(포술장: 연속 사격·조준 사격, 항해장: 회피 기동·급선회 …).

## 9. 구현 단계 (제안 순서)

| 단계 | 내용 | 주요 파일 |
|---|---|---|
| S1 | 계급·작위 표(`Ranks.luau`) + 상태 저장 + 승진 심사 퀘스트 1개 + 화면 | Shared/Ranks, State, Court(Service), View, Game.client |
| S2 | 작위에 따른 영지 하사 + 집 건설(첫 건물) + 발전 단계 | Facility, PortBuildings, 땅 데이터 |
| S3 | 사관학교 건물 발전도 + 문화권별 이름 | PortBuildings, CultureRegions |
| S4 | 전쟁 이벤트 + 참전 요청(주점) + 함대전(아군·적 AI 확대) | HistoryEvents, NavalBattle, Battle |
| S5 | 항해 중 적국 선단 습격(전쟁 중), 사략 면허, 호송 퀘스트 | VoyageScene, Quests |
| S6 | 해군 직업군(전문 분야 확장) + 스킬 버튼 연동 | Specialties, Skills, NavalBattle |

각 단계는 독립적으로 머지되고, 앞 단계가 끝나야 다음이 열린다.

## 10. 전투 연출 아이디어 (현재 엔진 확장)

- **전투 날씨**: 안개(가시거리↓, 포 사거리 보이는 범위↓), 폭풍(파도·조타 흔들림), 야간(등불 표시), 순풍/역풍 강조.
- **킬 캠**: 마지막 일격 때 짧게 포탄을 따라가는 카메라, 침몰할 때 천천히 줌아웃.
- **함대전 지휘선 표시**: 적 기함 머리 위 마커, 기함 격침 시 적 함대 사기 붕괴(후퇴).
- **스킬 연출**: 연속 사격 때 총포구 불꽃·연기 증가, 회피 기동 때 물보라 강조.
- **전장 이벤트**: 소용돌이·암초·상선단 난입 같은 변수가 가끔 등장.
