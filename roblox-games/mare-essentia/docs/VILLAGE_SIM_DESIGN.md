# 마을 건설 시뮬 설계 (초안)

목표: 마을이 **발전도**에 따라 자라고, **지역 건축 양식**과 **학문·교역**이 건물과 NPC 외형에 드러난다.
외형 규칙: 파츠·도형 조립 금지. 승인된 실제 에셋(아이콘·모델)만 쓰고, 없으면 아래 "필요 에셋"에 기록만 한다.

## 0. 이미 있는 것 / 이번에 더한 것
- 있음: 항구 건물 계통 `PortBuildings.Chains`(교역·조선·학문·방어) + `Build` 서비스, 발전도에 따라 자라는 명소 `Landmarks`, 지역 건축 양식·복식 `PortCultures`(STYLE/REGION/OUTFIT).
- 추가: **의료 계통**(약초원→선원 병원→검역소→의학원), **관측·실험 계통**(관측소→천문대→화학 실험실→왕립 관측·실험소). 학문 지식을 이해해야 다음 단계가 열린다.
- 앞으로(이 문서의 아이디어): 식물·인쇄·해도 계통, 지역 스킨별 외형 차이 확대, 건물 화재·역병 이벤트, 학자 상주.

## 1. 발전도 (마을 레벨 1~6)
점수 = 교역량 + 연구한 학문 수 + 안전(치안·방어) + 인구. 문턱을 넘으면 레벨업.
| 레벨 | 이름 | 실제 인류사 대응 | 열리는 것 |
|---|---|---|---|
| 1 | 어촌·장터 | 정착·물물교환 | 부두, 우물, 주점 |
| 2 | 마을 | 시장·길드 | 시장, 창고, 대장간, 교회/사원 |
| 3 | 항구 마을 | 해상 교역 | 조선소, 등대, 세관, 성벽 |
| 4 | 항구 도시 | 상업 혁명 | 거래소, 학원, 병원, 도서관 |
| 5 | 학술 도시 | 과학 혁명 | 천문대, 인쇄소, 식물원, 화학 실험실 |
| 6 | 대도시 | 산업화 직전 | 증기 공방, 은행, 박물관, 항만 크레인 |

## 2. 학문 → 건물 (카드를 모으면 건물이 한 단계 성장)
- 천문학 → 천문대 (항해 속도) · 의학 → 병원/검역소 (선원 회복) · 조선학 → 조선소/건선거
- 건축학 → 크레인·돔 공방 · 화학 → 실험실·염색소·유리 공방 · 광물학 → 제련소
- 식물학 → 식물원·약초원 · 언어학 → 인쇄소 · 지리·항해학 → 해도 제작소
- 상업·경제학 → 거래소·은행 · 철학/신학 → 학당·성당 · 군사학 → 병영·포대·성벽
- 신화/미스터리 → 선술집 "전설의 방", 잃어버린 대륙학 → 지도 수집관

## 3. 지역별 건축 양식 (건물 외형 세트)
| 지역 | 특징 | 대표 건물·재료 |
|---|---|---|
| 북유럽 | 목조, 가파른 지붕, 석조 성당 | 스타브 교회, 어물 창고, 한자 상관 |
| 서유럽 | 박공 벽돌집, 운하, 고딕 | 길드 회관, 풍차, 곡물 창고 |
| 지중해 | 흰 벽·테라코타 지붕, 아치 | 로마식 아치 항, 대성당, 레반트 상관 |
| 이슬람권 | 돔·미나렛·중정, 바자르 | 마드라사, 대상 숙소(카라반사라이), 지붕 시장 |
| 인도양 | 목조 무역항, 사원 | 향신료 창고, 다우선 선착장 |
| 동아시아 | 기와지붕·목구조, 성곽 | 관청, 서원, 포구 시장 |
| 아프리카 | 흙벽돌, 사헬 양식 | 사하라 교역 거점, 흙벽돌 모스크 |
| 아메리카 | 계단 피라미드, 석조 | 신전 광장, 시장 광장(틀라텔롤코) |
| 태평양 | 카누 집·석상 | 카누 창고, 의례 광장 |
| 가상 7대륙 | 고유 양식(사용자 설정 전까지 비움) | 아스테리아 유적 |
양식은 같은 건물 종류에 **지역 스킨**을 씌우는 방식으로 설계한다 (건물 하나 = 기능, 스킨 = 외형).

## 4. 교역 연계
- 항구 특산품(`Ports.Goods`)에 맞는 건물이 열린다: 후추→향신료 창고, 직물→직조 공방, 광석→제련소.
- 교역량이 쌓이면 창고·세관·거래소 단계가 오르고 세금 수입이 생긴다.
- 학문 효과(`DisciplineGoods`)는 해당 건물이 있을 때 가격 보너스가 커진다.

## 5. NPC 외형
- 직업(상인·학자·선원·병사·장인)과 지역 복식(터번, 두건, 기모노풍 등)을 조합.
- 마을 레벨이 오르면 복장이 고급스러워지고 직업 NPC 수가 늘어난다.
- 외형은 승인된 초상/에셋 풀에서만 고른다.

## 6. 시뮬 규칙 (하루 단위)
- 생산: 건물 기능 × 인구 × 안전. 소비: 인구 식량·유지비. 부족하면 불만 증가.
- 이벤트: 화재(목조 마을 위험↑, 석조는↓), 역병(병원·검역소로 완화), 폭풍, 학자 방문, 세계 연대기 사건.
- 건설: 코인 + 자재(목재·석재 등 교역품) + 건설 시간.
- 선택과 전문화: 슬롯이 한정돼 학술형/상업형/군사형 마을 성격이 갈린다.

## 7. 추가 아이디어
- 마을 조망 화면에 "발전 지도"(건물 아이콘 타일 + 레벨 게이지).
- 명소(랜드마크) 건설: 지역마다 하나, 학문 마일스톤을 달성해야 건설 가능.
- 학자·장인 유치: 학문별 NPC가 건물에 상주, 논문·발명이 건물 업그레이드가 된다.
- 항구 간 교류: 건물 수준이 높은 항구끼리 특산품 시세가 안정된다.
- 연대기 연결: 실제 사건(리스본 대지진 등)이 건물을 파괴·재건하는 이벤트로 이어진다.

## 8. 구현 순서
1. 데이터: `Buildings.luau`(종류·학문·레벨·효과), `ArchStyles.luau`(지역 양식 스킨)
2. 서버: `Village.luau`(레벨·건설·일일 틱), State 저장
3. 클라: 타일 건설 화면 + 발전 게이지 (기존 `H.tileGrid` 재사용)
4. 테스트: 건물 데이터 무결성(학문·양식 연결), 건설·틱 규칙

## 필요 에셋 (승인 필요, 임의 생성 안 함)
- 건물 아이콘(종류별 약 25종), 지역 양식 스킨 이미지, NPC 복식 초상. 현재 승인 목록에 없는 항목은 부족 목록으로 먼저 보고한다.
