## 항구 치안
치안은 0~100. 해역 기본 값(유럽 70, 서아프리카 50, 신대륙 40, 인도양 55, 극동 60, 태평양 45)과 해적 소굴(나소·킹스턴, 해적 황금기 1650~1730에 추가 감소), 방어 계통 건물(단계당 +6), 교역소 단계(단계당 +3)로 목표가 정해진다. 값은 하루 0.5씩 목표로 이동한다. 순찰은 200코인에 +12(10일에 한 번), 재해가 닥치면 -15. 판매 비율은 치안 50 기준 1점당 0.04%. **해역 기본 값과 소굴 목록은 게임 설정이며, 실제 치안 통계가 아니다.**

## 방 시계 (같이 하기)
서버 하나가 방 하나다. 같이 하기를 켜고 시작하면 방의 공통 시계(현실 1분 = 게임 6일, 현실 1시간 ≈ 1년)를 쓰고, 방 안에서는 항해·전투 같은 행동이 날짜를 건너뛰게 하지 않는다. 방이 이미 열려 있으면 그 시대로만 들어갈 수 있다. 세계 재해·행운과 후속 사건은 방 전체가 같은 결과를 겪는다(서버가 처음 굴린 결과를 기록해 공유). 혼자 하기는 지금처럼 행동으로 날짜가 흐른다. **비율은 게임 설정이다. 방은 서버가 닫히면 사라지고, 개인 진행(코인·배·지식)은 개인 저장이다.**

## 원더 연출 (큰 원화 장면)
유적·지형·건축물 카드 9개를 처음 발견하면 약 10초 장면이 나온다: 큰 원화(`event_*`)가 스케치 → 채색 순서로 스스로 그려지고, 제목과 자막 3줄, 장면에 맞는 음악(자연: 바다 음악+바람, 유적: 항구 음악+종소리)이 흐른다. 화면을 누르면 건너뛰고, 도감 카드 상세에서 다시 볼 수 있다. 대상: 스톤헨지, 페트라, 기자 피라미드, 앙코르 와트, 만리장성, 치첸이트사, 모아이, 마추픽추, 울루루. **자막의 설명은 일반 상식 수준이며 출처 확인이 필요하다.** 전용 음악은 아직 없어 기존 음악을 재사용한다(assets-wanted: wonder-scene-music).
