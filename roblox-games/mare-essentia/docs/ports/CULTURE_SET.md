# 🏘️ 문화권 공용 세트 — 한 번 만들면 그 문화권 항구 전부 바뀐다

> 2026-11-29 오너: "항구별 특징 하나도 없고 다 비슷, 주민도 다 비슷."
> **원인(측정):** 등록된 Town 모델 299개 중 런던 70·케니 67·쿼터니우스 27 = 거의 전부 유럽식. **아시아·중동·아프리카 집 0개.** 주민 옷도 유럽 농부·사냥꾼 한 벌. 코드는 색만 바꿀 수 있다 → 부산도 잔지바르도 "색만 다른 런던".
> **해결:** 항구 181곳마다 만들지 말고 **문화권 22개 공용 세트**를 만든다. 코드(`PortScene.cultureSlot`)가 `<항구>_house_1`이 없으면 **`<문화권>_house_1`을 자동으로 쓴다.** 이미 연결돼 있다. 파일만 오면 된다.

- 출처: CC0 원본 가공만(`RULES.md`). 라이선스 파일에 원본 URL·"derived".
- 항구 전용 파일(`<항구>_house_1`)이 있으면 그게 이긴다. 공용 세트는 바닥을 깔아 주는 것.
