# 이즈미르 (smyrna) — 항구 작업 지시서

> 공통 규칙: `docs/RULES.md`(원본 가공·라이선스·코드 한도) → `docs/PORT_VILLAGE_PROMPTS.md`. 이 문서만으로 이 항구의 테마·왕궁·방문 건물을 만든다.

## 1. 항구 테마

| 항목 | 값 |
|---|---|
| 문화권 | 오스만 (`ottoman`) |
| 나라 | ottoman |
| 기후 | 온대 남부(지중해형) — olive and cypress, dry summers |
| 테마 | **직물 항구** — weaving workshops, dye works and cloth hall |
| 특산물 | silk, spice, olive_oil, carpet, raisins, cotton |
| 건축 | Ottoman houses with stone ground floor, projecting timber upper floor, lattice windows, red tile roofs |
| 지붕·벽 | dome · stone |
| 광장 | temple_court |
| 길 1→5단계 | dirt → gravel → cobble → flagstone → flagstone |
| 밤 조명 | mosque_lamp |
| 상징물 | domed mosque with slender pencil minarets (2단계 공사 중 → 4단계 완성) |
| 조선소 | 있음 |
| 왕궁 | 없음 → 5단계에 총독 관저 |

## 2. 발전도별 마을

| 단계 | 마을 모습 | 새로 방문 가능 |
|---|---|---|
| 1 개척 | 오두막 6채·흙길·횃불, 부두 옆 교역소·주점·항만청 | 교역소, 주점, 항만청, 조선소 |
| 2 마을 | 광장(temple_court)·상징물 기초, 집 10채, 큰길 gravel | 학자의 서재, 전투 본부 |
| 3 읍 | 시장·종교·주거·공방 구역 분리, 직물 항구 특색 공방, 가로등 3칸마다 | 외교관 거처, 은행 |
| 4 도시 | 상징물 완성, 2층 상점 주택, 창고 마당, 길 flagstone, 가로등 2칸마다 | - |
| 5 대도시 | 3층 주택·외곽 구역, 길 flagstone, 모든 길 가로등, 농촌 가공소 | 총독 관저 |
