# 탕헤르 (tangier) — 항구 작업 지시서

> 공통 규칙: `docs/RULES.md`(원본 가공·라이선스·코드 한도) → `docs/PORT_VILLAGE_PROMPTS.md`. 이 문서만으로 이 항구의 테마·왕궁·방문 건물을 만든다.

## 1. 항구 테마

| 항목 | 값 |
|---|---|
| 문화권 | 북아프리카·레반트 (`desert`) |
| 나라 | morocco |
| 기후 | 온대 남부(지중해형) — olive and cypress, dry summers |
| 테마 | **어업·염장 항구** — fish market hall, drying racks and salt works |
| 특산물 | olive_oil, salt, fish, sugar, leather, ivory |
| 건축 | adobe and stone houses, flat roofs, inner courtyards, horseshoe arches, wooden lattice windows |
| 지붕·벽 | flat · adobe |
| 광장 | market |
| 길 1→5단계 | sand → dirt → gravel → flagstone → flagstone |
| 밤 조명 | mosque_lamp |
| 상징물 | mosque with square minaret and courtyard (2단계 공사 중 → 4단계 완성) |
| 조선소 | 없음(응급 수리만) |
| 왕궁 | 없음 → 5단계에 총독 관저 |

## 2. 발전도별 마을

| 단계 | 마을 모습 | 새로 방문 가능 |
|---|---|---|
| 1 개척 | 오두막 6채·흙길·횃불, 부두 옆 교역소·주점·항만청 | 교역소, 주점, 항만청 |
| 2 마을 | 광장(market)·상징물 기초, 집 10채, 큰길 dirt | 학자의 서재, 전투 본부 |
| 3 읍 | 시장·종교·주거·공방 구역 분리, 어업·염장 항구 특색 공방, 가로등 3칸마다 | 외교관 거처, 은행 |
| 4 도시 | 상징물 완성, 2층 상점 주택, 창고 마당, 길 flagstone, 가로등 2칸마다 | - |
| 5 대도시 | 3층 주택·외곽 구역, 길 flagstone, 모든 길 가로등, 농촌 가공소 | 총독 관저 |
