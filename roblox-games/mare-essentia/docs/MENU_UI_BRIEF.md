## 3. 메뉴 배치 규칙 (2026-11-29 오너 전면 재구성)
- 하단 5개 묶음과 기존 기능 20개는 유지한다. 가로 화면은 왼쪽 기능 탭/오른쪽 실제 조작 본문, 세로 화면은 상단 가로 스크롤 탭/전체 폭 본문이다. 교역·조선은 기존 내부 장부 공간을 확보하기 위해 상단 탭만 사용한다.
- 공통 머리줄은 시설명·항구·자금/화물·닫기만 사용한다. 기능과 관계없는 시설 초상·원화 전시장·자동 넘김·공통 요약 카드·중복 실행 버튼은 제거한다.
- 실제 상품/선박/인물/백과/해도/퀘스트 원화와 지식 연결은 유지한다. 첫 경험 안내와 의뢰 바로가기는 기능 본문 아래에만 둔다. 터치 44px 이상.

## 5. 메뉴창 구조·레이아웃 상세 (2026-11-28 오너 추가 지시: "비주얼 구조 레이아웃 디테일, 시각화·편의·직관, 아이콘·버튼·프레임 정리·수정·제작")

### 5-1. 공통 창 뼈대 (전면 재구성)
- 머리줄 48px(작은 세로 폰에서 자금 표시 시 90px), 가로 화면 기능 탭 너비 120~172px 및 세로 스크롤, 좁은 화면 상단 탭 44px 및 가로 스크롤.
- 공통 원화·추천판·요약판을 본문 앞에 배치하지 않는다. 기능별 목록/상세/행동을 먼저 보여 준다. 교역·조선은 기존 상세 장부에 자금 표시를 유지한다.

### 5-2. 화면별 배치

| 화면 | 왼쪽(목록) | 오른쪽(상세) | 큰 버튼 |
|---|---|---|---|
| 교역 | 상품 행: 상품 아이콘 · 이름 · 시세 막대(평균 대비 초록/빨강) · 🔒/특산/수요 배지 | 큰 상품 그림 · 사는 값/파는 값 · 내 손익 ▲▼ · 화물칸 막대 · 🎲흥정 | 사기 / 팔기 |
| 항해 | 항구 행: 거리 · 📜 · 🔧 · 실은 화물 예상 이익 🟢▲/🔴▼ | 미니 해도(경로 선) · 날짜·보급 소모 막대 | 출항 |
| 모험 | 의뢰 카드: 장 도장 · 문제→할 일 한 줄 · 진행 막대 | 인과 카드(문제·원인·할 일·결과) · 말하는 사람 초상 | 지금 할 일로 가기 |
| 성장 | 배·동료 카드 그리드(초상·레벨 막대) | 능력 비교 막대(지금 ↔ 바꾸면) | 고용 / 구매 / 강화 |
| 기록 | 분야 책갈피 + 카드 그리드(발견=그림, 미발견=실루엣) | 백과 장(ENCYCLOPEDIA_BRIEF 1절) | 이전 / 다음 |

### 5-3. 정리·수정 목록 (지금 화면에서 고칠 것)

- 같은 기능 두 이름(지식 백과/백과사전 등) → 하나로(코드 완료: '지식 카드'·'백과사전').
- 사각 테두리 버튼 + 원형 음영 섞임 → **모두 청동 원형 아이콘 + 아래 글자 띠**로 통일.
- 행마다 버튼 3~4개 → 행은 누르면 상세로, 버튼은 상세에만.
- 이모지 아이콘(📜🔧🔒⚔🎁★▶) → 아이콘 시트(1절 + 아래 5-4) 그림으로 교체(코드가 시트 등록 시 자동 교체).
