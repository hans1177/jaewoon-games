## 3. 메뉴 배치 규칙 (코드 완료 · 디자인 참고)

- 하단 버튼 5개: **항해 · 교역 · 모험 · 성장 · 기록** (+ 걷기, 일지·카드·설정). 묶음 안 기능은 위쪽 가로 탭.

- 엄지 영역: 자주 누르는 건 아래, 닫기는 오른쪽 위. 터치 칸 44px 이상.

## 5. 메뉴창 구조·레이아웃 상세 (2026-11-28 오너 추가 지시: "비주얼 구조 레이아웃 디테일, 시각화·편의·직관, 아이콘·버튼·프레임 정리·수정·제작")

### 5-1. 공통 창 뼈대 (모든 메뉴 같게)

```
┌──────────────────────────────────────────────┐ ← 책 프레임(ui_frame_book) 바깥 64px 장식
│ [묶음 아이콘] 묶음 이름 · 항구명 · 담당자      [✕] │ ← 머리 56px (닫기 오른쪽 위 고정, 44px 이상)
│ (탭) 교역 │ 시세 │ 항구 시설   ← 책갈피 리본 탭(ui_frame_tab_on/off) 44px      │
├──────────────────────────────────────────────┤
│ ▶ 지금 할 일 │ ★ 추천 │ 🎁 보상 받기   ← 카드 3칸(ui_frame_card) 64px          │
├──────────────────────┬───────────────────────┤
│ 왼쪽: 목록(스크롤)      │ 오른쪽: 선택한 것 상세  │ ← 넓은 화면 6:4, 폰은 위아래
│  행 = 아이콘 48 + 이름   │  큰 그림 · 숫자 막대     │
│      + 한 줄 설명 + 배지 │  · 큰 버튼(아래 고정)    │
└──────────────────────┴───────────────────────┘
```

- 폰(가로 600px 미만): 머리 48px, 탭은 가로 스크롤, 목록/상세는 위아래로 쌓고 상세의 큰 버튼은 화면 아래 고정.
- 색 규칙: 주 행동 = 금색 버튼(ui_button_gold), 확인·좋음 = 초록, 위험·팔기 손해 = 빨강, 보조 = 회색. **한 화면에 금색 버튼 1개만.**
- 숫자는 막대·▲▼·색으로 먼저 보이고 숫자는 옆에 작게. 글자 최소 14px(폰 13px).

### 5-3. 정리·수정 목록 (지금 화면에서 고칠 것)

- 같은 기능 두 이름(지식 백과/백과사전 등) → 하나로(코드 완료: '지식 카드'·'백과사전').

## 6. 상단 원화 띠 정리 (2026-11-28 오너: "상단 원화 디자인 구려")

- 예전: 흐린 배경 + 왼쪽 작은 카드 + 제목 여러 줄 → 지저분.
- 지금: **원화 한 장을 선명하게 꽉 채운 가로 띠**(높이 92~170). 왼쪽만 어둡게, 왼쪽 아래 제목 한 줄·설명 한 줄, 오른쪽 아래 ◀ ▶. 띠 전체를 누르면 백과로.
- 도감 탭에서는 띠를 띄우지 않음(화면 자체가 원화 중심).
- 원화 제작 규칙: 가로로 잘려도(가운데 약 3:1 띠만 보임) 주제가 **가운데 높이**에 오게. 왼쪽 1/3은 글자 자리라 어둡거나 단순하게. 시설별 가로 띠 전용(2400×800) 원화를 주면 더 좋음 — 파일명 `ui_strip_<시설>.png`.

## 7. 시설 원화 품질 승인 (오너 지시: 저품질 원화 사용 금지)

- 시설별 2400×800 풀컬러 원본을 실제로 열어 역사적 복장·건축·도구, 인체 및 손, 광원, 소재, 구도, 모바일 가독성을 비교한다.
- 반복 인물·유사 구도·과도한 장식·문자·흐림·오류가 있는 원화는 승인하지 않는다. 기존 승인 자산보다 낮은 품질로 교체하지 않는다.
- 자동 형식 검사와 시각 검수는 별개다. 기존 APPROVED_IMAGES.json에 실제 검수한 원본의 SHA-256이 일치할 때만 반입한다. 미승인 원본은 드롭박스에 보존하고 검수 대기로 기록한다.
- 기존 시설 원화 8종의 1차 제작본 비교: 교역소·조선소·학자의 서재·선장실은 유지 후보(최종 승인 전), 항만청·외교·주점·전투 본부는 제목 영역/반복 인물/구도 차별화 보완 대상. 드롭박스 원본과 실제 화면 비교 전 등록 완료로 판정하지 않는다.
