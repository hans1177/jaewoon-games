## 3. 메뉴 배치 규칙 (코드 완료 · 디자인 참고)

- 하단 버튼 5개: **항해 · 교역 · 모험 · 성장 · 기록** (+ 걷기, 일지·카드·설정). 묶음 안 기능은 위쪽 가로 탭.
- 메뉴 맨 위 3칸: **▶ 지금 할 일 / ★ 추천 / 🎁 보상 받기** — 1번 아이콘 시트 5·7·6번 칸이 들어갈 자리.
- 일지 인과 카드: 장 제목(8) · 문제(9) → 원인(10) → 할 일(11) → 바뀌는 것(12), 지난 이야기(13).
- 처음 해 보는 기능 3단계 안내(14), 해전 패배 조언(15).
- 엄지 영역: 자주 누르는 건 아래, 닫기는 오른쪽 위. 터치 칸 44px 이상.
