# 설계 문서: Mare Essentia

## 1. 컨셉
항해·교역·탐험·학문이 하나로 이어지는 "세계 백과 완성" RPG.
플레이어는 학자 겸 무역가가 되어 항구를 오가며 지식을 수집한다.

- 시대: 1600~1700년대 (린네, 뉴턴, 레이우엔훅 등 실존 학자가 겹치는 시기)
- 지역(1차): 서유럽·북유럽
- 전투: 보조 요소. 자동스킬 사용 (유적 수호자, 신화 몬스터, 교역로 습격)

## 2. 게임 루프
1. 항구에서 특산품을 싸게 사서 비싼 항구에 판다
2. 돈으로 배를 업그레이드해 먼 바다로 간다
3. 지도 조각을 모아 유적·서식지를 발견한다
4. 지상 탐험으로 식물·동물·광물·유물을 채집·관찰한다
5. 도감에 등록하고 학회에 제출해 명성·후원금을 받는다
6. 지식 해금으로 새 능력, 새 항로, 새 직업 스킬을 얻는다

## 3. 나라 선택 (시작 항구와 보너스)
| 나라 | 시작 항구 | 보너스 |
|---|---|---|
| 영국 | 런던 | 항해술, 왕립학회 연줄 |
| 네덜란드 | 암스테르담 | 교역 수수료 할인 |
| 프랑스 | 루앙 | 외교·귀족 후원 |
| 덴마크 | 코펜하겐 | 천문·북해 항로 |
| 스웨덴 | 예테보리 | 식물·광물 연구 |

확장 예정: 포르투갈, 스페인, 독일 등.

## 4. 직업 (전환 가능, 복수 육성)
- 식물학자: 채집, 씨앗 교역, 약초 제작
- 동물학자: 관찰·스케치, 길들이기
- 유물수집가: 발굴, 감정, 박물관 전시
- 무역가: 특산품 교역, 항로 개척
- 추가 후보: 지도제작자, 의사, 연금술사

## 5. 교역 시스템
- 항구마다 특산품과 수요 품목이 있다
- 가격 = 기준가 x 수요공급 계수 x 이벤트 계수
- 사면 가격 상승, 팔면 하락, 시간이 지나면 기준가로 회복
- 배 화물칸 크기가 한 번에 옮길 양을 제한한다

예시 특산품
- 런던: 양모, 석탄
- 암스테르담: 향신료(재수출), 치즈
- 루앙: 와인, 직물
- 코펜하겐: 호박, 생선
- 예테보리: 철, 목재

## 6. 세계 백과 (지식 카드)
모든 지식은 카드 한 장으로 통일한다.

필드: `id`, `name`, `field`(분야), `rarity`(희귀도), `description`, `source`(발견 방법), `reward`

분야: 식물, 동물, 광물, 유물, 유적, 천문, 화학/연금술, 물리, 지리, 종교, 철학, 의학, 역사, 언어

발견 흐름: 현장 관찰 → 스케치 → 실험·검증 → 학회 제출

학문 연결 예
- 천문 + 항해술 = 경도 측정 성공
- 화학 지식 = 화약·염료 제작 해금

종교·철학은 중립적·백과사전식 서술로 쓴다.

## 7. 불가사의 유적과 신화
실존: 스톤헨지, 피라미드, 페트라, 앙코르와트, 마추픽추, 나스카, 모아이, 보로부두르, 그레이트 짐바브웨 (서유럽·북유럽 1차 범위 밖은 후속 확장)
1차 범위 안: 스톤헨지, 카르나크 열석, 뉴그레인지, 로마 유적, 바이킹 유적, 룬석
신화: 아틀란티스, 엘도라도, 크라켄, 바다뱀, 세이렌, 프레스터 존

## 8. 실존 학자 NPC
- 스웨덴: 린네 (식물 분류)
- 덴마크: 튀코 브라헤 (천문대)
- 플랑드르: 메르카토르, 오르텔리우스 (지도)
- 네덜란드: 레이우엔훅 (현미경), 스피노자
- 영국: 한스 슬론, 조지프 뱅크스, 뉴턴, 핼리, 보일
- 마리아 메리안: 동료 가능
- 그 외: 갈릴레오, 케플러, 데카르트, 라이프니츠, 라부아지에

주의: 시대가 어긋나는 인물은 "시대 확장판" 또는 "역사 탐방" 콘텐츠로 분리한다.

## 9. 자동스킬 전투
- 장착 스킬 4~6개가 쿨타임마다 자동 발동
- 플레이어는 이동·방향·타겟만 조작
- 스킬 우선순위 설정 가능 (체력 낮으면 회복 먼저)
- 접현 시 갑판 백병전: 선원 NPC가 함께 싸움, 적 선장 격파 시 나포
- 스킬 시너지 (불 + 화약 = 폭발)

## 10. 기술 설계
- Luau, Rojo 프로젝트 구조
- 데이터 주도: 항구, 상품, 지식 카드, 스킬은 모두 데이터 테이블
- 서버 권한: 가격, 인벤토리, 도감 진행도는 서버에서 계산
- 저장: DataStore (플레이어별 도감, 자금, 배, 직업)

폴더
```
src/
  ReplicatedStorage/Shared/   공용 데이터·모듈
  ServerScriptService/        서버 로직
  StarterPlayer/              클라이언트 UI
```

## 11. 증기 세계관
대체 역사형 증기 레이어. 증기 기술은 도감 발견과 연구로만 해금되고, 석탄을 연료로 쓴다.
자세한 내용: [STEAM.md](STEAM.md)

## 12. 시스템 구성 (코드 구현 완료, Studio 검증 전)
- 교역: 항구별 특산품, 수요공급 가격, 교역 레벨 보너스
- 선박: 범선 4종, 증기선 2종, 조선소(구매·수리·보급품·석탄)
- 항해: 거리와 속도로 소요일 계산, 보급품 소모, 바람과 사건
- 자동전투: 포격 → 접현 백병전, 자동스킬 우선순위, 사략선 습격
- 직업(커리어): 교역 / 모험 / 전투 레벨
- 탐험: 항구 주변 탐험으로 도감 카드 발견
- 연구: 증기 기술 트리
- 학자 NPC: 연도 범위 안에서만 방문 가능, 지식 전수
- 퀘스트: 납품, 발견, 전투, 항해
- 저장: DataStore 한 곳에서 관리

대항해시대 류 게임의 시스템 구조(교역·모험·전투 3대 직업, 선박 관리, 항해 사건)를 참고하되, 이름·그림·문장은 모두 새로 만든 것이다.
