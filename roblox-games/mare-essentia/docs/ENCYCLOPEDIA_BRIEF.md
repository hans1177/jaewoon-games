## 1. 화면 구성 (코드 작업 — Claude)

| 구역 | 내용 |
|---|---|
| 머리 | 큰 원화(가로 띠) + 이름 + 학명/원어 이름 + 분야 도장 + 희귀도 별 |
| 요약 상자 | 한눈에 보기 표: 분류 · 지역 · 시대 · 크기/무게 · 쓰임 · 값(교역품이면) |
| 본문 | 개요 → 생김새·구조 → 쓰임·의미 → 역사 → 그 시대 항해자에게 |
| 그림 | 분포 지도(발견 지역에 금색 점), 연표 막대(시대), 크기 비교 실루엣(사람·배와 비교) |
| 연결 | 관련 카드 썸네일 줄(relations), 관련 항구·교역품 바로 가기 |
| 발견 기록 | 내가 언제·어디서·어떻게(스케치·채집·탁본) 발견했는지, 같은 분야 수집률 막대 |
| 넘김 | 책장 넘기는 효과, 좌우로 이전/다음 카드, 분야별 색 책갈피 |

## 2. 해설 데이터 형식 (글 작업 — ChatGPT)

```lua
Articles.<card_id> = {
	topic = "<위키 영문 표제>",            -- 기존 칸 유지
	latin = "<학명 또는 원어 표기>",        -- 동식물 학명, 유물·유적은 원어
	summary = "<개요 2~3문장, 120~200자>",
	looks = "<생김새·구조 3~5문장, 크기·색·재질 숫자 포함>",
	details = "<쓰임·특징 3~5문장>",        -- 기존 칸(길게 다시 씀)
	context = "<그 시대 항해자·상인에게 어떤 의미였나 2~4문장>", -- 기존 칸
	history = "<역사 3~6문장, 연도 포함>",  -- 기존 칸
	facts = { { "분류", "..." }, { "지역", "..." }, { "시대", "..." }, { "크기", "..." }, { "쓰임", "..." } }, -- 요약 상자 4~6줄
	trivia = "<알고 나면 재미있는 한 가지, 1~2문장>",
	sources = { "<참고한 공개 자료 이름>" },  -- 위키백과 문서명 등. 링크 X
}
```

- **분량**: 한 장당 본문 합계 600~1,000자(한국어). 짧은 설명(`description`)은 그대로 두고 카드 앞면용으로 쓴다.
- **사실만**: 연도·숫자는 공개 자료로 확인된 것만. 모르면 쓰지 않는다. 전설·추정은 "~라고 전한다"로 구분(`meta.evidence`).
- **쉬운 말**: 중학생이 읽을 수 있게. 전문 용어는 처음 나올 때 괄호로 풀이.
- **분야별 꼭 넣을 것**
  - 동물(Zoology): 학명 · 몸길이/몸무게 · 사는 곳 · 먹이 · 그 시대 사람과의 관계(식량·가죽·두려움)
  - 식물(Botany): 학명 · 키/잎·꽃 모양 · 자라는 기후 · 쓰임(약·향신료·염료) · 교역 경로
  - 광물(Mineral): 화학식 · 색/굳기(모스) · 산지 · 제련·쓰임
  - 유적(Site): 위치 · 지은 시기와 사람들 · 크기 · 남은 모습 · 발견·재발견 이야기
  - 유물(Relic): 재질 · 크기 · 만든 곳·때 · 쓰임 · 지금 있는 곳(박물관)
  - 지리·날씨·항해: 원리 그림으로 설명할 수 있게 단계별로
  - 교역품(Goods): 원산지 → 거쳐 간 항구 → 팔린 곳, 그 시대 값의 감(비싼/흔한)
- **납품 방법**: 분야별 50장씩 묶어 위 형식 Lua 그대로. 파일 `docs/encyclopedia/<분야>_<번호>.luau` 로 저장소에 올리면 Claude가 `Articles`에 합친다.

## 9. 깔끔한 도감 화면 (2026-11-28 오너: "답답·복잡, 원화 중심, 백과사전 보듯이")

화면 구성(코드 `H.renderDex`, 끄기 `H.dexClean = false`):

| 자리 | 내용 |
|---|---|
| 맨 위 | `📖 도감 · 찾은 수 / 전체` 한 줄 + 검색칸·분야 버튼(기존) |
| 왼쪽(폰은 위 가로 줄) | 원화 썸네일 격자. 아래 검은 띠에 이름 한 줄. 고른 카드는 금테 |
| 오른쪽 | 큰 원화(자르지 않음) + 아래 그라데이션 위 이름·★등급·학명·분야, 양옆 ◀ ▶ |
| 그 아래 | 정보 알약 3~4개(분야·📍지역·⏳시대·번호) → 개요 → 요약 |
| 접힘 | `자세히 보기 ▼` 를 눌러야 생김새·특징·배경·역사·재미·한눈에 보기·지도·연표·크기·관련·수집률·발견 기록 |

원화 제작 규칙(ChatGPT):
- 썸네일은 작게(약 80×110) 보여도 알아보게 **주제 하나를 크게, 가운데**. 배경은 단순하게.
- 큰 원화는 `Fit`이라 잘리지 않음. 7:10 세로 기준, 글자·로고·테두리 넣지 않음(이름은 게임이 씀).
- 아래 1/5은 이름 띠가 덮으므로 중요한 것을 두지 않음.


## 10. 중세 채색 필사본 전용 책 (2026-11-28 오너 추가 지시)

- 일반 메뉴·카드 격자와 달리 왼쪽은 큰 원화, 오른쪽은 해설. 세로폰은 각각 한 페이지. 그림에 제목이나 버튼을 겹치지 않는다.
- 책 원화는 `CardArt/ency_bg_book.png`: 금박 덩굴·청금석·적색 안료·작은 항해 삽화, 글자 없음. 테두리 장식과 제본선을 가리지 않도록 본문을 배치한다.
- 분야별 책갈피는 개별 파일 대신 `CardArt/ency_tab_sheet.png` 4×4 풀컬러 투명 시트로 통합한다. 왼쪽 위부터 동물·식물·광물·유적 / 유물·지리·항해·날씨 / 의학·천문·예술·언어 / 신화·법과 교역·선박·전체. 유사 분야는 해당 문양을 공유한다. 승인 등록 키가 없으면 그림을 억지로 표시하지 않는다.
- 페이지 이동은 기존 소리와 0.2초 종이 음영·이동 연출. 모션 감소 설정에서는 즉시 이동한다. 기존 발견 여부·책갈피 저장·검색·연표·분포 등은 유지한다.
- 실제 등록, 배포와 Studio 모바일 화면 확인은 별개로 검증한다.
