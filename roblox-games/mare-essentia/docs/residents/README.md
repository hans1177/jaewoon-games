## 현재 문제 (Studio 진단 2026-11-23)

- 머리카락·몸 덧입힘 메시에 텍스처가 없어 Roblox 기본 회색(163,162,165)으로 보인다 → 색 텍스처/SurfaceAppearance 필수, 회색 기본색 금지
- 같은 부위에 여러 층(몸통+덧옷+외투)이 겹쳐 깜빡이거나 두꺼워 보인다 → 층마다 1개만, 겹칠 땐 안쪽 층 숨김
- 모자·머리·장식이 얼굴을 가리거나 머리 속으로 파고든다 → 머리 크기 기준 오프셋 표, 얼굴 영역 비움
- 치마 링이 다리와 분리돼 보이던 문제(수정됨) → 치마 길이·폭을 다리 크기 비율로
- 모든 주민이 같은 속도·같은 대기 모션 → 나이·직업·날씨·경제에 따라 다르게

## 추가 아이디어

- 나이 3단계(아이·어른·노인): 키·자세·걸음·흰머리.
- 혼인·신분 표시가 있는 문화권은 헤어로 구분(조선 상투·쪽머리, 일본 올림머리 등).
- 계절·날씨 옷: 비 망토·삿갓·우산(동아시아)·양산, 겨울 모피·숄, 여름 얇은 옷·부채.
- 축제·장날 옷: 문화권 축제 색, 꽃·리본, 악사·광대 직업 추가.
- 경제 반응: 흉년엔 해진 옷·맨발 비율↑, 호황엔 새 옷·장신구↑.
- 외국인 상인: 다른 문화권 복장 1~2명(교역 상대국)으로 항구 국제색.
- 군중 밀도: 시간대·장날·날씨에 따라 인원 30~120% 조절, 모바일 상한.
- 이름표 없이도 직업이 보이게: 도구·앞치마·모자가 직업 신호.

## 성능

- 근거리만 전체 층·모션, 중거리 단순화, 원거리 실루엣. 모바일 인원 절반.
