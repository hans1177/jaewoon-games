# 북아프리카·레반트 (`desert`) 주민

| 항목 | 내용 |
|---|---|
| 남성 복장 | 젤라바/카프탄·터번·슬리퍼 |
| 여성 복장 | 긴 겉옷·히잡·은 장신구 |
| 헤어 | 터번 속 짧은 머리, 수염(남) |
| 천 | 면·모직 |
| 색 | 흰색·모래색·인디고 |

## 나이·계층 변형

- 아이: 어른 옷 축소형 + 맨발 비율↑, 머리 짧거나 땋음
- 노인: 흰머리·지팡이·두꺼운 겉옷, 느린 걸음
- 계층: README 계층표대로(빈민 덧댄 천 → 부유층 실크·장신구)

## 날씨·축제

- 비: 문화권 우비(삿갓·도롱이·기름 망토·숄 머리 덮기)
- 추위: 모피·두꺼운 숄·장화
- 더위: 얇은 천·부채·양산
- 축제: 흰색·모래색·인디고 중 밝은 색 + 꽃·리본·악기

## 금지

- 희화화·과장된 민족 특징, 다른 시대 복식 섞기, 실존 인물 얼굴, 종교 의복 오용.
