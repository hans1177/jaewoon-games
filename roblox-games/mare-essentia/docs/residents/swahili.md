# 스와힐리·아라비아 해안 (`swahili`) 주민

| 항목 | 내용 |
|---|---|
| 남성 복장 | 칸주(흰 긴 옷)·코피아 모자 |
| 여성 복장 | 캉가 천 두르기·머릿수건 |
| 헤어 | 짧은 머리(남), 땋거나 감싼 머리(여) |
| 천 | 면 |
| 색 | 흰색·밝은 무늬색 |

## 나이·계층 변형

- 아이: 어른 옷 축소형 + 맨발 비율↑, 머리 짧거나 땋음
- 노인: 흰머리·지팡이·두꺼운 겉옷, 느린 걸음
- 계층: README 계층표대로(빈민 덧댄 천 → 부유층 실크·장신구)

## 날씨·축제

- 비: 문화권 우비(삿갓·도롱이·기름 망토·숄 머리 덮기)
- 추위: 모피·두꺼운 숄·장화
- 더위: 얇은 천·부채·양산
- 축제: 흰색·밝은 무늬색 중 밝은 색 + 꽃·리본·악기

## 금지

- 희화화·과장된 민족 특징, 다른 시대 복식 섞기, 실존 인물 얼굴, 종교 의복 오용.
