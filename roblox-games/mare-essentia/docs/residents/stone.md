# 발트·러시아·스코틀랜드 석조 (`stone`) 주민

| 항목 | 내용 |
|---|---|
| 남성 복장 | 카프탄형 외투·모피 모자·장화 |
| 여성 복장 | 사라판(러시아식)·머릿수건 |
| 헤어 | 수염과 긴 머리(남), 긴 땋은 머리(여) |
| 천 | 모직·모피·리넨 |
| 색 | 적색·짙은 청색·금빛 자수 |

## 나이·계층 변형

- 아이: 어른 옷 축소형 + 맨발 비율↑, 머리 짧거나 땋음
- 노인: 흰머리·지팡이·두꺼운 겉옷, 느린 걸음
- 계층: README 계층표대로(빈민 덧댄 천 → 부유층 실크·장신구)

## 날씨·축제

- 비: 문화권 우비(삿갓·도롱이·기름 망토·숄 머리 덮기)
- 추위: 모피·두꺼운 숄·장화
- 더위: 얇은 천·부채·양산
- 축제: 적색·짙은 청색·금빛 자수 중 밝은 색 + 꽃·리본·악기

## 금지

- 희화화·과장된 민족 특징, 다른 시대 복식 섞기, 실존 인물 얼굴, 종교 의복 오용.
