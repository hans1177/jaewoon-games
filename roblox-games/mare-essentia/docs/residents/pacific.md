# 태평양·오세아니아 (`pacific`) 주민

| 항목 | 내용 |
|---|---|
| 남성 복장 | 타파 천 허리옷·꽃목걸이 |
| 여성 복장 | 타파/풀잎 치마·꽃목걸이 |
| 헤어 | 긴 머리·꽃 장식, 문신(일부) |
| 천 | 타파 천·식물 섬유 |
| 색 | 흙색·흰색·자연색 |

## 나이·계층 변형

- 아이: 어른 옷 축소형 + 맨발 비율↑, 머리 짧거나 땋음
- 노인: 흰머리·지팡이·두꺼운 겉옷, 느린 걸음
- 계층: README 계층표대로(빈민 덧댄 천 → 부유층 실크·장신구)

## 날씨·축제

- 비: 문화권 우비(삿갓·도롱이·기름 망토·숄 머리 덮기)
- 추위: 모피·두꺼운 숄·장화
- 더위: 얇은 천·부채·양산
- 축제: 흙색·흰색·자연색 중 밝은 색 + 꽃·리본·악기

## 금지

- 희화화·과장된 민족 특징, 다른 시대 복식 섞기, 실존 인물 얼굴, 종교 의복 오용.
