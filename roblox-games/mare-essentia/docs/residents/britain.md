# 잉글랜드·스코틀랜드 (`britain`) 주민

| 항목 | 내용 |
|---|---|
| 남성 복장 | 셔츠·조끼·브리치스·스타킹·버클 구두, 트리코른/펠트 모자 |
| 여성 복장 | 보디스·긴 치마·앞치마·숄·리넨 모브캡 |
| 헤어 | 짧은 머리·꼬리머리(남), 모자 속 땋은 머리(여) |
| 천 | 울·리넨·가죽 |
| 색 | 회색·갈색·남색·적갈색 |

## 나이·계층 변형

- 아이: 어른 옷 축소형 + 맨발 비율↑, 머리 짧거나 땋음
- 노인: 흰머리·지팡이·두꺼운 겉옷, 느린 걸음
- 계층: README 계층표대로(빈민 덧댄 천 → 부유층 실크·장신구)

## 날씨·축제

- 비: 문화권 우비(삿갓·도롱이·기름 망토·숄 머리 덮기)
- 추위: 모피·두꺼운 숄·장화
- 더위: 얇은 천·부채·양산
- 축제: 회색·갈색·남색·적갈색 중 밝은 색 + 꽃·리본·악기

## 금지

- 희화화·과장된 민족 특징, 다른 시대 복식 섞기, 실존 인물 얼굴, 종교 의복 오용.
