## 보완점

- 외형을 `frigate` 모델에서 빌리고 색(tint)만 바꿈 → 고유 모델 필요(최우선)
- V5 상세 모델 미등록 → 근·중·원 LOD 포함 상세 모델 제작
- 노 젓는 배인데 노 구멍·노·노잡이 표현 확인 필요
- 대포 10문이 포문 수와 일치해야 함(갑판 2층 기준 배치)
- 선미 갤러리·선수상·삭구 밀도가 등급(2급 중형)에 맞는지 확인

## 부위별 디테일 지시

- 선체: 1.5-2 decks, 2-3 masts, quarterdeck, 노 구멍 줄과 노잡이 갑판
- 포: 기본 포갑판 1층 + 상갑판 포, 10~16문. 대포 개조(장포·중포·카로네이드·증기포)에 따라 포신 모양 교체
- 갑판: 캡스턴·해치·비너클·타륜·보트 2척, 화물 조금
- 선미: 선미 창 1줄·등불 2개
- 선수: 단순 선수상, 닻 2개
- 삭구·돛: 문화권 돛 형태 반영, 낡은 정도는 등급 낮을수록↑
- 손상 단계·항적·PBR은 README 기준
