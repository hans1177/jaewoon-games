## 부위별 디테일 지시

- 선체: 1.5-2 decks, 2-3 masts, quarterdeck, 포문 6개를 1층에 나눠
- 포: 기본 포갑판 1층 + 상갑판 포, 10~16문. 대포 개조(장포·중포·카로네이드·증기포)에 따라 포신 모양 교체
- 갑판: 캡스턴·해치·비너클·타륜·보트 2척, 화물 많이
- 선미: 선미 창 1줄·등불 2개
- 선수: 단순 선수상, 닻 2개
- 삭구·돛: 문화권 돛 형태 반영, 낡은 정도는 등급 낮을수록↑
- 손상 단계·항적·PBR은 README 기준
