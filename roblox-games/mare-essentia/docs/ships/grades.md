# 등급·개조별 기능과 외형

## 배 등급(class)

| 등급 | 구조 | 무장 | 역할·조건 | 외형 차이 |
|---|---|---|---|---|
| 1급 소형 | 1 deck, 1-2 masts, open waist | 선회포·소형포 4~6문, 단층 갑판 | 근해 교역·정찰, 면허 불필요 | 장식 없음 |
| 2급 중형 | 1.5-2 decks, 2-3 masts, quarterdeck | 포갑판 1층 + 상갑판 포, 10~16문 | 원양 교역·호위, 항만청 면허 | 장식 간단한 선미 조각 |
| 3급 대형 | 2 gun decks, 3 masts, forecastle + quarterdeck + poop | 포갑판 2층 20~40문, 선미 갤러리 | 함대 주력·대량 수송 | 장식 선미 갤러리·선수상 |
| 4급 특수·기함 | 3 decks or steam/iron hull, flagship ornament | 포갑판 3층 또는 증기 포탑, 대형 장식 | 기함·결전·증기/장갑 | 장식 금박·3층 갤러리·대형 깃발 |

## 대포 5종 (Ships.Cannons) — 기능과 보이는 모습

| 대포 | 가격 | 위력 | 기능 | 외형 |
|---|---|---|---|---|
| 철제 6파운드포 | 0 | +0% | 기본 대포 | 짧은 주철 포·작은 포차 |
| 장거리 컬버린 | 1200 | +8% | 멀리 나가는 긴 포신 | 긴 포신·좁은 포구, 사거리↑(장포 연출) |
| 데미 캐논 | 3500 | +18% | 무겁고 강한 중포 | 굵은 중포·큰 포차, 반동 큼 |
| 카로네이드 | 6000 | +30% | 짧고 굵은 근거리 대포 (스톡홀름 주조공의 비법) | 짧고 굵은 통·미끄럼 포가, 근거리 산탄 연기 큼 |
| 증기 압축포 | 12000 | +50% | 증기압으로 쏘는 신형 대포 | 황동 압력통·배관이 붙은 포, 하얀 증기 |

## 선체 보강 3단계 (Ships.Plating)

| 단계 | 기능 | 외형 |
|---|---|---|
| 목재 보강 | 내구 +8% | 흘수선 위 덧댄 판·볼트 |
| 구리 피복 | 내구 +16%, 속도 +3% | 흘수선 아래 구리판(초록 녹) |
| 철판 장갑 | 내구 +30%, 속도 -4% (증기 기술) | 검은 철판·리벳 띠, 포문 둘레 강화 |

## 역할 특성(trait)별 세분화

| 역할 | 강점 | 약점 | 보이는 표시 |
|---|---|---|---|
| 교역 | 화물·관세 | 포·근접 | 넓은 선복, 갑판 화물 상자, 큰 해치 |
| 전투 | 포·근접 | 화물 | 포문 줄·두꺼운 띠, 전투 깃발 |
| 탐험 | 탐험·장거리 | 화물 | 측량 기구·망원경 든 견시, 작은 보트 2척 |
| 습격/해적 | 회피·기습 | 내구 | 낮은 선체·검은 돛 옵션·해골 장식 |
| 호위 | 화물 보호 | 속도 | 선미 신호기 줄·호송 깃발 |
| 연안·노선 | 얕은 물·무풍 | 폭풍 | 노 구멍 줄·노잡이 |
| 증기 | 무풍 속도 | 석탄 소모 | 굴뚝 연기·외륜/스크루 물보라 |

## 개조 레벨(제안) — 기능 세분화

| 레벨 | 열리는 기능 | 외형 |
|---|---|---|
| ★1 기본 | 기본 능력치 | 깨끗한 기본형 |
| ★2 | 돛 개량(순풍 +5%) | 새 돛천·추가 보조돛 |
| ★3 | 포갑판 확장(포 +2) | 포문 추가·포차 교체 |
| ★4 | 선원실 확장(선원 +10%) / 화물칸 확장 | 선체 조금 길어짐·해치 추가 |
| ★5 | 고유 특기(역할별: 일제 사격·은밀 항해·대량 하역) | 금박·나라 문장·고유 깃발 |
