## 4. 구역 이동·자동저장·다양한 현장 목표 (2026-11-29 오너 요청)
- 퍼즐·수수께끼는 제외. 실제 이동·전투·구조·추격·관찰·선택으로 진행한다.
- 1차 후보: 기존 1~3개 조사 지점을 입구→심부 순서로 연결하고 현재 목표만 미니맵 표시. 기존 stats에 활성 탐험 1개, 완료 단계·카드만 저장. 기존 15초 자동저장·종료 저장 사용. 구역 기록과 귀환 보상을 분리하고 완료 기록 소비 후 중복 정산을 거부. 재입장 시 완료 조사 지점은 제외하고 마지막 완료 지점 주변의 지면·물·경사·충돌·적 거리 검사를 통과한 안전 위치로 복원한다. 없으면 기존 입구로 복귀한다. 전투 상태·정확한 이전 위치는 복원하지 않는다. 실제 자동검사·Studio 미검증.
- 후속 구현 대상(미완료): 인질 구출, 호위, 추격, 역추적, 매복, 생존 방어, 거점 탈환, 잠입, 탈출, 현상금 사냥, 야생동물 사냥, 생태 관찰, 밀렵 저지, 유물 회수, 보급품 탈환, 증원 차단, 결투, 연속 보스전, 신화 탐험, 긴급 구조. 텍스트만 달리하고 조사 버튼을 누르는 것으로 완료 처리하지 않는다.
- 일반 1~2구역, 주요 3~5구역, 대형 원정 5~8구역은 후속 목표. 지역 고유 승인 지형·경로·실제 이동·전환·안전 체크포인트를 구성하고 기존 모듈에 연결한다. 이집트 사막→야영지→무덤, 인도 밀림→강가→신전, 북유럽 설원→호수→동굴, 중국 산길→숲→요새, 일본 해안→숲→성채, 아프리카 초원→협곡→폭포. 승인 자산 없는 곳은 부족 목록에 기록한다.
- 갈림길·직업별 발견/지원·환경 변화·보스 추격·야영지는 실제 동작과 모바일 비용 검증 후 적용. 진행도는 구역 목표만 보관하고 피해/체력/일회 보상 중복 정산을 허용하지 않는다.
