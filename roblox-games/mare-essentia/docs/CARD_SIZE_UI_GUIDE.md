# 카드 크기·원화·프롬프트 통일 가이드

> 목적: 카드배틀·내 카드·지도자·퀘스트 카드가 모바일/PC에서 같은 크기 규칙을 쓰도록 정리한다.
> 근거: `DeckBuilder.luau`의 현재 값. 새로 만든 규격이 아니라 **지금 코드의 실제 값**을 문서화했다.

## 1. 현재 기준 크기 (코드 값)

| 대상 | 크기 | 비고 |
|---|---|---|
| 카드 틀(PC·큰 화면) | **100 × 138 px** (약 5:7) | 지도자 카드도 동일 (`DeckBuilder.luau` 지도자 카드) |
| 그림 영역 | 카드 위쪽 70%, 좌우 4px 안쪽 → **약 92 × 92 px (1:1)** | 이름 띠는 아래 30% |
| 모바일 축소 카드 | **34 × 44 px** (화면 높이 640 미만) | 누르면 원본 크기로 확대 |
| 큰 화면 판정 | 오른쪽 패널 높이 ≥ 640 | 그 미만은 축소 표시 |
| 이미지 표시 방식 | `ScaleType.Fit` | 원화를 자르지 않는다 |

결론: **그림 영역이 정사각형이므로 모든 카드 원화는 1:1이 가장 낭비가 없다.**

## 2. 원화 규격

- 대륙·지식·동물·유물·**지도자** 카드 모두 **1:1, 1024×1024 PNG** (최소 768, 등록기 허용 768~4096, 50KB~20MB).
- 글자·수치·금테·패널·엠블럼·여러 장 모음을 그림 안에 넣지 않는다 (틀은 UI가 입힌다).
- 중앙에 주제, **가장자리 12%는 비워 둔다** (카드 모서리·테두리·확대 시 잘림 방지).
- 지도자도 **별도 초상화·얼굴 아이콘은 만들지 않는다.** 원화 한 장이 초상 역할을 한다.
- 기존 등록 지도자 원화(3:4 세로 전신)는 그대로 두고, **새로 만드는 원화부터 1:1.** 기존 것은 `Fit`이라 좌우 여백만 생긴다.

## 3. 움직이는 원화(지도자 등) 규칙

- 같은 1:1 슬롯에 넣는다. 슬롯 크기·위치 코드는 바꾸지 않는다.
- 움직임 폭은 가장자리 12% 안쪽에서만 (몸·망토·깃발이 프레임 밖으로 나가지 않게).
- 첫 프레임이 정지 원화로도 완성된 그림이어야 한다 (로딩 중·저사양 대비).
- 모바일 축소(34×44)에서는 **정지 첫 프레임만** 쓰고, 확대했을 때만 움직인다 (성능).

## 3-1. 24프레임 움직이는 원화 (귀트식 — 제안, 미검증)

- 재생 속도 **24fps**, 루프 길이 1~2초 (24~48프레임)를 기본으로 한다.
- 구현 방식(제안): 프레임을 **스프라이트 시트**로 묶어 `ImageRectOffset/Size`로 넘긴다.
  Roblox 이미지 한 장은 최대 1024×1024 정도로 알려져 있어, 프레임당 해상도는 시트 칸 수에 따라 정해진다.
  - 예) 1024×1024 시트를 4×4 = 16칸 → 프레임당 256×256, 시트 2~3장으로 이어 붙이면 32~48프레임.
  - 화면에서 그림이 약 92px(확대 시 더 큼)이므로 256×256 프레임이면 충분하다.
- 한 번에 재생하는 카드는 **화면에 보이는 확대 카드 1장**만. 목록 속 축소 카드는 정지 첫 프레임.
- 저사양/배터리 모드에서는 정지 프레임. 재생은 `RunService` 한 곳에서 시간 누적으로 프레임을 고른다.
- 정지 원화(1024×1024)와 움직이는 시트는 **같은 구도·색감**으로, 정지 원화가 항상 기준본이다.
- 용량·업로드·승인 절차는 기존 원화 등록기와 별도 확인이 필요하다 (이 문서는 규격 제안만 한다).

## 4. 모바일 규칙 (클릭 시 확대)

1. 화면 높이가 낮으면 카드는 **34×44 축소 표시**, 이름·설명은 옆 한 줄로.
2. 누르면 **원본 100×138 이상으로 확대**하고, 다시 누르거나 바깥을 누르면 닫는다.
3. 확대 카드는 화면 안에 맞춘다 (가장자리 안전 여백, 노치/하단 바 제외).
4. 퀘스트 카드·내 카드·카드배틀 카드가 **같은 크기 계산 함수**를 공유한다 (제안).
5. 터치 영역은 최소 36px 이상으로 유지한다 (축소 카드는 주변 여백까지 눌림 영역).

## 5. 아이디어 목록

- 카드 크기 상수를 한 곳(`CardTheme`)에 모아 모든 화면이 공유.
- 확대 카드에 좌우 이전/다음 넘김 (스와이프 또는 화살표).
- 확대 카드 뒷면: 설명·효과·출처 (뒤집기 연출은 가벼운 가로 스케일 애니메이션).
- 희귀도 테두리 색은 UI가 입히고 원화에는 넣지 않는다.
- 로딩 전 자리표시: 같은 크기의 단색 틀 (레이아웃 흔들림 방지).
- 저사양 모드: 움직이는 원화 정지.

## 6. 원화 프롬프트 템플릿

```
[카드 이름·주제] 한 가지 주제만. 역동적인 컬러 역사 회화, 입체적인 재질,
정사각형 1:1 구도 (1024×1024), 주제는 중앙, 가장자리 12%는 비운 여백.
글자·숫자·금테·카드 틀·엠블럼·여러 장 모음·스프라이트 시트 금지.
사진풍 금지, 시대에 맞지 않는 소품 금지, 다른 카드 소재 혼합 금지.
```

**지도자(정지 원화):**
```
[지도자 이름] 상반신 중심, 얼굴과 포즈를 중앙에, 기존 컬러 회화 화풍,
정사각형 1:1 (1024×1024), 가장자리 12% 여백, 글자·금테·틀 금지,
시대에 맞는 복식만, 배경은 단순하고 인물이 분명하게.
```

**지도자(움직이는 원화):**
```
위 정지 원화와 같은 구도·색감. 움직임은 망토·깃발·머리카락·숨쉬기 같은 작은 동작 위주,
프레임 가장자리 12% 안쪽에서만 움직임, 첫 프레임이 완성된 정지 그림이어야 함, 루프 재생.
```

## 7. 확인 방법

- 코드 값: `DeckBuilder.luau`의 지도자 카드(100×138)와 `layoutLeaderCard`(34×44) 부분.
- 등록 규격: `docs/CARD_BATTLE_HANDOFF.md`, `docs/CARD_ART_PROMPTS.md`.
- 이 문서는 문서만 추가한다. 코드·저장·밸런스는 바꾸지 않는다.
