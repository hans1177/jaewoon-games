# 대서양 섬 (`atlantic_islands`) — 해전 배경

- 지역: `w_africa` · 문화권 기준: 이베리아
- 이 해역 항구: 라스팔마스(`las_palmas`), 푼샬(`funchal`), 퐁타델가다(`ponta_delgada`)

## 기본 모습

| 항목 | 내용 |
|---|---|
| 물 | deep ocean blue |
| 하늘 | trade-wind clouds |
| 해안 실루엣(원경) | volcanic islands, terraced vineyards, white churches; volcanic cones |
| 중경 | volcano peak, harbour fort |
| 근경 | whales, fishing boats |
| 날씨 | 무역풍, 맑음, 폭풍 |
| 파티클 | 고래 물줄기·물보라 |

## 배치 지시

- 원경: 해안 실루엣을 전투 공간 두 방향(앞·옆)에 길게, 가까운 항구가 있으면 그 상징물 실루엣 포함.
- 중경: 3~6개 묶음(배 2~3척 정박/항해, 등대·요새 1, 섬 1~2). 전투 원(반경 250) 밖.
- 근경: 부유물·물새·암초를 6~12개, 전투 동선을 막지 않게.
- 날씨 순환: 무역풍 → 맑음 → 폭풍 (전투마다 무작위 1개, 지역 기후 가중)
