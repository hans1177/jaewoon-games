# 퀘스트·전투 배경 지시서

> **드롭박스 올리는 곳 (필독)**
> - 지상 탐험 원경: `/Vibe2Transfer/inbox/Terrain/field_<탐험지id>.glb`
> - 해전 배경: `/Vibe2Transfer/inbox/Naval/sea_<해역>_near|mid|far.glb`
> - 항해(수동 항해 포함) 배경: `/Vibe2Transfer/inbox/Naval/voyage_<해역>_near|mid|far.glb` (없으면 해전 배경을 다시 씀)
> - 해역 id: `src/ReplicatedStorage/Shared/SeaAreas.luau`
> - 올린 뒤에는 자동 검사(이름·형식·크기·256색 금지·중복) → 자동 등록 → 자동 배치. 결과·거부 이유는 `docs/assets/dropbox_inbox_report.md`. 규칙 전체: `docs/ASSET_MANAGEMENT.md` 2-1절, 파일 이름 전체 목록: `docs/AUTO_PLACEMENT.md`.

> 대상: 해전(NavalBattle)·지상전(FieldScene) 배경. 지역·대륙·항구·퀘스트마다 다르게. 먼저 `docs/RULES.md`.

## 지금 문제 (Studio 확인)

- 해전: 해역 테마 15종이 있지만 각 테마 소품이 **4개뿐**이고 ±450 스터드 가장자리에만 있어 넓은 빈 바다 + 어울리지 않는 바위만 보인다.
- 지상전: 생물군 4종(해안·평원·광산·숲)뿐이라 지역 차이가 없고, 나무가 옅은 청록 단색이라 평면적이다.

## 공통 구성 원칙

| 층 | 거리(스터드) | 내용 | 규칙 |
|---|---|---|---|
| 근경 | 0~120 | 부유물·암초·물새·해초 / 풀·바위·소품 | 전투 공간을 가리지 않게 가장자리, 움직임(흔들림·물결) |
| 중경 | 120~400 | 배·등대·요새·섬 / 나무숲·건물·유적 | 지역 특징이 가장 잘 보이는 층. 3~6개 묶음 |
| 원경 | 400~1500 | 해안선·산맥·도시 스카이라인 실루엣 | 단순 실루엣 + 대기 원근(멀수록 하늘색에 섞임) |
| 하늘 | - | 구름 종류·태양 각도·색 | 지역 기후·시간·날씨에 맞춤 |

- 물: 해역별 색·투명도·파고. 얕은 곳은 밝게(산호·모래), 깊은 곳 어둡게.
- 조명: 낮은 해(측광)로 그림자 길게, 대비 살짝↑. 안개는 원경에만(근경 선명).
- 파티클: 날씨별(비·눈·모래·물보라·화산재·꽃잎). 모바일은 절반.
- 근처 항구가 있으면 원경에 그 항구 스카이라인(`docs/ports/<항구>.md`의 상징물)을 실루엣으로.
- 성능: 원경은 단일 메시 실루엣, 중경 LOD, 근경만 디테일. 전투 시작 시 한 번 생성.

## 코드 위치

- 해전 배경: `src/ReplicatedStorage/Shared/NavalBattle.luau` 의 `coasts` 표(해역 테마: water/sky/props). 해역 선택 로직을 이 문서의 해역 id로 확장.
- 지상전 배경: `src/ReplicatedStorage/Shared/FieldScene.luau` 의 `BIOMES`(지점 이름 단어 → 지형). 이 문서의 생물군·기후·항구 문화로 확장.
- 탐험 지점: `src/ReplicatedStorage/Shared/Sites.luau` (592곳, 지점 id로 배경 지정 가능).
- 코드 한도: `Game.client.luau` 맨 바깥 local 금지(`tests/run.sh` 검사).

## 독립 실내·실외 탐험 확장 지시 (2026-11-29 오너 승인)

기존 지점 ID와 서버 구역 저장을 정본으로 사용한다. 퍼즐·수수께끼 제외. 아래는 구현 목표이며 완성 실물과 독립 맵 연결 검증 전에는 완료로 판단하지 않는다.

| 장소 | 독립 구역 순서 | 실제 목표 |
|---|---|---|
| 고대 유적 | 외곽 → 신전 → 지하 묘실 → 비밀 통로 | 기록·발굴·수호자 |
| 성채 | 성문 → 안뜰 → 병영 → 지휘관실 | 돌파·거점 탈환 |
| 왕궁 | 정원 → 접견실 → 복도 → 보물고 | 조사·경비 돌파 |
| 동굴 | 입구 → 지하 호수 → 깊은 동굴 → 소굴 | 추적·생존·두목 |
| 광산 | 작업장 → 갱도 → 광맥 → 채굴장 | 구조·광물 조사 |
| 밀림 | 숲길 → 강변 → 야영지 → 신전 | 밀렵 저지·구출 |
| 도서관 | 열람실 → 문서고 → 희귀 서적실 | 문헌 확보 |
| 수도원 | 예배당 → 회랑 → 납골당 | 기록·호위 |
| 해적 기지 | 해안 → 창고 → 동굴 선착장 → 선장실 | 잠입·보급 탈환 |
| 난파선 | 갑판 → 선실 → 화물칸 → 침수 구역 | 인양·구조 |
| 적선 | 갑판 → 포격실 → 선장실 → 화물칸 | 승선전·보급 회수 |
| 해상 요새 | 포대 → 병영 → 지하 감옥 | 봉쇄·구출 |
| 신화 소굴 | 해식 동굴 → 수중 공간 | 생존·괴물전 |

- 지역별 실내 원본은 해당 항구·문화권 건축 양식(고딕, 조선, 일본, 이슬람, 마야, 이집트)을 보존한다. 실제 벽·천장·문·계단·창·층간 연결, 가구·벽화·직물·조명·잔향 필요. 승인 모듈 원본의 실제 접점·충돌·동선 확인 전 임의 조립 금지.
- 기존 드롭박스 Interior 분류와 승인 등록기를 사용. 제작 규격 제안: Interior/field_<siteId>_zone_<단계>.glb; 정확한 siteId·단계와 원본 출처 확인 후 기존 등록 목록 및 자동 배치 경로에 추가. 입구·출구·안전 스폰·조사·적 위치를 모델 좌표 기준으로 검증한다. 등록되지 않은 방을 기존 건물 외형으로 사칭하지 않는다.
- 문·계단 전환은 기존 구역 서버 저장 성공 후에만 열고, 현재 구역만 로드한다. 재접속은 완료 기록과 안전한 위치 복원, 미완료 보스는 만피·첫 단계. 실제 실내는 외부 날씨/시간에 맞춘 창문 빛·빗소리 및 내부 광원/잔향 적용. 문·가구 파괴는 기존 전투 오브젝트 정본과 보상 중복 방지 유지.
- 기존 구역 수를 임의 증설하지 않는다. 상세 다층 경로를 열 때는 해당 퀘스트 정의·서버 허용 단계·기존 저장 마이그레이션 및 재진입 검사를 함께 적용한다.
- 1차: 기존 야외 조사 구획에 장소별 이름과 승인 소품을 배치한다. 완전한 실내·독립 맵·수중 이동은 아직 미구현이다.
