# 선박 3D 디자인 제작 규칙 (GPT·에이전트용)

배를 만들기 전에 **이 문서를 먼저 읽는다.** 읽지 못했으면 만들지 말고 알린다.
저장소: `hans1177/jaewoon-games` · 경로: `roblox-games/mare-essentia/`
배 목록과 프롬프트: `docs/ship_design_prompts.csv` (ship_id, name, class, design, era_region, prompt). 배가 늘면 `python3 tools/gen_ship_prompts.py > docs/ship_design_prompts.csv`.

## 목표
지금은 배 28종 중 대부분이 기본 모델 4개(소형·중형·대형·해적 대형)의 색만 바꿔 쓴다. 종류마다 **실루엣부터 다른** 배가 필요하다.
멀리서(카메라 40~120 스터드) 봐도 어떤 배인지 알아볼 수 있어야 한다.

## 형태 규칙
- 한 배 = 선체 + 돛대·돛 + 장식(선수상·깃발·방패·노) 으로 **조각을 나눠** 만든다 (돛만 따로 움직일 수 있게).
- 선수는 **+X 방향**, 위는 +Y, 원점은 수면선 중앙.
- 크기(길이, 스터드): 소형 30 · 중형 38 · 대형 46 · 초대형(갈레온·마닐라·동인도선) 52. 폭은 길이의 0.3~0.35.
- 삼각 대각돛(다우·캐러벨) / 사각돛(코그·갈레온) / 게발톱돛(프라우) / 대나무 살돛(정크) / 노(갤리·세키부네) 처럼 **돛 모양으로 구분**한다.
- 대포 구멍은 실제 포 수(`Ships.luau` 의 `cannons`)만큼. 갤리·거북선은 노 구멍.
- 지역 색은 게임이 `tint` 로 입히므로 **선체는 밝은 나무색**으로 만들고 돛·깃발만 고유색.
- 다각형 수: 배 한 척 **3천 삼각형 이하**, 재질 2~3개.

## 화풍
- 저폴리 스타일라이즈드, 손그림 질감의 단색 면, 굵직한 형태. 현대 물건·글자·상표 금지.
- 역사 고증: `era_region` 칸의 시대·지역을 지킨다 (예: 거북선=조선 1592, 정크=명나라).

## 제출물 (각 배마다)
1. 콘셉트 시트 PNG 1장: 3/4 뷰 + 옆면 + 정면 + 윗면(직교), 회색 배경
2. 가능하면 메시 `ship_id.glb` (또는 `.fbx`)
3. 같은 이름의 `ship_id.png.license.json`: `{"license": "PROJECT_ORIGINAL_ART", "author": "AI generated (도구 이름)", "source": "ai-generated"}`
- 위치: `roblox-games/mare-essentia/assets/inbox/ShipArt/`
- 등록·승인·모델 연결(`Ships.visual`)은 코딩 에이전트가 한다. 올리기만 하면 된다.

## 하지 말 것
- 기본 도형(Part/Ball/Cylinder)만 이어 붙인 배를 만들지 않는다 (AGENTS 규칙).
- 만들지 못한 배를 만든 것처럼 보고하지 않는다. 기존 `assets/` 모델을 덮어쓰지 않는다.
- 우선순위: 거북선 → 정크 → 다우 → 갤리 → 코그 → 나머지 순으로 보내면 좋다 (차이가 가장 눈에 띄는 순).

배 한 척마다: 3/4뷰+옆+정면+윗면 콘셉트 시트(회색 배경). 선수는 +X, 길이 소형30/중형38/대형46/초대형52 스터드.
