## 1. 해양 퀘스트 표시 (코드 — Claude)

| # | 기능 | 내용 |
|---|---|---|
| 1 | 항해 화면 목적지 표시 | 수동 항해 중 의뢰 목적지 방향에 금빛 빛기둥 + 화면 가장자리 화살표·남은 거리 |
| 2 | 바다 위 사건 표지 | 해적 출몰·난파선·조난선·고래 떼 위치에 부표·연기·갈매기 떼(가까이 가면 퀘스트/전투/구조) |

| 4 | 항해 중 '다음 할 일' | 항해 화면 위쪽에도 다음 할 일 띠(도착하면 할 일로 자동 전환) |

## 2. 대규모 해전 확장 (코드 — Claude, 단계별)

| 단계 | 내용 |
|---|---|
| A 함대 편성 | 내 배 1척 → **기함 + 호위 2~4척**. 동료가 호위함 선장(동료 능력 = 호위함 성능) |
| B 진형 | 일렬(포격↑) · 쐐기(돌파↑) · 원진(방어↑) 3가지, 바람 방향과 맞으면 보너스 |
| C 명령 | 집중 포격 · 측면 우회 · 화공선 · 후퇴 4개 버튼(쿨타임). 단순 조작은 유지 |
| D 바람·지형 | 바람 위쪽(풍상) 차지 보너스, 암초·여울·안개 구역, 해안 포대 |
| E 단계 목표 | 함대전 파도마다 목표가 바뀜: 호위선 지키기 → 적 기함 격침 → 항구 봉쇄 돌파 |
| F 역사 해전 | 레판토(1571)·칼레 화공선(1588)·노량(1598)·다운스(1639) 등 이야기 장(章)의 클라이맥스로(당시 조건 재현, 결과는 플레이어 몫) |
| G 결과 반영 | 이기면 그 해역 안전도↑·특산품 값·항로 개방, 지면 봉쇄(교역 흐름에 영향 — 인과 연결) |
