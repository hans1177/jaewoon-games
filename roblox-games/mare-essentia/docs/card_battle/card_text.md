# 카드 설명 작성 지시서

## 구조 (카드 상세)
1. **이름** — 실존 명칭(인물·부대·배·사건), 12자 이내 권장.
2. **병종·줄·전투력** — 아이콘 + 숫자.
3. **능력 한 줄** — `[키워드] 규칙` 형식, 30자 이내. 예: `[결속] 같은 카드가 있으면 서로 두 배`
4. **역사 한 줄** — 회색 작은 글씨, 40자 이내, 사실만. 예: "1571년 레판토에서 갤리선 함대를 이끌었다."

## 키워드 표 (같은 말 쓰기)
| 키워드 | 규칙 문장 |
|---|---|
| 결속 | 같은 카드가 있으면 서로 전투력이 곱해진다 |
| 사기 | 같은 줄 다른 카드 +1 |
| 첩자 | 상대 줄에 놓고 카드 2장 뽑기 |
| 치료 | 버린 카드 한 장 되살리기 |
| 영웅 | 날씨·소각·사기 영향 없음 |
| 장갑 | 받는 약화를 막는다 |
| 저격 | 상대 가장 센 비영웅 카드 하나 제거 |
| 소각 | 가장 센 비영웅 카드 제거 |
| 안개·폭풍·혼전 | 해당 줄 카드 전투력 1 |
| 맑음 | 날씨 해제 |

## 원칙
- 쉬운 말, 한 문장. 숫자는 아라비아 숫자. "~할 수 있다" 대신 "~한다".
- 역사 한 줄은 사실만, 미화·비하 금지. 출처가 필요하면 백과 해설로 연결.
- 고유 능력은 키워드 대신 짧은 이름 + 규칙(예: `[풍차 돌격] 상대 가장 센 카드와 맞붙어 둘 다 -2`).

## 중립 이야기 카드 설명
- 역사 한 줄 대신 **이야기 한 줄**: "『서유기』에서 여의봉으로 요괴를 물리친 원숭이 왕." (작품명 『』 표기)
- 묶음 표시: 카드 아래 "이야기: 서유기 (1/4)"처럼 묶음 이름과 번호.
- 실존 카드처럼 보이게 쓰지 않는다(연도·실제 사건으로 꾸미지 않기).
