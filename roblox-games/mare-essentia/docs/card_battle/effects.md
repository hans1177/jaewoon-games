# 카드배틀 이펙트·소리 지시서

## 공통 타이밍
| 동작 | 길이 | 연출 |
|---|---|---|
| 카드 집기 | 0.1s | 카드 살짝 커짐(1.08), 그림자 짙어짐 |
| 카드 놓기 | 0.25s | 줄로 날아가 쿵(나무 소리), 먼지 약간, 점수 굴러감 |
| 점수 변화 | 0.4s | 숫자 롤링, 오르면 초록 +N 떠오름 / 내리면 빨강 -N |
| 판 종료 | 1.2s | 승리 쪽 왕관 점등·북, 카드 쓸려감(물결) |
| 대결 종료 | 2s | 큰 배너, 패배 쪽 배 기울어짐 |

## 능력별
| 능력 | 연출 | 소리 |
|---|---|---|
| 결속(bond) | 같은 이름 카드 사이 금빛 사슬, 숫자 곱해짐 | 쇠사슬 찰칵 |
| 사기(morale) | 같은 줄 카드에 위로 화살표 물결 | 북 한 번 |
| 첩자(spy) | 카드가 상대 줄로 미끄러지고 내 손에 2장(신대륙 3장) 날아옴 | 속삭임·종이 |
| 치료(medic) | 버린 더미에서 빛기둥, 카드 되살아남 | 종소리 |
| 영웅 | 금테 카드, 날씨·소각 이펙트가 튕겨 나감 | 금속 울림 |
| 장갑(armor) | 방패 문양이 피해를 막음 | 쇠 부딪힘 |
| 저격(snipe) | 조준선 → 상대 카드 쓰러짐 | 머스킷 한 발 |
| 소각 | 가장 센 카드에 불길, 재로 사라짐 | 불길 |
| 안개/폭풍/혼전 | 줄 위에 안개·비바람·먼지구름 깔림, 숫자 1로 떨어짐 | 바람·천둥 |
| 맑음 | 구름 걷히며 햇빛 | 갈매기 |
| 지역 전술 | 줄 끝에 전술 이름 배너(방진·일제 사격…) | 진영 함성 |
| 상성 | 유리한 줄 ▲ 빛, 불리 ▼ 흐림 | - |
| 지도자 능력 | 지도자 초상 확대 + 한 줄 대사, 능력 이펙트 | 진영 나팔 |
| 고유 능력(돈키호테·풍차 등) | 카드 주제 짧은 연출 0.6s 이내(풍차 회전 등) | 주제 소리 |

## 해역·분위기
- 해역 규칙 배너는 판 시작마다 1회. 판이 갈수록 하늘이 노을로.
- 3판 동점 근접(차이 ≤ 5): 배경 음악 템포↑, 화면 가장자리 은은한 진동.

## 금지·성능
- 아이콘마다 상시 반짝이 금지(HUD 규칙). 이펙트는 사건이 있을 때만.
- 파티클 한 번에 40개 이하, 모바일 절반. 카드 한 장 연출 0.6초 넘기지 않기(지루함 방지).
