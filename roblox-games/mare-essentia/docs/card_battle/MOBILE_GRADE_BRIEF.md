## 1. 게임 기둥 4가지 (모든 결정의 기준)

1. **한 장 한 장이 무겁다** — 카드 놓을 때 화면이 반응(쿵, 먼지, 숫자 굴러감, 가벼운 흔들림).
2. **패스가 무기다** — 언제 판을 버릴지 고민. 상대 패스 순간이 가장 긴장되게.
3. **진영마다 이기는 법이 다르다** — 같은 카드라도 진영이 바뀌면 운영이 달라진다.
4. **역사 지식이 힘이다** — 백과에서 배운 사건·인물이 콤보·보너스로 이어진다.

## 2. 메뉴 (세로 모바일 기준, 1080×1920 기준 좌표)

### 2-1. 카드 허브 (카드 메뉴 첫 화면)
```
┌──────────────────────────────┐
│ [진영 깃발] 내 계급 ▸ 갑판장 III  ▓▓▓▓░ 별 3/5   [⚙] │  ← 상단 120px
├──────────────────────────────┤
│        ★ 오늘의 해전 ★                 │
│  [  큰 카드 3장 부채꼴: 내 덱 대표 카드  ]   │  ← 가운데 760px, 원화 크게
│     덱 이름 · 보급 148/165 · 진영        │
├──────────────────────────────┤
│ [ ⚔ 대결 ]  (가장 큰 금색 버튼, 남은 3/5) │  ← 220px
├──────────────────────────────┤
│ [연습] [퍼즐 ●] [이야기] [주간 상자 ▓▓░] │  ← 4칸 아이콘 버튼 160px
├──────────────────────────────┤
│ 덱 · 도감 · 지도자 · 기록 · 상점          │  ← 하단 탭 140px
└──────────────────────────────┘
```
- 배경: 저녁 노을 갑판(진영 색), 천천히 흔들리는 돛 그림자(4초 주기), 갈매기 1마리 가끔.
- 알림 점(●)은 할 일 있을 때만. 상시 반짝이 금지.
- 덱 대표 카드 3장은 손가락으로 넘기면 다른 덱으로 바뀜(좌우 스와이프).

### 2-2. 덱 편집
- 위 180px: 덱 이름, **보급 막대**(넘으면 빨강·흔들림), 카드 수 25/25, 진영·지도자 초상.
- 가운데: 덱 목록(비용 순, 한 줄에 카드 이름·비용·전투력·능력 아이콘). 같은 카드 2장이면 ×2.
- 아래: 보유 카드 격자 4열(7:10 작은 카드), 필터 칩(진영·병종·키워드·등급·비용), 검색.
- 카드 길게 누르기 = 크게 보기(원화 전체 + 능력 설명 + 백과 연결).
- "추천 덱" 버튼: 지역 전술·진영 패시브 맞춤 자동 구성.

### 2-3. 대결 매칭·입장 (2.5초)
1. 화면 가운데 내 지도자 ↔ 상대 지도자 초상이 양쪽에서 미끄러져 와 부딪힘(0.6s).
2. "VS" 대신 **엇갈린 두 닻 문양**(우리 상징) 쾅(0.3s).
3. 두 배가 맞닿는 짧은 연출 → 갑판 판으로 카메라 내려옴(1.2s).
4. 해역 규칙 배너("안개 해역 — 후열 약화") 1회.

### 2-4. 대결 화면 (궨트급 핵심 레이아웃)
```
[상대 지도자 초상(원) · 손패 수 · 판 보석 ◆◆ ]        [상대 합계 큰 숫자]
[상대 후열 ─ 카드들 ─ 줄 점수 · 날씨 아이콘 · 전술 이름]
[상대 전열 ─ 카드들 ─ 줄 점수]
════ 갑판 중앙선: 해역 아이콘 · 턴 표시(내 차례 금빛 물결) ════
[내 전열 ─ 카드들 ─ 줄 점수]
[내 후열 ─ 카드들 ─ 줄 점수]
[내 지도자 능력(누르면 사용) · 판 보석 · 합계 큰 숫자 · [패스]]
[손패 부채꼴 — 가운데 카드 크게, 양옆 작게, 가로 스와이프]
```
- 합계 숫자: 앞서는 쪽 **금색 + 살짝 커짐**, 지는 쪽 흰색.
- 카드를 끌면: 놓을 수 있는 줄이 밝아지고 **점수 변화 미리보기(+5/−3)** 가 줄 옆에 뜸(`B.previewPlay`).
- 내 차례 남은 시간(선택): 테두리 모래시계 30초.
- 패스 버튼: 누르면 "정말 패스? 남은 손패 7장" 1회 확인(설정에서 끌 수 있음).

### 2-5. 판 종료 · 결과
- **판 종료(1.4s):** 이긴 쪽 판 보석 점등 + 북 → 진 쪽 카드가 파도에 쓸려 사라짐 → 남는 카드(진영 패시브)는 빛나며 남음.
- **결과(3s):** 승리 = 상대 배 기울며 돛 찢어짐 + 금빛 배너 + 계급 별 채워짐 / 패배 = 내 배 연기 + 회색 배너 + "다시 도전".
- 보상 줄: 코인·명성·카드 조각이 하나씩 튀어나와 상단 숫자로 날아감(0.3s 간격).

### 2-6. 보상 상자 열기 (궨트급 손맛)
1. 상자 흔들림 3번(누를 때마다 금빛 금 가는 효과) → 4번째 터치에 열림.
2. 카드 5장 뒷면 부채꼴 → 한 장씩 뒤집기. 등급이 높을수록 뒤집기 전 테두리 빛 색이 미리 보임(일반 회색 · 희귀 파랑 · 영웅 보라 · 전설 금).
3. 전설: 화면 어두워짐 → 금빛 기둥 → 원화가 크게 1초 → 이름 배너.

### 2-7. 도감 · 지도자 · 기록 · 계급
- 도감: 진영 탭 + 원화 격자, 미보유는 실루엣. 카드 누르면 백과 해설로.
- 지도자: 초상 크게, 능력 1개 설명 + 쓰는 연출 미리보기 버튼.
- 기록: 승률 원그래프, 최근 10판 띠(승 금·패 회), 리플레이(`B.replay`).
- 계급: 견습 → 갑판장 → 항해사 → 선장 → 제독 (각 I~V, 별 5개). 시즌 보상: 카드 뒷면·갑판 무늬.

## 3. 규칙 (궨트급 균형 원칙 — 우리 규칙으로)

### 3-1. 기본
| 항목 | 값 |
|---|---|
| 덱 | 25장(같은 일반 카드 최대 2장, 영웅·전설 1장) |
| 보급(덱 비용) | 기본 150 + 지도자별 +10~+18. 카드 비용 4~14 |
| 판 | 3판 2선승. 시작 손패 10장, 2판 시작 +3장, 3판 시작 +3장(최대 10) |
| 멀리건 | 1판 전 3장, 2·3판 전 1장 |
| 패스 | 패스하면 그 판에서 더 못 냄. 둘 다 패스하면 판 종료 |
| 동점 | 둘 다 판 보석 1개 잃음(신대륙 패시브 예외) |

### 3-2. 카드 종류
| 종류 | 설명 | 프레임 |
|---|---|---|
| 부대(Unit) | 전투력 있음, 줄에 놓음 | 기본 |
| 영웅(Hero) | 날씨·소각·피해 면역 | 금 테두리 |
| 특수(Special) | 놓으면 효과 후 버림(포격·날씨·맑음) | 둥근 테두리 |
| 함선 장비(Artifact) | 줄에 남아 매 턴 효과 | 사각 청동 |

### 3-3. 키워드 12개로 정리 (아이콘 하나씩, 설명 한 줄)
| 키워드 | 한 줄 규칙 | 아이콘 |
|---|---|---|
| 결속 | 같은 이름끼리 서로 전투력 ×2 | 쇠사슬 |
| 사기 | 같은 줄 다른 카드 +1 | 위 화살표 |
| 첩자 | 상대 줄에 놓고 내 손에 2장 | 눈 |
| 치료 | 버린 더미에서 일반 카드 1장 꺼내 놓기 | 붕대 |
| 장갑 N | 받는 피해 N 줄임 | 방패 |
| 저격 N | 놓을 때 상대 카드 1장에 N 피해 | 조준경 |
| 포격 | 상대 줄 가장 센 일반 카드 파괴(동점 모두) | 불꽃 |
| 돌격 | 놓은 다음 턴 +3 | 말 |
| 매복 | 뒷면으로 놓였다가 상대가 그 줄에 놓으면 공개·발동 | 덤불 |
| 보급 | 놓을 때 덱에서 카드 1장 뽑기 | 상자 |
| 결의 | 판이 끝나도 남음(1회) | 깃발 |
| 지휘 | 같은 진영 카드 놓을 때마다 +1(최대 +5) | 지휘봉 |

- 고유 능력 40종(돈키호테·풍차 등)은 **위 12개 조합 + 카드 이름 연출**로 다시 쓴다. 새 낱말 키워드 금지(외울 게 늘어남).
- 카드 문구 형식: `[키워드] 숫자 — 한 줄` (`card_text.md`).

### 3-4. 진영 7개 — 이기는 방법을 뚜렷하게
| 진영 | 운영 한 줄 | 핵심 키워드 | 패시브(현행 유지) |
|---|---|---|---|
| 유럽 연합 | 판을 따고 카드 이득으로 굴린다 | 결속·보급 | 판 이기면 1장 더 |
| 동아시아 | 줄 하나에 몰아 사기로 폭발 | 사기·지휘 | 첫 판 선공, 사기 2배 |
| 신대륙 | 첩자로 손패 싸움, 동점도 승리 | 첩자·매복 | 동점 승리, 첩자 3장 |
| 중동 | 한 장을 끝까지 남겨 3판에 몰아친다 | 결의·장갑 | 5 이하 최강 1장 남김 |
| 남·동남아 | 손패 많고 길게 버틴다 | 보급·치료 | 시작 손패 +1 |
| 아프리카 | 돌격으로 다음 턴 폭발 | 돌격·사기 | 시작 손패 +1 |
| 미지의 땅(중립) | 지면 강해지는 이야기 카드 | 이야기 묶음 | 판 지면 다음 판 +2장 |

### 3-5. 균형 숫자(점검표)
- 카드 가치 공식: `전투력 + 키워드 가치 ≈ 비용 + 4`. 키워드 가치: 사기 2·첩자 −4(내가 약해짐)+손패 2장·포격 6~10·저격 N.
- 한 판 평균 점수 목표: 1판 45~60, 3판 70~90.
- 시험: `tests/`의 카드 시뮬로 진영 대 진영 1,000판 → 승률 45~55% 안.

## 7. 코드 연결 순서 (바이브 작업용)

1. 허브 레이아웃 2-1 → `Game.client` 카드 허브 렌더러(기존 버튼·서버 호출 재사용)

4. 키워드 12개 정리 → `BoardingCards` 능력 표에 키워드 이름·아이콘 칸 매핑(규칙 숫자는 균형 시험 후)
