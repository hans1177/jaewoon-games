## 0. 카드 분류 원칙 (오너 지시 2026-11-24) — 가장 먼저 지킨다
| 소재 | 분류 | 예 |
|---|---|---|
| **실제 존재**한 인물·부대·배·사건·동물·장소 | **대륙(진영) 카드** — 그 지역 진영 로스터 | 이순신·판옥선(동아시아), 살라딘(중동), 레판토 갤리선(유럽) |
| **소설·설화·신화·전설·미스터리**의 인물·괴물·장소·물건 | **중립 카드(미지의 땅·`lo_`)** — 반드시 **이야기 묶음**으로 엮는다 | 서유기 3장(`lo_51~53` 손오공·저팔계·사오정 + 삼장법사), 맥베스(`lo_48~50`), 오디세우스의 귀환(`lo_54~59`), 크라켄·인어·아틀란티스 |

- **이야기 묶음(StorySeries):** 중립 이야기 카드는 3~6장이 한 이야기로 묶이고, 같이 내면 이야기 효과(예: 서유기 삼제자 구출)가 발동한다. 새 이야기 카드는 `BoardingCards.StorySeries` 표에 묶음으로 추가한다. 낱장 추가 금지.
- **이야기 짜기:** 원작 줄거리의 핵심 장면 3~6개를 카드로(주인공·조력자·적·상징 물건·사건). 예: 서유기 = 손오공(주공격)·저팔계(방어)·사오정(보조)·삼장법사(구출 대상). 카드 대사는 게임 창작 대사.
- **예외 정리 필요:** 지금 일부 소설·설화 카드는 대륙 id(`eu_48~58` 삼총사·하멜른·돈키호테, `me_37~40` 길가메시, `af_37` 아난시, `ea_36` 공성계)를 쓰지만 `neutralStoryCards`로 **중립 취급**한다(저장 호환 때문에 id 유지). 새로 만드는 이야기 카드는 처음부터 `lo_` id로.
- **실존 + 전설이 섞인 소재:** 실존 인물은 대륙 카드, 그 인물의 전설 이야기(예: 아서왕 전설)는 중립 이야기 묶음.
- **원화:** 대륙 카드 = 역사 회화풍, 중립 이야기 카드 = 같은 회화풍이되 이야기 분위기(안개·빛·환상 요소 허용). 실존 인물 사진풍 금지는 공통.

## 1. 컨셉
- **무대:** 대항해시대(1500~1800) 두 배가 맞닿은 순간. 갑판 위에 병사·선원·지휘관을 카드로 늘어놓고 겨룬다(접현전).
- **한 줄 요약:** "바다 위 갑판에서 펼치는 역사 카드전 — 3판 2선승, 아껴 낼 것인가 몰아칠 것인가."
- **역사 지식 = 힘:** 백과에서 발견·이해한 지식이 카드 보너스와 덱 구성으로 이어진다.

## 2. 분위기
| 요소 | 방향 |
|---|---|
| 판(보드) | 젖은 나무 갑판, 밧줄·돛 그림자, 양쪽 배 난간. 진영별 갑판 색·깃발 |
| 빛 | 바다 반사광, 판이 진행될수록 해가 기울고(1판 낮 → 3판 노을) 긴장감 상승 |
| 소리 | 파도·삐걱임·바람이 기본, 카드 놓을 때 나무 쿵, 포 카드는 낮은 굉음, 판 승리 북·나팔 |
| 음악 | 진영별 주제(유럽 현악·동아시아 북·중동 우드·아프리카 타악), 3판 동점 근접 시 템포↑ |
| 글씨 | 짧고 굵게. 숫자(전투력)는 크고 명확하게 |

## 3. 지금 구현된 규칙 (요약)
- 줄 2개: **전열**(근접) / **후열**(사격·포). 카드 병종은 근접·사격·포 3종.
- **3판 2선승**, 판마다 낼 수 있는 카드 5장, 판 끝나면 3장 뽑기, 손패 최대 10, 첫 판 전 **멀리건 3장**.
- 상성: 근접>포>사격>근접(유리 ×1.3, 불리 ×0.85), 무기 검>도끼>창>검(±1).
- 능력: 결속·사기·첩자·치료·영웅·장갑·저격 + 고유 능력 약 40종(돈키호테·풍차·마라톤·로마 등).
- 특수: 소각, 날씨(안개·폭풍·혼전), 맑음. **해역 규칙**(잔잔·폭풍·안개·혼전)이 판 시작을 바꾼다.
- 지역 전술: 같은 지역 카드가 한 줄에 1장↑ +1, 3장↑ +2(방진·일제 사격·기습·기병 돌격·매복).
- 지도자: 진영별 3~5명, 한 판에 한 번 능력(뿔나팔 2배·카드 뽑기·저격·날씨 걷기·자비 등). 보급 한도로 덱 비용 제한.
- 적 성격: 돌격형·균형형·신중형. 일일 대결·연습·퍼즐·이야기 대결(특정 지도자).

## 4. 한 판 진행 (화면 흐름)
1. **입장:** 두 배가 다가와 맞닿는 짧은 연출(1.5초) → 해역 규칙 배너("안개 해역: 사격 줄 약화").
2. **동전 던지기:** 선공 결정(진영 패시브 반영) — 동전이 갑판에 튕기는 연출.
3. **멀리건:** 손패 10장 펼침, 최대 3장 교체(버린 카드는 덱 밑으로 미끄러짐).
4. **판 1~3:** 차례로 카드 내기 또는 **패스**. 카드 놓으면 점수 숫자가 굴러가듯 증가.
5. **판 종료:** 양쪽 합계 비교 → 이긴 쪽 **판 보석(왕관)** 점등, 진 쪽 카드가 바다로 쓸려가는 연출, 남는 카드는 진영 패시브 표시.
6. **결과:** 승패 화면, 얻은 카드·코인·명성, "다시 하기/덱 고치기".

## 5. 내 아이디어 (추가 제안)
- **패스 긴장 연출:** 상대가 패스하면 화면 가장자리가 어두워지고 "상대 패스 — 남은 카드로 뒤집을 수 있나?" 예상 점수 차 표시.
- **점수 예측 미리보기:** 카드를 손가락으로 끌면 놓을 줄의 점수 변화(+/-)를 미리 보여 준다(`B.previewPlay` 활용).
- **역사 콤보:** 같은 사건·인물 묶음(예: 레판토 해전 카드들)이 같은 판에 모이면 이름 배너와 작은 보너스.
- **판별 날씨 변화:** 3판 동안 하늘·바다가 변하고, 해역 규칙이 판마다 다르게 바뀔 수 있는 "변덕 해역" 모드.
- **도감 연결:** 카드 상세에서 "백과 해설 보기" → 위키식 해설·퀴즈로 바로 이동.
- **관전·리플레이:** `B.replay`로 지난 대결 다시 보기, 좋은 수 표시.
- **랭크 시즌:** 항해 계급(견습 → 갑판장 → 선장 → 제독), 시즌 보상 카드 뒷면·갑판 스킨.
- **일일 퍼즐 공유:** `B.puzzle(day)` 결과를 친구와 비교.
- **튜토리얼 3단계:** 1) 카드 내기·줄 2) 패스와 판 3) 능력·상성. 각 단계 실제 대결로.
