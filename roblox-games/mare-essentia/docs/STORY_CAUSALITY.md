# 이야기 인과관계·장(章) 지시서 (2026-11-28 오너 지시, 모두 필독)

> 목표: 플레이어가 "왜 이걸 하지?"를 묻지 않게. 모든 퀘스트가 **문제 → 원인 → 할 일 → 바뀌는 것**으로 이어지고,
> 교역·지상 탐험·해상 전투가 한 사건 안에서 자연스럽게 이어진다.
> 코드 규칙: `docs/STORY_QUEST_SYSTEM.md`. 데이터 파일: `src/ReplicatedStorage/Shared/StoryChapters.luau` (제1장 예시가 들어 있음).

## 1. 한 장(章)의 뼈대 — 반드시 이 순서

| 단계 | 퀘스트 종류(kind) | 하는 일 | 예 (제1장 · 막힌 항로) |
|---|---|---|---|
| 1 문제 발견 | `deliver` | 교역에서 이상한 일을 겪는다 | 암스테르담 직조소가 멈춤 → 양모 납품 |
| 2 원인 조사 | `discover_card` (+ `exploreSite`·`portId`·`cardId`) | 지상 탐험으로 원인을 찾는다 | 포스 만 물범이 떠난 자리 → 해적 은신처 |
| 3 해결 | `win`(해전 승리) / `war_clear`(함대전) / `duel_leader`(카드 대결) | 바다에서 해결 | 해적선 2척 격파 |
| 4 선택 | `choice` (`choiceKey`·`choices`) | 결과가 갈리는 결정 | 해적 선장: 법대로 / 선원으로 |
| 5 결과 | `deliver`·`visit` (+ `needChoice`) | 선택에 따라 다른 마무리, 항구가 달라진 걸 보여 줌 | 순찰선 길 / 해적 지름길 |

## 2. 모든 퀘스트에 꼭 쓰는 칸 (화면에 그대로 나옴)

| 칸 | 뜻 | 길이 | 나오는 곳 |
|---|---|---|---|
| `chapter` | 장 제목 "제N장 · ○○" | 짧게 | 일지 카드 맨 위, 장 완료 장면 |
| `guide` | 장을 끝까지 안내하는 인물 1명 | 이름(직업) | 일지 카드 |
| `problem` | 지금 무엇이 문제인가 | 한 문장 | 화면 아래 '다음 할 일' 띠의 "왜?", 일지 |
| `cause` | 왜 그렇게 됐나 | 한 문장 | 일지 |
| `result` | 하면 무엇이 바뀌나 | 한 문장 | 일지, 완료 장면의 "당신 덕분에 —" |
| `speaker`·`line` | 진행 중 말풍선 대사 | 한 줄 | 동료 말풍선 |
| HAND 사연·결말 | 시작 이야기 / 끝난 뒤 이야기 | 3~5문장 / 2~3문장 | 일지·완료 장면·접속 때 '지난 이야기' |

- **결말(HAND 두 번째)은 다음 단계의 문제를 꺼내며 끝낸다.** (예: "…누가 가서 봐 줘야 해.") → 자연스럽게 다음으로 이어짐.
- 선택(4단계)은 **둘 다 틀리지 않게** 쓴다. 고른 쪽 인물이 5단계에서 다시 나와 돕는다.
- 숫자·목표는 summary 에만. problem/cause/result 는 사람 말로.
- 실존 인물은 알려진 업적만, 대사·사연은 창작임을 지킨다.

## 3. 다음에 쓸 장 (우선순위)

1. 제2장 · 지중해 — 베네치아 유리 품귀 → 무라노 원료 산지 탐험 → 사략선 봉쇄 함대전(`war_clear`) → 상인 길드 편/공화국 편 선택
2. 제3장 · 인도양 — 캘리컷 후추 값 폭락 → 말라바르 해안 숲 탐험 → 해적 카드 대결(`duel_leader`) → 결과
3. 제4장 · 동아시아 — 나가사키 데지마 교역 금지령 → 서적·지도 조사 → 함대전 → 선택

각 장은 5~6단계. `afterPrologue = true`(서막 뒤) 또는 `after = "앞 장 마지막 id"` 로 잇는다.

## 4. 게임이 이미 해 주는 것 (코드 완료)

> 이 화면들에 쓸 아이콘·프레임 제작: `docs/MENU_UI_BRIEF.md`

- 화면 아래 **'▶ 다음' 띠**: 지금 할 일 하나 + "왜?". 누르면 그 메뉴로, 3D 항구에선 해당 건물에 금빛 테두리와 "여기!" 표시.
- 일지 **인과 카드**: 장 제목·안내 인물·지난 이야기·문제→원인→할 일→바뀌는 것·다음 이야기·바로 가기.
- **완료 장면**: "당신 덕분에 — (result)" + 결말. 장 마지막이면 "제N장 완료!" 축하.
- **접속 때 '지난 이야기'** 한 번.
- 메뉴 첫 줄 **지금 할 일 / 추천 / 보상 받기**, 처음 해 보는 기능은 **3단계 그림 안내**, 해전에서 지면 **진 이유 + 다음 할 일**.

## 5. 지역별 이야기 원전 및 창작 원칙 (오너 후속 지시)

- 북해: 스코틀랜드 북부 섬의 셀키 전승. 포스 만의 실종 사건과 인물은 창작. 참고: https://blog.historicenvironment.scot/2024/09/orkney-folktales-the-outrun/
- 지중해: 1291년 무라노 화로 이전의 역사, 장인 비법을 둘러싼 창작 추리극. 참고: https://www.ngv.vic.gov.au/essay/portrait-of-venice-majestic-murano/
- 인도양: 말라바르 후추·계절풍 교역의 역사와 고전 항해담 신밧드의 로크. 해적·표식·대결은 창작. 참고: https://sejarah-nusantara.anri.go.id/hartakarun/category/14/ 및 https://blogs.loc.gov/international-collections/2017/08/the-seven-voyages-of-sindbad-the-sailor/
- 동아시아: 1641년 데지마 네덜란드 상관 이전과 일본 해양 전승 후나유레이. 위조 선단과 사건은 창작. 참고: https://nagasakidejima.jp/english/history/ 및 https://yokai.jp/en/yokai/funayurei
- 후속 지역도 실제 역사·신화·민담·공개 저작물의 고전 문학·창작 미스터리·드라마적 갈등 중 적합한 소재를 지역 고유의 인물·단서·반전·선택으로 변주한다. 현대 소설·드라마의 고유 인물, 대사, 장면, 독특한 설정을 복제하지 않는다. 확인된 역사와 전승, 창작 사건을 구분하고 기존 퀘스트 조건·보상·저장·카드·전투의 실제 동작과 맞는 이야기만 표시한다.

## 6. 모든 지상·해상 의뢰와 지식카드 연결

- 메인 장, 12개 시작 국가의 서막과 학자 이야기, 동료, 10대 지역 대장정 60단계, 10대 현장 항로 50단계, 일반 교역·해전·함대전·역사·연구·인물·치안·시대·주식·길드 허가증을 빠짐없이 적용한다.
- 기존 발견/이해 대상 카드와 기존 보상 카드를 최우선으로 연결한다. 나머지는 실제 지역·상품·학문·인물 및 종류에 맞는 기존 참고 기록을 연결한다. 관련 카드는 신규 완료 조건이나 추가 보상이 아니다.
- 일지 사연의 관련 백과 이름과 완료 후 보유 카드 상세의 가상 이야기 단락을 연결한다. 새 저장 키·카드 지급·해금 조건·파이프라인은 만들지 않는다.
- 역사적 사실과 전승·가상의 사건은 구별하고 현대 창작물의 고유 표현을 복제하지 않는다. 지상 탐험은 실제 카드 발견을 근거로 하고, 해상 전투는 기존 승리/작전 완료 기록만 사용한다. 실제 방문이나 역사적 성과를 별도 판정 없이 주장하지 않는다.

- 10대 대장정은 지역별 인물·계약·유산 기록을 단계마다 별도로 집필한다. 공통 사연 틀을 반복하지 않는다. 역사·인물 연속 의뢰 8개에도 개별 도입과 결말을 두고 길드 허가증의 결말은 실제 거래 해금 결과를 표시한다.

- 주간 길드 의뢰는 기존 7일·3건·수락 한도·보상·완료 기록을 유지하고 실제 항구와 해역, 상품 지식을 반영한 사연 및 완료 문장을 표시한다. 보유한 관련 카드만 기존 백과 상세로 바로 열 수 있다. 해상 사건 33종은 실제 발생한 항해 사건과 출발·도착 항구의 기록에 관련 지식카드를 안내하며, 신화 사건은 가상 전승으로 분류한다. 기존 카드 지급 확률·해전·항해 결과는 그대로 유지한다.
