# 건물 카탈로그 (지역 경제 건물·공공시설·학문 연결) — 설계 초안

표기: **Lv** = 항구 발전도(1~6, VILLAGE_SIM_DESIGN.md), **학문** = 연결 학문 id, **효과** = 마을 안정도(식·의·주·위생·치안)와 교역 보너스.
연도·지역은 실제 역사에서 널리 알려진 것만 쓰고, 정확한 수치는 구현 전 출처 확인(docs/CATALOG.md 규칙). 외형은 승인된 에셋만 사용, 없으면 부족 목록에 기록.

## F. 종교
성당(유럽) · 모스크(이슬람권) · 힌두·불교 사원(인도·동아시아) · 신사(일본) · 신전 광장(아메리카·가상 대륙) → `religious_studies`, `theology`. 효과: 안정도, 축제 이벤트, 학자 후원.

## G. 발전 설비 (마을 레벨업을 돕는 기반)
- 식량 기반(곡물 창고·제분소·어시장) → 인구 상한
- 위생 기반(우물·목욕탕·하수) → 역병 저항
- 치안 기반(재판소·감옥·소방대) → 안정도
- 교육 기반(학교·인쇄소·도서관) → 학문 연구 속도
- 교역 기반(세관·거래소·크레인) → 교역 보너스
레벨업 조건: 다섯 기반 가운데 3개 이상이 일정 단계에 이르러야 한다.

## H. 지역 특화 경제 (예시)
- 네덜란드: 간척·풍차·거래소 → 곡물·금융
- 이탈리아: 유리·직조·거래소 → 사치품·은행
- 영국: 양모·광산·조선 → 직물·무기
- 이슬람권: 바자르·대상 숙소·목욕탕 → 중계 교역
- 인도: 면직·향신료 → 교역품 생산
- 동아시아: 도자기·비단·차·쌀 → 수출 상품
- 아프리카: 소금·금 교역소 → 중계 교역
- 아메리카: 은광·옥수수·설탕 농장 → 원료 공급
- 태평양: 카누 창고·공동 식당 → 항해 지식
