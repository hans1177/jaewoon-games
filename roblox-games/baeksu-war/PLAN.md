# 백수대전쟁 — 로블록스 1차 계획서

## 게임 본질
- **스트롱홀드 즉시 건축 + 냥코 자동 진격 + 건물 10단계 몬스터 진화**.
- 45도 3D 사선 시점, 단일 짧은 전선, 아군/적 성문 정면 입구만 3D로 구현.
- 플레이어는 **슬롯 구매·생물집 건설·건물 업그레이드**만 담당. 소환·이동·공격은 모두 자동.
- 초기 무료 슬롯 3개. 다음 슬롯은 게임 내 골드로 구매, 건물 1개=슬롯 1개. 정해진 3열 고정 슬롯 배치. 상한 개수 임의 지정하지 않음.
- 8종 시작: 참새, 개미, 장수풍뎅이, 늑대, 거북, 슬라임, 골렘, 용. 곤충·동물·식물·괴물로 장기 확장.
- 건설 즉시 1마리 출격. 업그레이드 시 즉시 진화 개체 출격. 5단계 2마리, 10단계 3마리씩 자동 출격.
- 적 처치/성문 파괴 골드 → 다음 슬롯 또는 업그레이드 선택. 적 성문 파괴시 다음 스테이지, 내 성문 함락시 같은 스테이지 재도전.
- 플레이어별 독립 전장·서버 권한 판정·DataStore 저장(골드, 스테이지, 슬롯, 건물 레벨).

## 외부 게임 참고
- **Noob Army Tycoon**: 자동으로 진격하는 병력과 기지 성장의 연결만 참고.
- **Clone Tycoon 2**: 시설이 유닛을 자동 생산하고 전투 수익으로 시설을 업그레이드하는 구조만 참고.
- 모델/텍스처/코드/오디오 복사 없음. 1차 Roblox Part 외형은 출시 아트가 아닌 임시 3D 뼈대.

## 책임 파일
- `shared/Config.luau`: 8종 생물/10단계/경제.
- `server/Game.server.luau`: 좁은 전장/성문/건설/소환/전투/저장.
- `client/Game.client.luau`: 모바일 슬롯·진화 HUD/카메라.
- `default.project.json`: 기존 Rojo 패키지 규약.

## 1차 배포 조건
- 기존 F0~F9 검증·현재 소스 묶음·게임별 정식 Roblox 대상 확인 전에는 **정식 출시 아님**.
- 검증용 비공개 후보 배포와 정식 게임 서버 게시를 구별. 저장·모바일·전투 현장 점검 미실시 항목은 미검증.
- 다음 단계: CC0/내부 자산 적용, 생물별 애니메이션, 연계 공격, 전선 폭주, 실제 모바일/재접속 QA.
