# 로드맵

## 현재 상태
- 게임 로직(교역, 항해, 자동 해전, 도감, 연구, 퀘스트, 저장 검증)은 Luau CLI로 테스트한다. (`tests/run.sh`)
- **Roblox Studio에서는 아직 실행해 보지 않았다.** 서버 진입점(`Core.server.luau`)과 UI(`Game.client.luau`)는 코드 분석만 했고, 실제 화면과 DataStore 동작은 확인이 필요하다.
- 전투 밸런스는 1차 조정 상태다. 매칭 승률은 캐러벨 약 65%, 프리깃 약 85%, 외륜 증기선 약 77%, 철갑 증기 프리깃 약 97% (`tests/run.sh balance`).

## 다음 작업 (추천 순서)
1. **Studio 검증**: Rojo로 열어 UI 표시, 구매·판매, 저장·재접속 확인. 오류는 여기서 가장 많이 나올 것이다.
2. **항구 3D 맵**: 항구 모델, 클릭으로 시설(시장, 조선소, 학자) 이동
3. **항해 연출**: 바다 위 배 이동, 사건 연출, 해전 장면(포격 이펙트, 접현)
4. **지상 탐험 맵**: 스톤헨지 맵 1개, 채집·관찰 상호작용
5. **신화 보스**: 크라켄 (증기선 엔진 소리에 반응하는 패턴)
6. **직업 확장**: 식물학자, 동물학자, 유물수집가, 지도제작자별 스킬
7. **동료 NPC**: 마리아 메리안 등 동료 영입, 대화 연출
8. **콘텐츠**: 퀘스트와 항구 확장 (포르투갈, 스페인, 지중해)
9. **밸런스·튜토리얼·사운드·아트**

## 알려진 한계
- 학자의 활동 시기와 장소는 게임 설정이며 출처 확인 전이다.
- 시장 가격은 서버 전체가 공유한다. 플레이어가 많아질 때의 경제 밸런스는 검증하지 않았다.
- 해전은 자동 시뮬레이션만 있고 연출이 없다.
- 한 플레이어당 배는 1척만 가진다.
