# 로드맵

## 현재 상태
- 게임 로직(교역, 항해, 자동 해전, 도감, 연구, 퀘스트, 저장 검증)은 Luau CLI로 테스트한다. (`tests/run.sh`)
- **Roblox Studio 검증(1차 완료)**: Play에서 새 게임, 교역(구매), 항해(런던→더블린 4일), 자동 해전(승리·전투 Lv2), 전투 탭의 신화 괴물 목록을 확인했다. 출력창 오류 없음. DataStore 저장·재접속은 게시된 체험에서 확인 필요.
- 검증 중 고친 것: 성공할 때마다 DataStore를 동기 저장해 응답이 막히던 문제(→ 변경 표시 후 15초마다 모아 저장), 기본 채팅창이 탭을 가림(→ 끔), 탭 10개가 한 줄에 안 들어감(→ 2줄).
- 전투 밸런스는 1차 조정 상태다. 매칭 승률은 캐러벨 약 65%, 프리깃 약 85%, 외륜 증기선 약 77%, 철갑 증기 프리깃 약 97% (`tests/run.sh balance`).

## 알려진 한계
- 학자의 활동 시기와 장소는 게임 설정이며 출처 확인 전이다.
- 시장 가격은 서버 전체가 공유한다. 플레이어가 많아질 때의 경제 밸런스는 검증하지 않았다.
- 해전은 자동 시뮬레이션만 있고 연출이 없다.
- 한 플레이어당 배는 1척만 가진다.
