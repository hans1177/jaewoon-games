# Studio 일괄 점검표

코드를 먼저 모아서 구현하고, Studio에서는 이 표대로 한 번에 확인한다.
방법: `python3 tools/build_rbxlx.py` → `MareScientia.rbxlx` 열기 → Play(F5). 출력창에 `[Game] call ...` 로그가 남는다.

| # | 확인 | 기대 결과 | 상태 |
|---|---|---|---|
| 1 | 새 게임 화면, 나라·시대 선택, 출항 | 상태 탭이 열린다 | 확인함 |
| 2 | 교역: 구매·판매, ▲▼ 표시와 시장 소식 | 코인·화물 갱신, 소식 표시 | 구매만 확인 |
| 3 | 항해: 출항 → 도착 메시지 | 날짜·보급품 갱신 | 확인함 |
| 4 | 조선소: 수리, 보급품, 선원, 배 구매 | 비용만큼 코인 감소 | 미확인 |
| 5 | 탐험: 항구 탐험 지점 | 카드 발견 또는 "찾지 못했다" | 미확인 |
| 6 | 도감 탭, 분야 표시(신화 포함) | 발견한 카드 강조 | 미확인 |
| 7 | 학자 방문 → 카드 | 연도·명성 조건 메시지 | 미확인 |
| 8 | 연구 탭: 증기 기술 | 필요 카드 없으면 사유 표시 | 미확인 |
| 9 | 퀘스트 수락·납품·보상 | 보상 지급 | 미확인 |
| 10 | 전투 탭: 사략선 사냥 | 승패·전리품·레벨 | 확인함 |
| 11 | 전투 탭: 신화 괴물 도전 (전투 Lv5↑, 런던/더블린/보르도 등) | 쿨타임 안내, 카드 지급 | 미확인 |
| 12 | 상태 탭: 전문 분야 선택, 동료 영입·작별 | 비용·사유 메시지 | 미확인 |
| 13 | 저장·재접속 (게시된 체험에서) | 코인·위치 유지 | 미확인 |
| 14 | 전투 탭: 전문 분야·동료 전용 스킬 잠금 표시와 장착 | 필요 조건 문구, 장착 후 로그에 스킬 이름 | 미확인 |
| 15 | 좁은 화면(휴대폰)에서 버튼 크기·글자 | 잘림 없음 | 미확인 |

알려진 Studio 주의점
- 게시 전 파일에서는 DataStore가 동작하지 않는다 (저장은 게시된 체험에서 확인).
- 화면 오른쪽 버튼은 다른 창에 가려질 수 있다. 사이드 패널을 닫아 게임 창을 왼쪽으로 옮긴다.
| 16 | 지도 탭 | 실제 해안선 위에 항구가 제 위치에 찍히는가, 항구 클릭→출항 | 대기 |
| 17 | 항해 연출 | 출항 시 배·갈매기·파도 연출이 나오고, 화면 누르면 건너뛰어지는가 (증기선은 연기) | 대기 |
