# Roblox 게임 소스

`COMPANY_FLOW.md`의 Roblox 기본 플랫폼 정책을 실제 소스 구조로 구현하는 루트다.

## 규칙

- 게임별 Roblox 소스는 `roblox-games/<game-id>/` 아래에 둔다.
- 모든 Roblox 게임은 같은 게임의 필수 웹 동반 버전을 가져야 한다. 웹 버전은 브라우저 QA와 휴대 가능한 게임플레이 검증용이며 Roblox 네이티브 런타임 증거를 대신하지 않는다.
- 승인된 DESIGN_BASELINE의 게임플레이·콘텐츠 분량은 전부 구현해야 한다. 축소 프로토타입은 중간 검증에는 쓸 수 있지만 개발 완료·출시 후보 완료로 계산하지 않는다.
- Roblox 전용 기능을 웹에서 그대로 구현할 수 없을 때는 승인된 게임플레이 의미를 보존하는 동등한 웹 표현을 문서화한다. 승인 기능을 조용히 누락하는 것은 금지한다.
- 기존 V3 Pump 실행 체인과 `tools/vibe3-roblox-platform.mjs` 어댑터를 그대로 사용한다.
- 별도 배포 파이프라인, 우회 스크립트, 쿠키 인증을 만들지 않는다.
- 모바일 입력/UI를 기본으로 설계한다.
- 서버 권한과 클라이언트 표시 로직을 분리한다.
- 저장이 있으면 DataStore 재접속 검증을 통과해야 한다.
- 멀티플레이 기능이 있으면 서버/클라이언트 경계와 Remote 보안 검증을 통과해야 한다.
- `.rbxl`/`.rbxlx` 게시 파일은 검증된 현재 리비전과 같은 게임 폴더 아래에 둔다.
- 웹 동반 버전 PASS와 별개로 실제 Roblox 게시 성공, 런타임 성공, 독립 QA, 회귀 검증 전에는 Roblox 출시 성공으로 기록하지 않는다.
- 검증된 웹게임 증거는 기존 canonical distillation의 보조 학습 증거로만 사용할 수 있고 Roblox 검증 학습 lane의 네이티브 증거 조건을 우회할 수 없다.

## 기본 구조

`base/`는 새 Roblox 게임을 시작할 때 복사 기준으로 쓰는 최소 소스다. 게임 규칙·밸런스·저장 키는 포함하지 않는다.
