# 카드 격자전

- gameId: `card-grid-duel`
- target: Roblox
- mode: 1대1 멀티 턴제 카드 전술
- board: 5×5
- 이동: 유닛당 자기 턴 1칸
- 행동: 유닛당 이동 1회 + 공격 1회
- 소환: 턴당 카드 1장
- 손패: 시작 4장 / 최대 5장 / 턴 시작 시 1장 드로우
- 덱: 진영별 4종 카드 × 2장
- 판정: 서버 권한

## 파랑 진영
- 검사: HP 100 / 공격 30 / 사거리 1
- 궁수: HP 70 / 공격 25 / 사거리 2
- 방패병: HP 150 / 공격 18 / 사거리 1 / 받는 피해 30% 감소
- 마법사: HP 60 / 공격 35 / 사거리 2 / 대상 주변 1칸 15 피해

## 빨강 진영
- 고블린: HP 80 / 공격 25 / 사거리 1
- 오크: HP 140 / 공격 32 / 사거리 1
- 해골 궁수: HP 65 / 공격 23 / 사거리 2
- 흑마법사: HP 75 / 공격 30 / 사거리 2 / 30% 확률로 다음 턴 행동 봉인

## 승리
상대의 보드 유닛, 손패, 덱이 모두 소진되면 승리한다.

## 구조
- `shared/GameConfig.luau`: 카드/보드 공통 규칙
- `server/Game.server.luau`: 매칭과 모든 게임 판정
- `client/Game.client.luau`: 모바일 우선 보드/손패 UI
